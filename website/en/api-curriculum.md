## How to reproduce {#reproduce}

Start at the preparation code in the primary lesson. Learn fields in [basic tables](chord-data.html) and conversions in [formats](formats.html). Shared lesson snippets execute in independent environments and important comparisons are rendered by ggchord. Explicit synthetic geometry demonstrations are not biological evidence. Keep version/source/verification records and use the [installation page](installation.html) to distinguish development and stable versions.
