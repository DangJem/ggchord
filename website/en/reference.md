## Read the reference {#about}
Every current Rd topic is included below. Signatures, defaults, arguments,
returns and examples are generated directly from the package help source.
English R help is canonical; the Han website translates all prose sections while retaining code, signatures and source identifiers. Both paths contain the same API;
localized [topics](data.md), [terminology](modes.md#terms) and [migration](about.md)
explain the workflows. No functions are hidden because of language.

Examples include their actual rendered figures or text output. Data readers, filters and exporters show tables or reports; unavailable optional parsers explicitly report that no result was computed. Interactive previews open only in interactive sessions, while the website retains reproducible static figures.
