## v0.16.6 旗舰展示与配色 / Flagship figures and colour system

三张showcase图由当前R代码重新生成，未将用户提供的旧版截图或第三方图片作为输出。
弦图和共线性图使用仓库四条FASTA、266条GFF3 CDS及32条原始BLAST HSP；展示
明确筛为12条较长HSP。当前首页不展示GC，相关计算与轨道仍在轨道专题。复杂质粒图
取随包pETDuet-1、常见特征与参考引物，以及commercial_all/unique_6plus酶切子集。

The three showcase images are generated by current R code, not reused user
screenshots or third-party figures. Chord and collinear examples use the four
repository FASTA records, 266 GFF3 CDS and 32 original BLAST HSPs, with an
explicit 12-HSP display subset. The flagship leaves GC to the dedicated track tutorial. The plasmid uses bundled pETDuet-1, curated features,
reference primers and the commercial_all/unique_6plus restriction subset.

序列类别沿用用户参考图的珊瑚红/深蓝灰/青绿/赭黄关系；正负链为红/蓝，相似度为
蓝绿至黄绿的连续标度，背景为暖白。质粒类别保留本包既有紫红编码区、浅绿抗性基因、
黄色起点、蓝色调控与紫色引物。含义不同的类别不强行共用颜色；相同含义保持统一。
共线性的信息层级参考gggenomes、clinker、gggenes官方示例，没有复制它们的绘图代码。

Sequence categories follow the coral/navy/teal/ochre relationship in the supplied
reference. Strands use red/blue, identity uses a blue-green to lime-yellow scale,
and backgrounds are warm white. Plasmid categories retain the package's plum
coding regions, mint resistance genes, yellow origins, blue regulatory features
and purple primers. Shared meanings keep their colours; unrelated categories
are not assigned a misleading common meaning. Collinear composition references
[gggenomes](https://thackl.github.io/gggenomes/),
[clinker](https://github.com/gamcil/clinker) and
[gggenes](https://wilkox.org/gggenes/) without copying their plotting code.

所有展示identity的当前图共享0–100%范围、0/50/80/90/100的颜色位置，以及0/50/80/100的色条刻度，
避免相同相似度随页面的局部数据范围换色。这是文档显式标度，不改变包默认。
All current identity examples share a 0–100% domain, colour positions at
0/50/80/90/100 and readable breaks at 0/50/80/100, so the same identity value
retains its colour across pages.
These are explicit documentation scales; package defaults are unchanged.

当前文档PNG的panel背景透明，plot背景显式统一为 `#FFFCF5`；
截图中的白色feature或标签框仍按其自身语义保留，不做像素替换。
All current documentation PNGs use transparent panel backgrounds over an
explicit `#FFFCF5` plot background; intentional feature and label fills are retained.

本轮补充逐层绘图示例和13个独立质粒参考图。它们均来自当前代码，而不是examples/plasmid中的历史PNG。图库仅在图内适配标签，可隐藏拥挤文字，全部特征几何仍保留。弦图按原始注释顺序四分组抽样并补充负链端部特征，以保留中等密度；方向优化不修改原始链。

Progressive layer examples and13 unique plasmid feature maps are current R outputs, not the historical PNG files in examples/plasmid. Gallery labels fit inside and may hide; feature geometry is retained. Chord features are sampled across annotation order with additional negative-strand endpoints. Orientation optimization changes display only.

GRanges/GInteractions教程结合了[issue #2](https://github.com/DangJem/ggchord/issues/2)的原始需求、当时回复与当前适配器代码；不将仍开放的issue状态当作缺失功能证明，也不将可选依赖跳过计为通过。
