先了解[参考表和图层数据表](data.md)。只要知道两条序列的全长和一对实测比对区间，就能开始比较这两条基因组。可以直接用随包数据[绘制第一张弦图](chord.md#backbones)。示例先画两条带名称的骨架，再加入一条比对，最后在同一组弧线上标出编码序列。

<a id="reading-order"></a>

## 换几种视图阅读同一条比对 {#reading-order}

1. 从[弦图](chord.md#backbones)开始，先比较两条参考序列的长度，再找到连接带的两端。
2. 把同一组记录放到[平行骨架](collinear.md)上，再比较[径向排列](radial-synteny.md)和[双列桑基视图](sankey.md)。同样的源坐标换一种排列，有时更容易读出位置关系。
3. 根据问题继续读[单序列圆图](circular.md)、[双轴比对点图](dotplot.md)，或[总览与细节组合图](fusion.md)。这些图使用不同的输入或面板布局。

<a id="modules"></a>

## 按问题选择视图 {#modules}

六种坐标系分别决定单个面板内的数据如何排列。Fusion 组合图将独立绘制的面板放在一起，并连接面板间相互对应的区间。

| 想回答的问题 | 绘图指南 |
| --- | --- |
| 多条序列环绕排列时，哪些区间彼此匹配？ | [弦图](chord.md) |
| 两条序列平行排列时，比对区间分别在哪里起止？ | [共线性图](collinear.md) |
| 序列从中心向外辐射时，哪些区间彼此匹配？ | [径向共线性图](radial-synteny.md) |
| 左侧查询序列的哪个区间与右侧目标序列的哪个区间匹配？ | [桑基视图](sankey.md) |
| 特征、引物和酶切位点位于一条环状序列的什么位置？ | [单序列圆图](circular.md) |
| 局部比对线段的斜率反映了怎样的相对方向？ | [比对点图](dotplot.md) |
| 另一个面板放大了总览中的哪一段？ | [Fusion 组合图](fusion.md) |

<a id="adjust"></a>

## 调整已有图形 {#adjust}

要改变骨架的阅读顺序或方向，可查阅[序列排列与方向](multi-sequence-layout.md)。要标明部分注释，可查阅[特征和标签](annotations.md)。要叠加测量值，可查阅[定量轨道](tracks.md)。如果需要按序列或链分别设置几何参数，见[灵活参数](parameters.md)。
