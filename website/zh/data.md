先为每条参考序列准备一行记录。知道一条参考上的注释位置，就可以添加特征；知道两条参考上相互对应的位置，就可以添加连接；已有测量值或想对观察记录计数时，可以添加轨道。第一张弦图只用两行参考记录和一行比对记录。

<a id="fields"></a>

## 参考序列 {#fields}

从 `seq_data_example` 选取的两行给出完整的基因组长度，包括比对区间以外的部分。其他表中的标识必须与参考序列完全一致，包括 accession 的版本号。也可以使用本地标识，例如 contig 名称。

| 列 | 何时需要 | 含义与单位 |
| --- | --- | --- |
| `accver` | 必需 | 序列标识必须唯一且非空，以文本保存。 |
| `length` | 必需 | 完整序列长度，必须大于零。核酸以碱基对计，蛋白质以残基计。 |
| `sequence_unit` | 原生蛋白坐标必需，核酸坐标可选 | `"aa"` 表示残基，`"bp"` 表示碱基对，省略时按 bp 处理。同一张图中的参考序列使用同一单位。 |

| accver | length（bp） |
| --- | ---: |
| MT108731.1 | 64,323 |
| MT118296.1 | 32,090 |

坐标从 1 起算，区间包含两端。位置 1–100 覆盖 100 个单位，1–1 表示第一个碱基或残基。要把蛋白区间投影到核酸骨架上，请使用 [CDS 坐标模型](projection.md)。

<a id="features"></a>

## 一条序列上的特征 {#features}

每行特征记录表示一段编码序列（CDS）、一个启动子、一段重复序列或其他注释。随包的 MT108731.1 GFF3 文件首条记录覆盖整条基因组，随后才是下表中的 CDS。要选取编码序列，请按类型筛选。

| 列 | 何时需要 | 含义与单位 |
| --- | --- | --- |
| `accver` | 必需 | 特征所在参考序列的标识。 |
| `start` | 必需 | 区间起点，采用参考序列的单位。 |
| `end` | 必需 | 区间终点，单位与起点相同，包含该位置。 |
| `strand` | 直接向图层传表时必需，也可改用方向字段 | 生物学链向。已知时使用 `"+"` 或 `"-"`，无链向特征使用 `"."`。 |
| `directionality` 或 `direction` | 直接向图层传表时可代替 `strand` | 可用值包括 `"forward"`、`"reverse"`、`"bidirectional"` 和 `"none"`。同时提供链和方向时，含义必须一致。 |
| `type` | 一般特征可选；按类型筛选时需要此列或其他分类字段 | 特征类别，例如 CDS。 |
| `anno` | 可选 | 来源注释或产物描述。 |
| `feature_id` | 按 ID 关联时需要 | 来源中的稳定特征标识，可用来把标签关联到选定记录。 |

| accver | start（bp） | end（bp） | strand | type | GFF3 ID | 产物 |
| --- | ---: | ---: | --- | --- | --- | --- |
| MT108731.1 | 13,064 | 14,554 | + | CDS | cds-QIQ63803.1 | hypothetical protein |

直接用 `geom_feature(data = features)` 接收原始数据时，需要提供链或显式方向。通过 `prepare_ggchord_data()` 准备主注释表 `feature_data` 时，可以只提供参考标识和两个区间端点，缺少方向信息时会记为 `"."`。教学数据 `gene_data_example` 同时保存展示用链和原始链 `source_strand`，解读生物学方向时使用后者。

当 `geom_feature(preset = "gene")` 继承主注释表时，会依次查找 `feature_class`、`type` 和 `role`，用最先找到的字段筛选标为 gene 或 CDS 的行。如果向图层显式提供表，则由所给的行决定绘制对象，省去按类别筛选的步骤。两种写法都要求每个基因的链向已知，为正链或负链。

<a id="alignments"></a>

## 两个区间之间的比对 {#alignments}

一个高分片段对（HSP）表示一条局部比对。ggchord 最初用于绘制 BLAST 表格，因此沿用了紧凑的字段名。前缀 q 表示查询序列（query），s 表示目标序列（subject），accver 表示带版本号的 accession。其他来源的比对也可以使用同一组列。

BLAST 表格格式 6 和 7 默认都有 12 个字段，格式 7 还包含注释行。随包示例的原文件采用定制的格式 7，共 17 个字段，还记录了查询和目标序列的全长及目标链向。连接带只需用两项序列标识和四个端点定位。安装包中的教程 TSV 也用标准的 12 列格式保存了同一条首行比对。

| 列 | 何时需要 | 含义与单位 |
| --- | --- | --- |
| `qaccver` | 必需 | 查询侧的参考标识。 |
| `saccver` | 必需 | 目标侧的参考标识。 |
| `qstart` | 必需 | 来源报告的查询区间起点，使用查询参考的单位。 |
| `qend` | 必需 | 来源报告的查询区间终点，包含该位置。 |
| `sstart` | 必需 | 来源报告的目标区间起点，使用目标参考的单位。 |
| `send` | 必需 | 来源报告的目标区间终点，包含该位置。 |
| `pident` | 可选；按实测一致性着色时需要 | 比对中相同位置所占的百分比，取值为 0 至 100。 |
| `length` | 可选 | 比对列数，包括缺口。参考表中的同名列则表示完整序列长度。 |

`ribbon_data_example` 的第一行来自教程中这对序列的第一条 BLAST 比对，两侧坐标在源记录中均递增。如果一侧递增、另一侧递减，两者的相对方向就相反。应按来源报告的顺序保留四个端点。特征本身的生物学链向和骨架的显示方向各有其含义。

| 查询序列 | 查询起点（bp） | 查询终点（bp） | 目标序列 | 目标起点（bp） | 目标终点（bp） | 一致性（%） |
| --- | ---: | ---: | --- | ---: | ---: | ---: |
| MT108731.1 | 26,298 | 51,139 | MT118296.1 | 7,121 | 31,959 | 98.612 |

<a id="points"></a>

## 两个位置之间的点连接 {#points}

连接线可以把一条参考上的位点与另一条参考上的位点相连。若决定用一个点代表一段区间，应记录取点方法。例如，分别求出上述 HSP 两侧区间的中点并向下取整，得到 MT108731.1 上的 38,718 bp 和 MT118296.1 上的 19,540 bp。连接线表示这两个位置；要保留比对区间的实际跨度，可以绘制连接带。

| 列 | 何时需要 | 含义与单位 |
| --- | --- | --- |
| `qaccver` | 必需 | 第一个点所在的参考序列标识。 |
| `qpos` | 必需 | 第一个点的位置，采用参考序列的单位。 |
| `saccver` | 必需 | 第二个点所在的参考序列标识。 |
| `spos` | 必需 | 第二个点的位置，采用参考序列的单位。 |
| `sequence_unit` | 可选 | 提供时必须与两端骨架所用的单位一致。 |

<a id="measurements"></a>

## 测量值、窗口与计数 {#measurements}

当一个位点或区间已有数值时，可以按该值绘图。随包 pUC19 bedGraph 的第一个窗口记录了 60% 的 GC 含量。原文件采用从 0 起算的左闭右开区间 0–100；读入后，同样的 100 个碱基记为从 1 到 100，包含两端。这里的 GC 百分比描述这个窗口中的序列组成。

| 列 | 何时需要 | 含义与单位 |
| --- | --- | --- |
| `accver` | 必需 | 观察记录或统计窗口所在的参考序列。 |
| `start` | 区间或显式窗口需要 | 纳入的第一个碱基或残基。 |
| `end` | 区间或显式窗口需要 | 纳入的最后一个碱基或残基。 |
| `pos` | 点测量值或单个位置上的事件需要 | 以参考序列单位表示的位置。也可以将自定义列映射到 `x`。 |
| `value` | 已有测量值的信号需要 | 实测数量及其自身单位，例如 GC 百分比。可把数值列映射到高度或填色。 |
| `window_id` | 显式窗口可选 | 每个窗口的唯一标识，用于关联其统计结果。 |

要统计事件数，每个事件保留一行。同一位置的两条观察计为两次。要统计区间覆盖率，提供来源区间，并指定窗口宽度或显式窗口。重叠区间中的每个被覆盖碱基只计一次，用覆盖碱基数除以窗口实际长度可得到覆盖比例。[定量轨道](tracks.md)示范如何绘制测量值，[窗口统计](tracks-statistics.md)展示如何从区间计算覆盖率。
