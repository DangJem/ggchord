## 反馈问题 {#feedback}

请提供能复现问题的最小输入、R 代码和 `packageVersion("ggchord")` 的结果。反馈绘图问题时，请附上图片并注明预期宽高。[在 GitHub 上反馈](https://github.com/DangJem/ggchord/issues)
