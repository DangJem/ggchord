# Sequence colour scales

Sequence colour scales

## Usage

``` r
scale_seq_colour_manual(..., values)

scale_seq_color_manual(..., values)
```

## Arguments

- ...:

  Arguments passed to \[ggplot2::scale_colour_manual()\].

- values:

  A set of aesthetic values to map data values to.

## Value

A ggplot2 scale.
