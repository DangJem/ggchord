# Gene, feature and region fill scales

Gene, feature and region fill scales

## Usage

``` r
scale_gene_fill_manual(..., values)

scale_feature_fill_manual(..., values)

scale_region_fill_manual(..., values)
```

## Arguments

- ...:

  Arguments passed to \[ggplot2::scale_fill_manual()\].

- values:

  A set of fill values to map data values to.

## Value

A ggplot2 scale.
