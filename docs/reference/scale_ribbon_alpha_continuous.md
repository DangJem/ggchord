# Ribbon alpha, outline and linetype scales

Ribbon alpha, outline and linetype scales

## Usage

``` r
scale_ribbon_alpha_continuous(..., range = NULL)

scale_ribbon_alpha_manual(..., values)

scale_ribbon_colour_manual(..., values)

scale_ribbon_color_manual(..., values)

scale_ribbon_linetype_manual(..., values)
```

## Arguments

- ...:

  Arguments passed to the corresponding ggplot2 scale.

- range:

  Output alpha range for a continuous scale.

- values:

  Manual aesthetic values.

## Value

A ggplot2 scale.
