# Resolve the per-legend position overrides for a plot

Each legend can be moved independently with the \`legend_position\`
argument of \`geom_seq()\`, \`geom_ribbon()\` and \`geom_gene()\`. A
NULL entry means that legend follows the theme's \`legend.position\`
together with the others.

## Usage

``` r
ggchord_legend_positions(plot)
```
