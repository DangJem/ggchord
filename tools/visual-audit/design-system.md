# ggchord 网站设计系统

本文件描述视觉与交互契约；真实浏览器结果由同目录验收记录补充。设计目标是以三种图形语言组织科研学习：弦图的弧线与连接、共线性图的平行骨架、单序列圆图的环与注释。装饰母题是原创示意，不作为生物分析结果。

## 设计令牌

单一来源为 `website/assets/site.css` 的 `:root` 与 `[data-bs-theme=dark]`；不要在文末追加相同组件的覆盖补丁。确切值、公式和本轮计算见 `contrast.json`，运行 `python3 tools/check-site-design.py --write` 刷新证据，默认命令只校验。

| --- | --- | --- | --- |

必要控件边界与装饰分界分开。`--color-rule` 不足以独自满足必要 UI 的 3:1 阈值；输入边界须采用独立 `--color-control`。本轮已将搜索输入边界改用该令牌；其余组件的真实层叠与焦点仍由浏览器验收确认，不能只因令牌被声明就假定所有页面已应用。

空间比例以 `.25/.5/.75/1/1.5/2/3rem` 递增；小圆角 5px、面板圆角 10px；阴影仅用于弹窗层级。系统无衬线正文与系统等宽代码不引入远程字体。

## 页面层级与响应式

- 长教程：左侧当前课程，中央正文，右侧本页小节；其他课程通过顶栏和章节索引进入。当前课程用基础必学、进阶可选和综合案例分层。
- 正文上限 `76ch`，图、表、代码使用可用的较宽空间；不能为了长行代码扩大整个页面。
- 首页、图库和函数索引使用宽画布；不强行保留两侧文章导航。
- 1200px 以下收起右侧页内目录，在文内提供可折叠目录；900px 以下课程导航改为文内抽屉；650px 以下参数对照和任务卡改为单列。
- 固定顶栏的高度、文档锚点间距通过 `--header-height` 协同；标题跳转后不能被顶栏遮住。
- 三类课程同时用名称、原创图形母题和颜色识别。当前项同时有边线、字重和背景，不能只依靠颜色。

## 组件契约

| 组件 | 目的与行为 |
| --- | --- |
| `course-nav` / `.chapter-nav` | 当前课程、课程首页、学习阶段、当前章；其他课程另设入口 |
| `.page-nav` / `.page-outline` | 仅当前页标题，滚动时更新活动项而不移动键盘焦点 |
| `.breadcrumb` / `.lesson-stage` | 返回上级入口并显示真实章节进度；不伪造学习完成状态 |
| `.task-card` / `.mode-motif` | 绘图问题、最少输入、第一课、完整案例；示意 SVG 不冒充数据图 |
| `.code-disclosure` / `.copy-code` | 语言、当前步骤代码及明确复制反馈；基础代码默认可见 |
| `.example-actions` | 完整脚本具有真实准备步骤与依赖说明；只复制本步骤的按钮不能称为完整可运行示例 |
| `.table-scroll` / `.data-output` | 表格局部横滚，保留完整 ID、坐标和数值；数值可右对齐、等宽 |
| `.parameter-table` | 窄屏允许保留足够列宽，不将相邻参数对照拆成无法比较的卡片 |
| `.figure-comparison` / `.figure-panel` | 同输入参数图在宽屏相邻展示，窄屏单列；不能凭排版把多参数预设称为单参数对照 |
| `.figure-viewer` | 全尺寸原图、适应视窗、原始大小、滚动/平移；Esc 关闭、焦点约束及返回触发链接 |
| `.search-dialog` | 课程、函数、参数、FAQ 分类及命中摘要；键盘打开、上下选择、Esc 关闭、明确无结果状态 |
| `.language-control` | 对应语言同页切换；保留已有锚点，当前语种有文本与状态 |

主题切换只改变图片外围容器，不对科研图应用滤镜、反色或替换颜色。所有科研图仍能打开原 PNG；放大查看是密集注释的必要路径，不依赖小缩略图辨识每个标签。

## 图像与性能

按用户最新要求，网站直接复用原始 Logo 和 169 张科研 PNG，不保留多尺寸展示副本，
不生成 srcset。浏览器按容器尺寸展示同一文件；首屏关键图优先加载，其余图延迟加载。
删除衍生资源后，原先的字节节省统计不再适用于当前实现。

## 可访问性验收边界

[WCAG 2.2 对比度最低要求](https://www.w3.org/TR/WCAG22/#contrast-minimum)为普通文字 4.5:1、大字 3:1；大字阈值为 18pt，或 14pt 粗体。本项目对全部受控文字令牌保守采用 4.5。必要非文字 UI 采用 [3:1 的相邻颜色对比](https://www.w3.org/TR/WCAG22/#non-text-contrast)。主要按钮建议 40–44 CSS px；[AA 2.5.8](https://www.w3.org/TR/WCAG22/#target-size-minimum)通常为 24×24 CSS px，并有间距等例外，不能写成“AA 一律要求 44px”。

令牌检查不是整站 WCAG 认证。语法高亮、浏览器原生菜单、真实焦点遮挡、图像文字和动态状态仍需实际浏览器与键盘复核。减少动画偏好、可见焦点、跳到正文、弹窗焦点返回均为独立验收项。
