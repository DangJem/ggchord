## 已完成的有界验证

### 展示衍生资产

`python3 tools/generate-site-assets.py` 实际生成 342 个无损 WebP 展示副本；完整 Logo 与全部 169 张科研 PNG 没有改写。生成器逐个验证 WebP 解码像素与缩放后像素相同；无 Pillow 的 `python3 -S tools/generate-site-assets.py --check` 通过全部源/输出哈希、实际尺寸与透明信息校验。

代表 Logo320、弦图960和密集质粒960已查看，保留完整画布、图内原色及背景。细读密集名称仍应打开原 PNG，不把 480px 展示副本冒充研究级原图。文件字节收益见 `derived-manifest.json`；没有把静态字节下降宣称为加载速度或 CWV 提升。

### 颜色与源规则

`tools/check-site-design.py` 只用标准库，以 sRGB 线性化、相对亮度及未四舍五入的对比比值比较阈值。`contrast.json` 保存 CSS SHA256、实际颜色、76 组明暗组合、每组阈值和通过状态。

当前 76 组受控配色均通过：普通文字最小 5.1799:1，必要 UI 最小 3.0497:1。初次计算发现分界线用于必要边界时不足（纸面上浅色约 1.35:1、深色约 1.99:1），现已分出独立 `--color-control` 并用于搜索输入。复制按钮的焦点改为内侧安全间距，真实键盘可见性仍待浏览器确认。

普通文字统一按 4.5:1；焦点及必要控件边界按 3:1。工具另检查不反色科学图、减少动画偏好、焦点规则、无外部字体/样式导入及旧调色别名移除。它不处理完整 CSS 层叠，也不证明所有语法高亮或浏览器状态通过，不能当作整站 WCAG 认证。

若 CSS 调整后证据变旧，运行 `python3 tools/check-site-design.py --write`；默认命令只检查记录与源码一致。检查不通过时保留失败明细，不通过修改阈值消除问题。
