## 现代汉语

v0.27.1 优化 Radial 和多视图组合，并改进真实数据示例的可读性。此前 v0.16.7–v0.27.0 的累积功能与迁移方向见[完整 v0.27.0 说明](https://github.com/DangJem/ggchord/blob/v0.27.0/tools/release-notes/v0.27.0.md)。

### 主要变化与迁移

- Radial 环形相邻序列的 ribbon 使用实线，非相邻序列使用与 Collinear 一致的较粗虚线；首尾视为相邻。显式线型映射和固定样式优先。若需要普通线宽，可设置 `nonadjacent_linewidth = 0`；若需要统一实线，可显式设置 `linetype = "solid"`。
- `coord_radial_synteny(nonadjacent_bulge = ...)` 可调整非相邻连接的外拱和通道间距。旗舰图的两条序列调整了显示方向，原始坐标和链保持不变。
- `ggchord_fusion(guides = "collect")` 可收集子图的原生外侧图例并去除视觉上相同的重复项；默认 `"keep"` 保持原行为。`magnify_ggchord()` 也支持该选项。
- `magnify_ggchord(connector = "envelope")` 可分别描绘精确的源选区高亮，并用两条引线连接细节展示框。展示框不代表单个基因组区间，源记录保持不变。
- 修正近切向跨面板 ribbon 的人为折返，并优化标题避让、五面板 Fusion 旗舰图、真实源选区和 README 图片排版。

## English

v0.27.1 improves Radial and multi-view composition and makes the real-data examples easier to read. For the cumulative v0.16.7–v0.27.0 changes and migration guidance, see the [complete v0.27.0 notes](https://github.com/DangJem/ggchord/blob/v0.27.0/tools/release-notes/v0.27.0.md).

### Changes and migration

- Radial ribbons between cyclic neighbours use solid outlines; non-neighbours use heavier dashed outlines consistent with Collinear. The first and last sequences are neighbours. Explicit fixed and mapped styles take priority. Set `nonadjacent_linewidth = 0` for ordinary width or explicitly set `linetype = "solid"` for uniformly solid outlines.
- `coord_radial_synteny(nonadjacent_bulge = ...)` adjusts the outward lift and separation of non-adjacent links. Two sequences in the flagship change display direction while retaining source coordinates and strands.
- `ggchord_fusion(guides = "collect")` collects native outer child guides and removes visually identical duplicates; the default `"keep"` retains previous behaviour. `magnify_ggchord()` also supports this option.
- `magnify_ggchord(connector = "envelope")` outlines each exact source highlight and connects it to the detail display frame with two leaders. The display frame is not a single genomic interval; source records remain intact.
- Fixed artificial bends in nearly tangential cross-panel ribbons and improved heading avoidance, the five-panel Fusion flagship, source-window display and README figure layout.

After download, install it with `install.packages("ggchord_0.27.1.tar.gz", repos = NULL, type = "source")`. Requires R ≥ 4.1.0 and ggplot2 ≥ 4.0.0; this release does not imply a CRAN update.
