## 现代汉语

v0.28.1 汇总 v0.27.1 之后的残基显示、精确放大、Fusion 与文档改进，替换原 v0.27.1 GitHub Release；旧标签保留，便于追溯。

### 主要变化

- `geom_residue()` 默认使用连续方格、深色粗体字形及 DNA/RNA/AA 化学性质配色。自动字号统一适配单元格，保留 3 mm 可读性下限；显式字号继续遵循 `overflow` 策略。`scale_fill_residue()` 可指定字母表，用户自定义标度优先。
- `geom_residue(line_width = 50)` 支持将 100 列分为两行。多序列共用分段边界，gap 仍占一列；原始字符、对齐列和源位置不重新编号。注册 Fusion 选区跨行时须显式拆分。
- `magnify_ggchord(frame_region = ...)` 可独立调整源图框线，保留真实选区、细节数据和放大倍率。默认框线的横向源区间严格对应细节区间，框高独立调整；字符高亮使用无填充描边。
- Fusion 在录制图形跨设备重放时，按最终设备重新计算布局，修复 API 图片裁切及 ribbon/引线错位。旗舰图加入来自真实第二个 CDS 的 60 bp 字符细节；Identity 图例保留数值区间比例。
- 双语 API 页面提供真实图片或文本输出。网站增量构建验证输入、运行环境和输出哈希后复用中间结果；源码、数据或依赖变化使相关缓存失效，全站校验仍执行。纯正文修改的实际验收复用了 API 输出，仅重建两种语言的对应页面。
- 设计来源说明已核实并区分借鉴与比较对象。当前说明正文清理了商业产品名称，原始数据来源、机器标识和历史记录保留。

### 迁移与边界

默认字符图例现为隐藏，需要时设置 `show.legend = TRUE`。自定义残基颜色使用 `ggplot2::scale_fill_manual()`。`line_width = NULL` 保持单行。需要比真实选区更宽的源框时设置 `frame_region`，无需扩大 `region`。这些接口不计算新比对，也不推断缺失字符或生物学关系；自定义映射、标度和明确的源坐标继续优先。

## English

v0.28.1 consolidates residue display, precise magnification, Fusion and documentation improvements since v0.27.1. It replaces the v0.27.1 GitHub Release; the historical tag is retained for traceability.

### Main changes

- `geom_residue()` defaults to continuous square cells, dark bold glyphs and chemical-property DNA/RNA/AA colors. Automatic text fits cells uniformly with a 3 mm readability floor; explicit sizes retain the `overflow` policy. `scale_fill_residue()` selects an alphabet; user scales take priority.
- `geom_residue(line_width = 50)` splits 100 columns into two lines. Sequences share boundaries and gaps consume columns; original symbols, alignment columns and source positions are retained. Split registered Fusion selections explicitly when they span displayed lines.
- `magnify_ggchord(frame_region = ...)` independently adjusts the source frame while preserving the actual selection, detail data and magnification ratio. Default horizontal source extents match detail intervals; frame height is independent. Character selections use unfilled outlines.
- Fusion rebuilds layout on the final device when recorded graphics are replayed, fixing cropped reference figures and misplaced ribbons/leaders. The flagship adds 60 bp from an observed second CDS; Identity legends retain proportional numeric intervals.
- Bilingual API pages include evaluated figures or text. Incremental website builds reuse native intermediates only after checking inputs, runtime and output hashes. Source, data or dependency changes invalidate affected caches; complete site validation remains enabled. Actual prose-edit acceptance reused API output and rebuilt only the corresponding page in each language.
- Design attribution distinguishes documented influences from comparisons. Current explanatory prose omits commercial product names; original provenance, machine identifiers and historical records remain intact.

### Migration and limits

Character legends are now hidden by default; use `show.legend = TRUE` when needed. Use `ggplot2::scale_fill_manual()` for custom residue colors. `line_width = NULL` retains one line. Set `frame_region` for a wider source frame without enlarging `region`. These interfaces do not compute alignments or infer missing characters or biological relationships. User mappings/scales and explicit source coordinates retain priority.

Bilingual sources, API documentation and image dependencies passed their checks.
