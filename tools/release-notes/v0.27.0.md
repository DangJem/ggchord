## 现代汉语

### 版本概览

v0.27.0 是继 **v0.16.6** 后的正式版本，整合了 v0.16.7 至 v0.27.0 开发阶段的累积成果：从统一注释输入、更多序列关系视图，扩展到跨面板组合、真实比对字符、局部放大、数据适配器及物理尺寸布局，并重构了配套文档。中间开发版本并未分别正式发布，因此本说明以 v0.16.6 为升级基线。

### 序列关系视图与统一图层

- **序列比对点图 Dotplot**：新增 `coord_dotplot()` 和 `geom_alignment_segment()`，直接展示已有 HSP。横纵轴可分别选择序列、顺序和方向，保留真实端点、bp/aa 单位和长度比例；序列标题及完整范围与局部刻度分开，每个比较区域有明确边界。导出包含原始比对行、可逆 `axis_layout` 和筛选报告。输入只有单向组合时，图中只显示真实输入，不自动生成镜像或自身比对；空区不等于无同源性。
- **径向共线性 Radial**：新增 `coord_radial_synteny()`，以长度成比例的向外辐条展示序列，支持环形相邻关系、原生注释及定量轨道。完整区间连接保留反向比对两端、单位置 HSP 宽度和中心留白；导出包含辐条坐标框架与端点。两辐条布局每条 HSP 仅保留一次，不支持单辐条或共享分支。
- **Sankey 与 Collinear**：新增镜像双列 Sankey、纵向 Collinear、显式命名/重复展示实例和 `between` 路由。Sankey 保留输入的互向记录，默认过滤同实体连接；对有歧义的实例要求明确选择，避免静默复制证据。
- **统一注释与蛋白坐标**：`feature_data` 统一基因和通用特征输入；gene 图层选择已分类的 gene/CDS，通用 feature 图层可保留未知或双向链。显式图层数据优先。原生蛋白图使用 `sequence_unit = "aa"`，保留完整蛋白长度和单位；拒绝在同一原生图中混用 bp/aa。
- 可选 `length_mode = "equal"` 保留原始长度和投影因子，不允许用统一绝对比例尺误导不同缩放序列。Identity 默认采用固定 0–100 域及 0/50/80/90/95/100 分段，用户显式 scale 优先；渐变 ribbon 和端部收尖需显式启用。

### 多视图组合、局部放大与真实字符

- `ggchord_fusion()`、`fusion_panel()` 和 `fusion_ribbon()` 将静态面板与真实来源区间连接起来，支持嵌套组合、八方位/角度/盒子分配、自动外围排布及显式重叠。每个导出尺寸重新测量字体、图例、边距和面板空间；无法满足的约束明确报错，不通过缩字或丢面板掩盖。
- 组合标题、副标题、说明、标签、背景、边距及跨面板 Guides 使用实际空间；修复了嵌套裁切、半透明连接重复绘制和子面板普通边距造成的假断裂。显式 `legend.position = "none"` 得到尊重。
- 连接可选 `route = "avoid"` 或 `"bundle"`，按实际障碍规划路径；共享显示走廊由显式组定义，不合并科学观测。导出保留来源、完整区间前沿、路由状态、碰撞与遮挡信息。
- `magnify_ggchord()` 支持显式源区间、多个区间和最多四个独立 Collinear 源面板，连接独立构建的细节图；支持嵌套路径和明确声明的跨原点区域。
- `as_ggchord_alignment()`、`read_aligned_fasta()`、`register_ggchord_alignment()`、`map_alignment_position()` 与 `geom_residue()` 提供真实对齐字符及来源位置映射；`translate_ggchord_cds()` 通过可选 Biostrings 翻译真实 CDS。没有比对 trace 的 HSP 不会被重构成碱基层面的错配。

### 定量轨道与已有文件适配

- `geom_track()` 提供十四种几何及 identity/count/bin/summary 统计，并增加源空间 `smooth`、`density`、`ecdf`。统计在展示复制前计算；模型结果保留估计组来源，不伪装成独立观测。不同 track ID 有独立数值域、轴与颜色规则。
- 新增或扩展 BEDPE、bedGraph/BigWig、VCF/BCF、MAF、chain、NUCMER/PROMER delta、已有 feature pairs/memberships 和蛋白 signature matches 的读取；保留原始坐标、物理行、完整长度、元数据及来源记录。缺失长度、Identity、read support 或来源身份不自动推断。
- 部分读取需要用户安装 Bioconductor、Biopython、pysam/HTSlib 或提供 show-coords；绘图不会自动安装解码器或运行比对分析。BigWig 的 rtracklayer 路径目前不支持 Windows。BAM coverage 提供可选工作流，明确 flag、deletion 和 reference-skip 语义。
- 修复 BED 系列将合法序列 ID `track`/`browser` 误当显示头而丢行、GenBank 显式虚拟环境路径解析，以及闭合圆 inward Track 的假自交。

### 注释、坐标与物理尺寸布局

- 圆图跨原点特征保持连续拓扑，真实分段间隙及颜色不被压平；箭头仅出现在真实端点。内侧标签沿各自半径逐字排布，支持多行弧字；分段边界裁切到实际特征轮廓。
- 优化内外标签分配、短引线和密集注释协同；`label_repeat = "bracket"` 可显式为相邻同名短特征提供共享括号标签，保留每个原始特征和来源关联，默认仍逐条标注。
- Collinear 优先搜索局部位置；Radial、Sankey 和纵向 Collinear 在投影后以物理文字尺寸处理碰撞，尊重手动位置。旗舰图采用适合各视图的画幅、可读名称和 Sequence 图例。
- 坐标端点优先，圆图接缝组合起终点；普通刻度可按空间隐藏重叠文字，保留刻度几何。Track 数值轴支持全局 theme 和局部 `guide_axis(theme = ...)`。
- `adapt_ggchord()` 提供可选 fixed/scale/adaptive 布局策略；`diagnose_ggchord()` 增加可测量的文字接触、引线交叉/穿字框、边界及长度信息。未收敛或无法解决的关系会报告，不保证任意输入都无碰撞。

### 文档与网站源

文档按多序列关系、单序列圆图、序列比对点图和多视图组合组织，配套真实输入、渐进示例、参数格式对照、兼容性及故障定位。首页使用真实数据专用预览，并保留完整图和教程入口。网站以汉语正文及结构化内容为唯一手工源，英语由保存、校对的译文生成；缺译、源更新未校对、结构损坏或生成页漂移会阻止构建。代码、数据、图像、导航和锚点共享。本次 GitHub Release 不代表新版网站已部署。

## English

### Release overview

v0.27.0 is the first formal release after **v0.16.6**, consolidating development from v0.16.7 through v0.27.0. It expands unified annotation input and sequence-relation views into cross-panel composition, real alignment characters, magnification, file adapters, physical-size layout, and restructured documentation. The intermediate development versions were not individually released; v0.16.6 is the upgrade baseline used here.

### Sequence-relation views and shared layers

- **Sequence alignment Dotplot**: `coord_dotplot()` and `geom_alignment_segment()` display existing HSPs. Each axis independently selects sequences, order, and direction while preserving original endpoints, bp/aa units, and length proportions. Sequence/range headers are separate from local ticks, with explicit comparison-cell boundaries. Exports include alignment rows, reversible `axis_layout`, and filtering reports. One-way input is not mirrored or expanded with invented self-alignments; empty cells do not establish absence of homology.
- **Radial synteny**: `coord_radial_synteny()` uses length-proportional outward spokes, cyclic adjacency, native annotations, and quantitative tracks. Full interval connections retain inversion fronts, nonzero single-position HSP widths, and the central hole. Exports include spoke frames and endpoints. Two spokes retain each HSP once; one spoke and shared branches are unsupported.
- **Sankey and Collinear**: added mirrored two-column Sankey, vertical Collinear, named/repeated display instances, and explicit `between` routes. Sankey retains reciprocal input rows and filters same-entity links by default. Ambiguous instances require explicit selection rather than silent evidence duplication.
- **Unified annotations and protein coordinates**: `feature_data` accepts genes and general features. Gene layers select classified gene/CDS records; generic feature layers retain unknown or bidirectional strands. Explicit layer data takes priority. Native protein plots use `sequence_unit = "aa"`, retaining complete lengths and units; mixed bp/aa native plots are rejected.
- Opt-in `length_mode = "equal"` retains source lengths and projection factors and rejects misleading shared absolute scale bars. Default Identity uses a fixed 0–100 domain with 0/50/80/90/95/100 bins; explicit user scales take priority. Gradient ribbons and subject tapering are opt-in.

### Composition, magnification, and real characters

- `ggchord_fusion()`, `fusion_panel()`, and `fusion_ribbon()` connect static panels through actual source intervals. They support nested compositions, eight named sides/angles/boxes, automatic perimeter placement, and explicit overlap. Fonts, guides, margins, and panels are measured again at each output size. Impossible constraints fail explicitly instead of shrinking text or dropping panels.
- Composition titles, subtitles, captions, tags, backgrounds, margins, and cross-panel Guides occupy measured space. Fixes address inherited clipping, repeated translucent painting, and artificial connection breaks in ordinary child margins. Explicit `legend.position = "none"` is respected.
- Optional `route = "avoid"` and `"bundle"` use measured obstacles. Shared display corridors use explicit groups and never aggregate scientific observations. Exports retain source identity, complete interval fronts, route status, collisions, and covering information.
- `magnify_ggchord()` accepts explicit source intervals, multiple intervals, and up to four independent Collinear source panels with separately constructed detail plots. Nested paths and explicitly declared origin-crossing regions are supported.
- `as_ggchord_alignment()`, `read_aligned_fasta()`, `register_ggchord_alignment()`, `map_alignment_position()`, and `geom_residue()` expose real alignment characters and source positions. `translate_ggchord_cds()` uses optional Biostrings to translate real CDS. HSPs without alignment traces are not reconstructed into base-level mismatches.

### Quantitative tracks and existing-file adapters

- `geom_track()` provides fourteen geometries and identity/count/bin/summary statistics, adding source-space `smooth`, `density`, and `ecdf`. Statistics run before display replication. Model outputs retain estimation-group provenance rather than becoming independent observations. Different track IDs retain independent numerical domains, axes, and colour rules.
- Added or extended readers for BEDPE, bedGraph/BigWig, VCF/BCF, MAF, chain, NUCMER/PROMER delta, existing feature pairs/memberships, and protein signature matches. Original coordinates, physical rows, complete lengths, metadata, and provenance remain traceable. Missing lengths, Identity, read support, and source identity are not inferred.
- Some readers require user-installed Bioconductor, Biopython, pysam/HTSlib, or a supplied show-coords executable. Plotting does not install decoders or run aligners. The rtracklayer BigWig path currently excludes Windows. The optional BAM coverage workflow states flag, deletion, and reference-skip semantics.
- Fixes preserve valid BED-family sequence IDs `track`/`browser`, honour explicit GenBank virtual-environment paths, and avoid false inward-Track self-intersections at closed circular seams.

### Annotations, axes, and physical layout

- Origin-crossing circular features retain continuous topology, real segment gaps, and colours; arrowheads occur only at true endpoints. Internal labels follow their individual radii character by character, including multiline arc text. Segment-boundary marks are clipped to actual feature contours.
- Improved inner/exterior label assignment, short leaders, and dense annotation coordination. Explicit `label_repeat = "bracket"` shares a bracket label across adjacent identical short features while retaining every feature and its source association; individual labels remain the default.
- Collinear searches nearby positions first. Radial, Sankey, and vertical Collinear resolve collisions after projection using physical text dimensions, preserving manual placements. Flagships use view-appropriate dimensions, readable names, and Sequence guides.
- Scientific axis endpoints take priority, with combined circular seam strings. Intermediate overlapping labels may be hidden while ticks remain. Track value axes support global theme settings and local `guide_axis(theme = ...)`.
- `adapt_ggchord()` offers optional fixed/scale/adaptive policies. `diagnose_ggchord()` adds measured text contacts, leader crossings/through-text contacts, bounds, and lengths. Unresolved or nonconverged layouts are reported; arbitrary inputs are not guaranteed collision-free.

### Documentation and website sources

Documentation is organized around multi-sequence relations, single circular maps, sequence alignment Dotplots, and multi-view composition, with real inputs, progressive examples, parameter-format comparisons, compatibility guidance, and symptom-based diagnostics. The homepage uses dedicated real-data previews and retains full-image/tutorial links. Han prose and structured content are the sole manually maintained website sources; English is generated from saved, reviewed translations. Missing/stale translations, broken structure, and generated-page drift block builds. Code, data, images, navigation, and anchors are shared. This GitHub Release does not imply deployment of the redesigned website.

### Upgrading from v0.16.6

| Change | Migration |
| --- | --- |
| Circular origin at 12 o'clock with clockwise coordinates | Preserve an explicit v0.16.6 angle with `coord_circular(rotation = old_rotation - 90)`; for example, replace 0 with -90. |
| Chord rotation defaults to 0 degrees | Use `coord_chord(rotation = 45)` for the previous 45-degree appearance. |
| Track `bar` counts observations | Use `geom_track_col()` for previous numeric-height bars; do not mechanically replace genuine count plots. |
| Unified annotation input | Prefer `ggchord(feature_data = features)`. `gene_data` and the third positional argument remain with a migration message and no removal version scheduled. Do not supply both non-NULL inputs; select disjoint subsets when combining gene/feature layers. |
| Axis labels hide overlaps automatically | Keep all labels with `theme_ggchord(axis.text.check.overlap = FALSE)`. |
| Non-adjacent Collinear ribbons default to heavier dashed outlines | `nonadjacent_linewidth = 0` inherits the ordinary fixed width; explicit mappings take priority. This default is limited to cross-row Collinear links. |
| Collinear scale bars have no default horizontal inset | Restore the earlier inset with `offset = grid::unit(c(2, 6), "mm")`. |

See [NEWS.md](https://github.com/DangJem/ggchord/blob/v0.27.0/NEWS.md) for individual changes, interface limits, and development-stage records. Historical candidates and unfinished items are not release capability promises.
