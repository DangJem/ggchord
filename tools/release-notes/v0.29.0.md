## 现代汉语

ggchord v0.29.0 是沿用旧版 API 的最后一个正式版。ggchord v0.50.0 正在全面重构，升级后现有绘图代码可能需要改写。依赖旧版 API 的项目可固定使用 v0.29.0。

### 主要变更

- 定量轨道新增 `stat = "coverage"`。用 `binwidth` 指定窗口宽度，默认绘制各窗口的区间并集覆盖比例。用 `after_stat(mean_depth)` 可计入重叠深度。布局导出保留窗口端点和贡献行。
- 特征分道可分别指定首道位置和后续增长方向。默认布局及旧 `side` 调用沿用原几何。
- `ggchord()` 可直接接收准备结果。连接带可在图层中选择捆绑或密度统计，定量图层可指定物理轨道，特征标签可分别控制位置和溢出方式。布局导出可按图层追溯来源、映射、统计或几何阶段。
- 修正反向区间重复排序、链方向冲突、函数图层数据和点图映射等问题。优化密集圆图的标签和引线计算。开发对照中的 178 张教学 PNG 与基线逐字节一致。

### 兼容性与迁移

未移除旧 API。自定义 BLAST 元数据列默认保留文本，需要数值时可通过 `colClasses` 指定列类型。轨道 accession 映射须返回单值或逐行等长值。指定特征位置、轨道位置或连接带统计参数时，须使用支持相应参数的图层或统计。更多示例见[迁移指南](https://github.com/DangJem/ggchord/blob/v0.29.0/MIGRATION-Hans.md)。

### 验证与安装

在 macOS、R 4.6.0 上完成完整测试套件（34 项通过）、R CMD check、双语 vignette 构建，以及 9 个绘图场景的 PNG、PDF、SVG 验收（27 个输出）。

## English

ggchord v0.29.0 is the final release using the legacy API. A major rewrite of ggchord is underway for v0.50.0, and existing plotting code may need changes when you upgrade. Projects that rely on the legacy API can pin v0.29.0.

### Highlights

- Quantitative tracks support `stat = "coverage"`. Set the window width with `binwidth` to plot the fraction of each window covered by any interval. Use `after_stat(mean_depth)` to account for overlap depth. Layout exports retain window endpoints and contributing rows.
- Feature stacking can set the first lane and the direction of subsequent lanes independently. Existing defaults and legacy `side` calls retain their geometry.
- `ggchord()` accepts a prepared result directly. Ribbon layers can select bundling or density statistics, quantitative layers can specify physical tracks, and feature labels can control placement and overflow independently. Layout exports can trace each layer through source, mapped, statistic, and geometry stages.
- Fixes cover repeated sorting of reverse intervals, conflicting strand directions, function-supplied layer data, and dot plot mappings. Dense circular plots use faster label and leader calculations. All 178 tutorial PNGs in the development comparison matched the baseline byte for byte.

### Compatibility and migration

This release removes no legacy API. Custom BLAST metadata columns default to text. Use `colClasses` for numeric columns. Track accession mappings must supply either one value or one value per row. Use a compatible layer or statistic when supplying feature positions, track positions, or ribbon statistic arguments. See the [migration guide](https://github.com/DangJem/ggchord/blob/v0.29.0/MIGRATION.md) for examples.

### Verification and installation

On macOS with R 4.6.0, the full test suite passed all 34 assertions. Release verification also covered R CMD check, the English and Modern Chinese vignettes, and nine plot cases rendered to PNG, PDF, and SVG (27 outputs).

```r
remotes::install_github("DangJem/ggchord", ref = "v0.29.0", dependencies = NA)
```
