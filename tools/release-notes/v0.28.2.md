## 现代汉语

v0.28.2 是相对于 v0.28.1 的 CRAN 预检维护版。本次Release替换v0.28.1 Release，旧Git标签保留供历史追溯；本次GitHub发布不代表已提交或获CRAN接受。

本版承接自CRAN v0.16.6以来的累计能力：Chord/Circular/Collinear、Dotplot、Radial、Sankey、统一注释与蛋白坐标、定量轨道、静态Fusion、真实区间放大和字符细节，以及直接绘图的旗舰数据。此前功能及迁移规则继续适用，完整内容见[累计升级说明](https://github.com/DangJem/ggchord/blob/v0.28.1/tools/release-notes/v0.28.1.md)与下方NEWS；旧Release被替换后，这份有版本的说明仍保留。

### 修改

- VCF 帮助示例按流读取原始头部和前三条真实记录，到第三条立即关闭连接，避免先读取完整压缩文件。已核对记录与原选择逐字一致。
- 两个可选 Bioconductor 解码示例使用带原因注释的 `\donttest{}`，保留完整可运行代码以及依赖/平台判断；不使用 `\dontrun{}`，不删除读取功能。`--as-cran` 的附加示例仍已实际执行。
- DESCRIPTION 改用 `dot plots` 并省去冗余 HSP 缩写，保留完整的 high-scoring segment pair 表述；synteny 是准确的专业术语。重投说明解释术语及从 CRAN 0.16.6 累计开发至 0.28.2 的版本跨度。
- 增加独立 Windows／Debian R-devel 计时与检查记录。公开 API、科学数据、真实输入语义、完整官网教程和默认绘图行为均未改变，无需迁移代码。

### 验证与限制

Windows R-devel r90890 和真实 Debian forky/sid R-devel r90859 的完整 `R CMD check --as-cran` 均为 **0 ERROR、0 WARNING、1 NOTE**，仅剩已解释的版本跨度。普通示例、`--run-donttest`、34项测试、双语教程重建及PDF/HTML手册均通过，未出现examples或DESCRIPTION拼写NOTE。

Windows VCF 独立依赖冷加载8.96秒、实际解析0.44秒，完整附加示例10.36秒；Debian BigWig冷加载2.450秒、区域读取0.055秒，完整附加示例2.977秒。初始化成本仍存在，不能把示例执行范围调整当作底层算法加速；GitHub运行环境也不等于CRAN预检机器。

发布验收重绘178张网站PNG，9组文档图与7类旗舰完成PNG/PDF/SVG检查（48个输出）；网站源码与图片回执已同步，汉语和英语网站一并重新构建部署。远端main检查记录见[GitHub Actions](https://github.com/DangJem/ggchord/actions/workflows/R-CMD-check.yaml)。

## English

v0.28.2 is a CRAN pre-test maintenance release relative to v0.28.1. This Release replaces the v0.28.1 Release, retaining historical Git tags. This GitHub release does not imply CRAN submission or acceptance.

This version carries forward the cumulative capabilities since CRAN v0.16.6: Chord/Circular/Collinear, Dotplot, Radial, Sankey, unified annotations and protein coordinates, quantitative tracks, static Fusion, source-interval magnification and character details, and ready-to-plot flagship data. Existing features and migration rules continue to apply. See the [cumulative upgrade notes](https://github.com/DangJem/ggchord/blob/v0.28.1/tools/release-notes/v0.28.1.md) and NEWS below; this versioned documentation remains available after replacing the old Release.

### Changes

- The VCF help example streams the original headers and first three observed records, closing the connection after the third record instead of reading the complete compressed file first. Records were verified identical to the previous selection.
- Both optional Bioconductor decoder examples use explained `\donttest{}` blocks, retaining complete runnable code and dependency/platform guards. No `\dontrun{}` block or reader functionality was removed. The additional examples were actually executed by `--as-cran`.
- DESCRIPTION uses `dot plots` and omits the redundant HSP abbreviation while retaining the full high-scoring segment pair wording. Synteny remains an accurate scientific term. Resubmission comments explain the terminology and cumulative version jump from CRAN 0.16.6 to 0.28.2.
- Independent Windows/Debian R-devel profiling and checks are recorded. Public APIs, scientific data, real-input semantics, complete website tutorials and plotting defaults are unchanged; no code migration is required.

### Validation and limits

Full `R CMD check --as-cran` on Windows R-devel r90890 and actual Debian forky/sid R-devel r90859 returned **0 ERRORs, 0 WARNINGs, 1 NOTE**, solely the explained version jump. Ordinary examples, `--run-donttest`, all 34 test assertions, bilingual vignette rebuilding and PDF/HTML manuals passed. No examples or DESCRIPTION spelling NOTE remained in these runs.

Independent Windows VCF dependency loading took 8.96 s and parsing 0.44 s; the whole additional example took 10.36 s. Debian BigWig loading took 2.450 s and regional reading 0.055 s; the whole additional example took 2.977 s. Initialization cost remains; adjusting example execution scope is not an underlying algorithm speedup. GitHub runners are not the CRAN incoming machines.

Release acceptance regenerated 178 website PNGs and checked nine documentation cases plus seven flagship types on PNG/PDF/SVG (48 outputs). Website sources and image receipts are synchronized; the Han and English websites are rebuilt and deployed together. Remote main checks are recorded in [GitHub Actions](https://github.com/DangJem/ggchord/actions/workflows/R-CMD-check.yaml).
