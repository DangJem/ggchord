# v0.50.0 原生 API 帮助示例图逐图检查

2026-11-19。初查以旧站帮助页声明的 700 × 433 CSS 像素，逐张查看英语参考页中直接嵌入示例的全部 74 张 PNG，并阅读相邻示例中的输入、投影、映射或预设。两份代表帮助扩展后增加三张图。

示例定稿为 `e77fe176`，桌面深色主题配色修正为 `4512630f`。两种语言分别有 60 个带图帮助主题、77 个嵌图位置。按最终 HTML 的 `img` 引用配对核对，77 对 PNG 文件的 SHA-256 及解码后的像素逐一相同。77 个位置共有 74 种像素内容。质粒预设与等价参数的两图相同，三个帮助主题也共用同一张四列残基示例图。

1440 px 电脑视口实测原生帮助图为 624 × 386 CSS 像素，原图为 1400 × 866 像素。下表的最终观察来自对本次构建的 77 张图按此尺寸逐张辨读。并排排版仅用于巡检，保持每张图的完整边界和显示尺寸。未使用 OCR。参考资料目录中没有嵌入示例代码的历史配图不计入此清单。
