# 窗口覆盖、分面与外部 Stat 的定向核验

2026-11-18，在 v0.50.0 开发分支通过公开轨道接口、`export_ggchord_layout()`、`ggplot_build()` 和 gtable 检查。覆盖几何采用源区间的一基闭端点。柱的两个边缘分别是 `window_start - 1` 和 `window_end`，线取这两个边缘的中点。下列数值来自本地开发核验。

## 手算输入

参考 A 长 10 bp。源表第 1、2、3 行依次为 3–6、4–5、10–10。对 `stat_coverage()`、`geom_track_col(stat = "coverage")` 和 `geom_track_line(stat = "coverage")` 的同一输入导出窗口、源端点、单位、分母、两种分子及成员。三种调用结果相同。

| 4 bp 分窗 | 实际分母 | 并集长度 | 各行交集长度之和 | 覆盖率 | 平均深度 | 来源行 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 1–4 | 4 | 2 | 3 | 0.5 | 0.75 | 1、2 |
| 5–8 | 4 | 2 | 3 | 0.5 | 0.75 | 1、2 |
| 9–10 | 2 | 1 | 1 | 0.5 | 0.5 | 3 |

换成显式窗口 1–4、3–6、10–10、7–8，分母为 4、4、1、2，并集长度为 2、4、1、0，交集长度之和为 3、6、1、0。前两个窗内都能查回第 1、2 行。最后一个窗口的 `source_rows` 为长度零的整数向量。没有观测的样本或参考没有统计行。重复的窗口 ID、同时给定窗宽和窗口表、显式区间或窗口单位与参考单位不一致均有错误诊断。

用 10 aa 参考和 3–6、5–8 两行区间复核既有离散分组语义。对两行不同类别映射 `aes(fill = kind)` 后，两组的覆盖率各为 0.4。改用 `aes(fill = after_stat(coverage))`，并集比例为 0.6，平均深度为 0.8，导出单位为 aa。源参考 A 的 3–7 局部视图以位置 1 重新分窗后，两窗的原始源端点仍为 3–6、7–7。仅对显示视口作裁切时不重新计算统计。

## 样本与真实汇总

一个 10 bp 窗中 S1 有 1 条区间，S2 有 3 条区间。样本以固定尺度 `facet_wrap(vars(sample))` 分开。两组贡献行分别为第 1 行和第 2–4 行。`aes(y = after_stat(n_interval / sum(n_interval)))` 为 0.25、0.75，共同的轨道高度域为 0–0.75。最终构建恰有两个面板，两个面板各有一条柱形及本面板的局部数值轴。

另取仓库已有的[拟南芥完整首对比对块](../../examples/genome-alignments/arabidopsis-first-pair.delta)，来源和校验和见[数据记录](../../examples/genome-alignments/arabidopsis-source.json)。选取文件已记录的 39 条 Chr1 侧闭区间，保留原始比对记录行号。参考长度 30,427,671 bp，按 1,000,000 bp 分成 31 窗。在每窗按输入端点独立列出交集和边界事件，逐窗核对并集长度、交集长度和与来源行。首窗没有交集，末窗的实际分母为 427,671 bp，1 条比对贡献 2,131 bp。这里计算的是既有比对记录的区间覆盖。

## 扩展统计的输入和结果

以下第三方定义只使用公开的 ggplot2 Stat 和 ggchord 轨道接口。轨道向 Stat 提供 `source_row`，内容为整层源表的行号。Stat 可用 `source_rows` 列返回每个统计结果的成员。

```r
library(ggplot2)
library(ggchord)

reference <- data.frame(accver = "A", length = 10)
observations <- data.frame(
  accver = "A", sample = c("S1", "S2", "S1", "S2", "S2", "S2"),
  pos = c(2, 2, 8, 2, 8, 8), value = c(3, 5, 2, 4, 7, 8)
)
StatAtPosition <- ggproto("StatAtPosition", Stat,
  required_aes = c("x", "weight"),
  dropped_aes = "weight",
  compute_group = function(data, scales) {
    hits <- split(seq_len(nrow(data)), data$x)
    data.frame(
      x = vapply(hits, function(i) data$x[i[1]], numeric(1)),
      total = vapply(hits, function(i) sum(data$weight[i]), numeric(1)),
      source_rows = I(unname(lapply(hits, function(i) data$source_row[i])))
    )
  }
)
mapping <- aes(x = pos, weight = value, y = after_stat(total / sum(total)))
p <- ggchord(reference) +
  geom_seq() +
  geom_track_col(mapping, data = observations, stat = StatAtPosition,
                 id = "column", position = "identity", width = 1) +
  geom_track_line(mapping, data = observations, stat = StatAtPosition, id = "line") +
  facet_wrap(vars(sample)) +
  coord_collinear()
export_ggchord_layout(p)$track_statistics
```

| 面板 | 位置 | 按位置的总量 | 整层归一化 | Stat 报告的源行 |
| --- | ---: | ---: | --- | --- |
| S1 | 2 | 3 | 3/29 | 1 |
| S1 | 8 | 2 | 2/29 | 3 |
| S2 | 2 | 9 | 9/29 | 2、4 |
| S2 | 8 | 15 | 15/29 | 5、6 |

两种几何均通过导出和绘制构建。外部 Stat 显式报告成员时，`source_status` 为 `"reported"`；省略成员时为 `"unknown"`，对应的 `source_rows` 元素为 `NULL`。显式返回 `integer(0)` 可以表示已知无贡献行。另用故意引用另一面板源行的 Stat 核对，获得源行错误诊断。成员的科学归属由扩展代码给出，ggchord 校验其索引及所属参考和面板。该探针覆盖这里的数值型位置、逐组统计以及柱和线，其他自定义 Stat 与几何仍须满足各自输入、输出及绘图参数契约。

### 跨图层的来源核对

另取 6 行交错排列的 S2、S1 氨基酸区间，与闭窗 1–5、4–8、10–10 相交。每个面板的三窗均逐位置核对并集、深度总和和分母；成员索引回指全表行号。共用同一输入的特征层导出中，原行号也能逐一还原实体及面板。并列的原生 ggplot2 点层和统计层各用了一个数据函数，单次构建各调用一次。派生图导出四个阶段后回读原图，仍能还原原始数据。再令一个原生点层的数据函数单独引入 S3 面板，三个面板均保留共用骨架；S3 只显示相应点与公共装饰，没有其他样本的特征或覆盖统计值。

### 指定图层显示的面板

混排 S2、S1、S2、S1 的四条注释，分别传给 `geom_feature(data = features, layout = 2)` 与 `stat_coverage(aes(y = after_stat(n_interval / sum(n_interval))), data = source_function, binwidth = 100, layout = 2)`。固定尺度的 `facet_wrap(vars(sample))` 生成 S1 和 S2。导出的特征、多边形及统计均只含 S2，窗口成员是整张输入表的第 1、3 行，该层分母只计选中面板，结果为 1。源表四行仍可导出，数据函数每次构建只执行一次。增加一个仅在原生点层出现的 S0 后，第 2 个面板变成 S1，来源随之变为第 2、4 行。另在 `facet_grid()` 核对共用骨架选择、全部面板都未选中的空图层，以及接收函数式输入后单独贡献面板的覆盖层。参考图层可按面板重复；带样本的注释和轨道拒绝显式跨样本重复，提示用带实际样本键的来源表。
