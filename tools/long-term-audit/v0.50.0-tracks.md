# 同一物理轨道上的独立图层

在 v0.50.0 开发分支上，用一条 1,000 bp 的示例参考序列比较直线与圆形布局。四个观测位置各有一个柱和一个点，两端另有两个预测值，分别来自独立图层。下列代码使用包的公开接口重现轨道注册表和按层统计行数。

```r
library(ggchord)

reference <- data.frame(accver = "A", length = 1000)
observed <- data.frame(accver = "A", pos = c(125, 375, 625, 875),
                       value = c(3, 6, 4, 5))
predicted <- data.frame(accver = "A", pos = c(125, 875), value = c(2, 8))

p <- ggchord(reference) +
  geom_seq() +
  geom_track_col(aes(pos, value), data = observed, track = "depth",
                 id = "observed-bars", width = 140) +
  geom_track_line(aes(pos, value), data = predicted, track = "depth",
                  id = "prediction") +
  geom_track(aes(pos, value), data = observed, geom = "point",
             track = "depth", id = "samples") +
  track_band("depth", width = grid::unit(18, "mm"))

for (coordinate in list(coord_collinear(), coord_circular())) {
  layout <- export_ggchord_layout(p + coordinate, data_stage = "statistic")
  print(layout$track_registry[c("track_id", "width_mm", "limits", "source_layers")])
  print(vapply(layout$track_statistics, nrow, integer(1)))
}
```

| 布局 | 声明带宽 | 共用数值域 | observed-bars | prediction | samples |
| --- | --- | --- | ---: | ---: | ---: |
| 直线 | 18 mm | 0–8 | 4 | 2 | 4 |
| 圆形 | 18 mm | 0–8 | 4 | 2 | 4 |

两种布局均成功生成 ggplot 图形对象。每种布局只导出一条名为 `depth` 的轨道注册记录，列出三个来源图层 ID。第一根柱的中心位于 125，沿参考序列的两端为 55 和 195，两端之差是柱层的 `width = 140`。柱的零基线和折线末端的预测值 8 共同决定高度域。

## 声明和源数据位置

- 将具名带的声明放在图层后，三个引用都能解析。在同图再加一次 `track_band("depth")` 会因为 ID 重复而报错。把图层引用写成 `track = "deph"`，诊断列出有效的 `default` 和 `depth`。
- 单独使用一个点层并省略 `track`，注册表给出 `default`。保留该图，再在内侧加宽 7 mm 的 `extra` 轨道及折线，其默认带的注册记录与原图一致。
- 零宽物理带和负间隔均在声明时给出错误。在同一位置绘制权重分别为 2、3 的两组柱，`position = "dodge"` 产生两个独立的沿序列位置，统计计数之和为 5。
