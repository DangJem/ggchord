# 双语工具书的本地验收

## 本轮重编的范围与依据

在 `v0.50.0` 分支先完成「灵活参数」和 `geom_seq()` 两个代表页，再将同一套绘图、翻译和查阅规则用于全站。首页沿用四组七幅缩图，点开放大后显示当前示例脚本生成的原图。

| 读者的问题 | 实施决定与复验方法 |
| --- | --- |
| 如何从一种图开始 | 六个顶栏入口，绘图指南按七种图形分别给出可独立运行的小图。完整案例各有独立地址。pUC19 简图直接使用随包数据，完整图与首页对应的 pUC19 一致。 |
| 参数为什么在重排后跟错序列 | 专题对照按名称和按顺序指定半径的结果，并实测正负链、部分指定及未知 ID 的反例。11 个公开函数的 24 项标记逐项依据实际效果核定。序列标签的固定 `size` 没有此标记。 |
| 从图追到可执行代码 | 普通图、完整案例、原始尺寸 PNG、复制按钮和 R 下载都使用同一独立脚本。数据示例附实际运行结果。多面板大图的渲染会受同一会话之前绘图的影响，因此每张图使用独立 R 进程。 |
| 主要注释表怎么传 | 准备、校验、清洗、聚焦和分段统一用 `feature_data`。多表使用具名 `features`。原有数据页将构造器的第二个参数误写成连接表，新页按实际签名说明 `mapping` 和逐层传入数据的方式。 |
| 怎样查函数和参数 | 按绘图任务分组的原生参考保留签名、参数、返回值和实际示例输出。参数索引从当前命名空间与 Rd 提取 1,692 个函数和参数组合，点击后定位到帮助页相应参数。 |
| 两种语言如何持续一致 | 英语 Markdown、结构化字段和 Rd 为主源，汉语译文绑定英语摘要。构建检查章节锚点、代码、链接与图像，拒绝缺译、过期和生成文件漂移。双语维护也适用于 README、离线指南及其他成对的说明文档。 |

此前一轮验收使用不同的页面编排和图像清单，历史数字保留在下方。

## 首轮本地网站验收（历史记录）

本地开发分支 `v0.50.0`。用途是从任一条目查看画法、输入或函数，直接复制公开代码操作。网站沿用 pkgdown 与双语正文源，生成物位于被忽略的 `.site/`。

### 用户反例与决定

| 场景 | 实施与复核 |
| --- | --- |
| 想试画 pUC19，复制后缺少 `make_reference_map()` | 页首从随包记录画 2,686 bp 骨架和全部 9 个真实特征。完整参考图保留 39 条位点记录、33 个切点位置。两个例子分别提供图与可独立运行的代码。[源码](../../website/zh/plasmids.md) |
| 给弦图加一层连接需要往回找骨架变量 | 同节可复制代码包括图所需的骨架与连接。起步、加连接、加注释可分别进入。[条目](../../website/zh/multi-sequence-start.md) |
| 画计数轨道时要先算质粒 GC、生成无关图 | 计数例直接选择两条具名参考，用观测到的 query 起点计数。该短例独立渲染的 9 × 5 in PNG 与原计数图字节相同。[条目](../../website/zh/tracks-statistics.md) |
| 读取现成数据要下载整个仓库 | 常用导入示例通过 `system.file()` 定位随包文件。保留原始文件内容、来源和许可。可选解码器的依赖在使用处说明。[导入](../../website/zh/import-signals.md) · [输入来源](../../inst/extdata/tutorial/SOURCES.tsv) |
| 坐标投影必须先去别页或下载准备脚本 | 单端例用随包 lacZα 注释，双端例使用注明用途的区间。两例自行构造所需输入。已有成员关系使用随包植物文件。[投影](../../website/zh/projection.md) · [成员关系](../../website/zh/homology.md) |
| 首页、图库、参考不便于按图或按名查找 | 首页保留四组七图。图库以真实坐标类型分七组，一开始显示八幅代表图。API 索引按 16 类用途组织，函数页区分调用格式、参数、结果和可复制的示例。[首页](../../website/zh/index.md) · [图库](../../website/zh/gallery.md) · [参考索引配置](../../_pkgdown.yml) |

### 查阅方式与取舍

- 顶栏设开始使用、绘图指南、数据与操作、案例图库和 API 参考五个入口。首页用四组旗舰图描述能力。指南从“想画哪一种图”进入，先画骨架，再按需加连接、注释、标签和轨道。已有图的读者也能直接查布局或外观问题。
- 数据入口按手中的文件与接下来的操作组织。同一任务在指南、图库和 API 参考之间互链。普通页面采用通用表述，迁移页保留接口变更版本，数据来源保留可追溯的固定链接。
- 完整参考图保留影响图形的公开调用。页首另给使用真实随包数据的简图，并区分两幅图的输出，让想快速试画和想复现指定图的读者都能直接取用代码。
- 历史页、图 ID、参数和函数书签都有对应去向。移除的函数名通往迁移说明，旧函数的示例书签落到替代函数的示例。API 索引只列当前帮助主题。

### 验证范围

- 汉语是手工正文源。英语与页面结构、代码、链接和锚点通过保存并校对的译文生成。
- 在两种语言的最终 HTML 中核对原始 ID、站内链接与片段、搜索入口、下载文件、源代码与复制内容。绘图示例在空工作目录、新 R 会话中执行。API 原生示例额外核对代码区不含渲染输出。
- 重新绘制 178 张图库 PNG。13 张完整参考图由同页公开图层重绘。7 幅首页预览保留原先的展示构思。用正常尺寸核对实际像素、图片摘要和来源。[手册图渲染记录](../site-audit/handbook-art-rendering.json)
- 四种可选读取示例另行实读。Biopython 1.85 解析随包 GenBank（2,686 bp、1 条注释）、chain（16 条连接）及 MAF（222 条连接、34,429 行比对）。MUMmer 的 show-coords 读取随包 delta，得到 2 条序列、39 条连接。
