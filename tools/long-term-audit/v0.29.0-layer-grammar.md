2026-11-18，以本分支 `5e56526d` 为改动前基线。重点审查同一份源记录怎样经过统计、位置调整、布局和标度，及哪些计算在同一次绘制中重复执行。先前对数据准备、目录引用、历史归档和依赖下限的评估见[二次审计实施记录](v0.29.0-second-review.md)。

## 从用户任务判断接口是否完整

ggplot2 的图层把数据、映射、统计、几何与位置调整组合起来。常见操作有默认值、字符串简写和可配置对象。另一个值得借鉴的设计是明确计算时机，让调用者可以选择原始列、统计结果或最终标度值。ggchord 还要处理源坐标与绘图坐标之间的投影。审核一个参数时，应能回答它读哪一张表、以什么为单位、是否改变行数、投影后还能否查回源记录。[ggplot2 图层](https://ggplot2.tidyverse.org/reference/layer.html) · [位置调整](https://ggplot2.tidyverse.org/reference/layer_positions.html) · [统计扩展](https://ggplot2.tidyverse.org/reference/Stat.html) · [映射求值阶段](https://ggplot2.tidyverse.org/reference/aes_eval.html)

| 用户任务 | 负责的接口 | 单位、行数和边界 |
| --- | --- | --- |
| 把点观察计数、分箱，或显示已测高度 | `geom_track_bar()`、`geom_track(stat = "bin", binwidth = ...)`、`geom_track_col()` | count 对相同组和位置计数。bin 的宽度用源坐标单位。col 的 y 是已有数值。三者按 accession/window 分开计算。显式 group 决定统计分组。 |
| 在同一骨架上分开两组柱 | `track = position_track("events")` 和 `position = ggplot2::position_dodge(width = 10)` | track 的 width 可用毫米，dodge 的宽度以源坐标为单位。先计算计数，再移动柱。共用轨道 ID 可共用物理带，相同坐标上的两组仍有各自的来源。 |
| 给不同链或相交特征分道 | `position_strand()`、`position_plasmid()`、`position_feature_stack(base_position = ...)` | 先确定序列局部法向偏移，再按优先级、长度与闭区间冲突分配最近可用道。跨圆起点和同一多段特征共用生物学来源。旧版 stack 的 side 命名仍有历史方向语义，指定正负偏移时优先写出 base_position。 |
| 保留比对、合并比对，或给原比对标记局部密度 | `geom_link_ribbon(stat = ...)` 及两个 `stat_ribbon_*()` 快捷入口 | identity 保留原记录。bundle 可减少行数。density 保留每条连接，在归一化的 query/subject 中点网格按序列对、方向及可选类别计算，相对密度用序列对内最大权重归一。count、length、pident 权重分别表示行数、比对长度、长度乘一致率。 |
| 用渐变或透明度表达统计量 | `aes(... = after_stat(...))`、每轨道的 fill/colour 标度、`stage()` | 可以先按原始类别训练标度，再用 after_scale 修改得到的颜色。定量轨道的源 x、y、组和最终绘图色值有不同求值时机。端点或 accession 等定位字段需要在几何或统计之前可用。 |
| 核对一个图上元素来自哪里 | `export_ggchord_layout(p, data_stage = ...)` 与 `track_statistics` | 汇总结果可以对应多行。对于模型、密度和 ECDF，来源表示提交给估计器的合格组。窗口复制或几何离散产生的顶点数不能用作观测数。 |

实现入口见[定量图层与统计适配](../../R/track-grammar.R)、[特征位置与分道](../../R/position-feature.R)、[区间合并](../../R/ribbon-layout.R)和[连接带统计](../../R/stat-ribbon.R)。

多数领域图层默认独立使用自己的映射与数据。一张图上，骨架的 accver、特征的 start/end、连接的 qaccver/saccver 属于不同输入表。跨层共享映射时应明确选择 inherit.aes，并确保参与图层的输入都能求出该列。固定样式放 geom，类别差异放 aes，可比较的色值交给 scale。把同一参数下放给每个坐标系会使同一个源记录在换视图时改变意义。[图层输入](../../R/layer-input.R) · [标度推断](../../R/ggchord-scales.R)

## 已复现并修复的边界

1. 过去只有从统计快捷函数进入，才会把连接带的统计结果交给布局。`geom_link_ribbon(stat = "ribbon_density")` 现在支持从几何入口选统计，两个入口共用同一实现。`bins` 等参数交给统计，`min_bundle` 只属于合并。向 identity 传分箱数会报错，拼错为 `binz` 会得到未知参数警告。新增 stat 须按名称传递，既有位置参数顺序保留。
2. `position_track()`、特征位置及默认 identity 在投影后的 ggplot2 图层上可能具有同一个父类。此前把物理轨道交给特征层可以成功建层，但无法移动特征。现在按消费位置的图层校验。特征堆叠的字符串简写与构造器等价。原生轨道的非零柱基线和估计层都能识别 ggplot2 的 identity 对象。
3. 轨道的 14 种原生几何和 7 种受支持统计继续共用 `geom_track()`。此前柱图快捷入口只从省略号接收 track 和 stat，读签名时看不到必需的物理轨道声明。现在两个都是可补全的具名参数，原写法仍可运行。七种统计逐一核对了名字和 ggplot2 内置 Stat 对象的统计输出。smooth、density、ecdf 有各自可搭配的几何和 identity 位置约束。自定义 Stat 若能改变行数或生成新 x，必须先解决来源归属。
4. 当同组同位置有高度 3、NA、9 时，旧 summary 正确返回均值 6，却把三行都列为来源。现在从 ggplot2 筛选后的原生输入记录两个有效行号。加权 count 同步排除缺失权重。按 accession、group 和原位置分组，dodge 或 nudge 后仍可追溯。经两条序列、不同分组与缺失值组合核对。
5. 此前通过搜索表达式显示文本判断求值阶段，原始列 `after_scale_value` 会被当作延迟映射。现在识别函数调用，在 native track 里保留 `stage(start = ..., after_scale = ...)` 的分组和标度训练。验证了映射原始类别、映射统计 count，以及手动标度后的透明色。
6. 在 R 4.6.0 配 ggplot2 4.0.0 的环境，使用默认连接带透明度标度并映射 density 会在选择调色函数时失败。这个上游版本按 aesthetic 名查默认调色函数。现在对该版本使用与原生 alpha 相同的 0.1 到 1 范围，调用者显式设置的范围仍优先。相同调用在 ggplot2 4.0.0、4.0.3 均实际构图成功。

示例及迁移写法见[迁移说明](../../MIGRATION-Hans.md)和[连接带函数帮助](../../man/geom_link_ribbon.Rd)。

## 绘图实测

R 4.6.0、ggplot2 4.0.3、同一台 Mac、同一套字体，用 ragg 以 144 dpi 输出普通 PNG。五类图各画三轮，次序为正、反、正，比较完整出图耗时的中位数。表中未扣除图对象构造、gtable、绘制或关闭设备的时间。CPU 采样单独运行。[复现脚本](../profile-showcase-render.R)

| 场景 | 基线秒 | 本轮秒 | 解释 |
| --- | ---: | ---: | --- |
| 最小直线骨架 | 0.243 | 0.245 | 毫秒级波动 |
| Dotplot | 0.111 | 0.117 | 毫秒级波动 |
| 真实数据弦图 | 2.293 | 1.841 | 本次少 0.45 秒 |
| 真实数据共线性图 | 3.987 | 3.790 | 本次少 0.20 秒 |
| 密集注释圆图 | 47.242 | 22.090 | 少 25.152 秒，耗时下降 53.2% |

圆图基线三轮为 48.598、47.005、47.242 秒，最终代码（a5b5e4a0）三轮为 23.432、22.079、22.090 秒。此前独立复测的中位数为 22.337 秒。每次仍完成四轮面板尺寸修正。单看各阶段的中位数，build 从 7.02 秒降到 3.43 秒，gtable 从 40.06 秒降到 18.53 秒，最终绘制和关闭设备均约 0.12 秒。不同阶段各自取中位数，不能直接相加作为总耗时。

- 密集外侧标签按原次序批量测试 101 个高度，仍选择第一个合法位置。引线先用外框排除不可能相交的线段，余下的做精确相交判定，只记录不同引线对。触碰共同端点沿用原规则。[外侧标签](../../R/layout-perimeter.R) · [引线统计](../../R/layout-external-annotation.R)
- 径向标签把同一候选在弧上的位置与法向预先算好。搜索按原顺序，当已用引线长度达到已知最优值时停止当前分支。旋转矩形仍沿四条轴精确判定。只做碰撞检查时直接求字形框，同次布局的轴标与视图边界复用相同几何。[径向布局](../../R/helpers-label-radial.R) · [字形与矩形](../../R/helpers-label-boxes.R) · [引线裁剪](../../R/helpers-label-routing.R)
- 特征优先级和分道顺序沿用旧规则。按顺序检查已有道，找到第一条相容的道即可停止。一组含跨起点、多段和优先级的 240 行合成输入产生相同道号，三次局部计时中位数由 0.102 秒降至 0.003 秒。这只测分道计算。[分道实现](../../R/position-feature.R)

基准的 15 对 PNG 已逐文件、逐像素比较。圆图和共线性图分别核对 8、9 项公开几何及标签诊断。额外把旧提交的判定函数加载到独立 R 环境，与新版比较了 22,500 对旋转矩形、150 条引线的字形裁剪、15 条折线之间的交叉、2,700 对外侧候选及分段特征分道。不同机器、字体、设备和数据密度会影响这些时间。另一次优化后 CPU 采样中，特征标签分道占 24.0%，径向标签分道占 22.1%，文字盒测量占 12.2%。这些是包含子调用的采样比例，可能重叠。

最终源码重绘了 178 张教学 PNG，逐文件与基线 Git 中的原始图片比对，全部字节一致。执行了 53 个教学页面的准备和构图代码，94 对双语源码、158 个导出与 125 个 Rd 主题通过源码核验。在两个依赖版本上另行核对了名字和对象、位置调整、公开来源行与分阶段配色。验证范围为本机开发环境和普通教学 PNG。

复现五种图的计时命令为 `Rscript --vanilla tools/profile-showcase-render.R /tmp/ggchord-performance timing`。性能归因可使用 `profile circular` 替换结尾的 `timing`。两版使用不同输出目录，保留相同输入与图形尺寸。[示例来源](../documentation-examples.R)

## 后续设计取舍

| 优先级 | 值得验证的工作流 | 进入公开 API 前的验收条件 |
| --- | --- | --- |
| 1 | 从区间注释直接生成每窗口覆盖轨道。现有 bin 按观察的 x（区间输入缺省使用中点）分配，与逐碱基覆盖回答的是不同问题。 | 单碱基、跨两个窗口、重叠区间、未覆盖窗口、窗口边界都给出可手算例子。明确是计数、深度之和、还是被覆盖碱基占比，以及窗口分母、缺失值和对应源行。现阶段可将预先计算的结果交给 `geom_track_tile()`。 |
| 2 | 允许第三方提供轨道 Stat。当前对象支持精确到七个有来源规则的内置统计。 | 先约定返回行到输入行的映射、组与窗口身份、空组、模型新预测点和位置移动前的坐标。第三方能用一个新统计跑通绘制、导出、两层独立复用，再决定扩展入口。 |
| 3 | 简化旧的特征分道方向参数。旧 `side = "outside"` 的基准偏移为 −0.1，`"inside"` 为 +0.1，与 `position_plasmid(offset = ...)` 的正负方向容易混淆。 | 先以显式 base_position 教学。迁移时还应核对向内、向外逐道递增的方向，分别验证圆图和直线图上所有道的几何，再确定旧入口的退役版。 |
| 4 | 继续缩短含密集标签图的尺寸修正。 | 从剩余约 18.5 秒的 gtable 阶段采样，区分与面板大小无关的源区间、随尺寸变化的文字测量和引线选择。只有输入、字体、尺寸与可见性均满足复用条件时才缓存，再核对几何与图像。 |

以上四项为设计候选。尤其是覆盖率的统计含义和通用 Stat 的来源契约，会直接影响使用者如何解释图中的数据。
