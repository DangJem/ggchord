## 影响绘图解释和数据追溯的问题

| 基线问题 | 分支中的处理 | 已核对的可观察结果 |
| --- | --- | --- |
| 再清洗一次使反向连接变同向 | 排序后的数据保留已知相对方向，遇到不相容的方向声明时报出行号 | 原端点为 query 1→20、subject 40→21。两次默认清洗的连接表相同。需要方向端点的绘图使用原始表和 `reversed_interval = "keep"` |
| 一项角色映射覆盖另一项的输入 | 角色表达式共同读取映射前的表 | 对调 `qstart` 和 `qend` 的书写次序均得到 20→1 |
| Dotplot 视觉标度读取投影坐标 | 区分输入列、角色映射结果和用于绘制的投影列 | 输入 `x=99` 时线宽标度读到 99。交换端点并将线宽映射到原始 `qstart` 时仍读到 1。用户命名的内部同名列也可用于视觉映射 |
| 径向显示长度退化为水平分量 | 从原生显示轴求跨度 | 两条等长序列在两个旋转角度均导出相等的正长度，同例的普通共线性和 Sankey 骨架长度也正常 |
| 自定义 BLAST 标识丢失前导零 | 已知数值列正常转换，自定义字段默认按文本保留。按名称指定数值测量类型时，其他自定义字段继续保留原值 | `0007` 和 `7` 进入 Dotplot 后仍对应两条 HSP。相邻测量列可用 `colClasses` 读为数值 |
| 轨道把长度不足的 accession 映射循环补齐 | 身份字段仅接受标量或与观测数等长的值 | 三行观测提供两个 accession 时明确报错 |

下面的最小输入同时检查清洗、几何映射和视觉映射。前两次清洗应返回相同的表，图中 query 从 20 指向 1，线宽读取的源值为 1。[清洗实现](../../R/clean.R) · [输入映射](../../R/layer-input.R) · [点图投影](../../R/coord-dotplot.R)

```r
pkgload::load_all(".", export_all = FALSE)
seqs <- data.frame(accver = c("A", "B"), length = 100)
hits <- data.frame(
  qaccver = "A", saccver = "B", qstart = 1, qend = 20,
  sstart = 40, send = 21
)
once <- clean_ggchord_data(seqs, hits)$ribbon_data
stopifnot(identical(clean_ggchord_data(seqs, once)$ribbon_data, once))
p <- ggchord(seq_data = seqs, ribbon_data = hits) +
  geom_alignment_segment(aes(qstart = qend, qend = qstart, link_linewidth = qstart)) +
  coord_dotplot()
export_ggchord_layout(p)$alignment[c("qstart", "qend")]
ggplot2::ggplot_build(p)$plot$scales$get_scales("link_linewidth")$range$range
```

## 预检、读入与结果报告

| 情形 | 当前行为 |
| --- | --- |
| 注释或命名集合的单位与骨架冲突 | bp 骨架加 aa 区间时，直接预检和准备报告均判无效。绘图入口拒绝该组合 |
| 注释方向、统一输入和映射顺序 | 显式映射的 reverse 可生成负链。若声明的链与方向冲突，预检返回问题 |
| 统一注释清洗报告 | 终点由 120 裁到 100 时，改动记在 feature，打印摘要显示 `feature_data` 行数 |
| GFF3 未知链和教学展示链 | 按已确认的兼容策略，默认转换为正链时提示该文件受影响的数量。真实数据教学显式取来源链，使用 `unstranded = "keep"` 可以保留未知链 |
| BigWig 空选择 | 开启来源追踪后，结果仍为零行且保留字符型 `.source_file` |
| Dotplot 缓存和公式形式的图层数据 | 同一设备在构建后可用 `get_chord_layout(p, build = FALSE)` 取得缓存，设备尺寸改变后缓存失效。单边公式可以筛选图层数据 |

## 调用成本和源码职责

- 100 个互不重叠的通用特征，以前做了 4,950 次成对重叠检查再丢弃结果，现在为 0 次。精确重复和范围校验继续执行。这个计数仅适用于通用特征路径。
- 在收集图例的双面板 Fusion 示例中，一次导出的原生轨道统计从 6 次降到 1 次。仍有 12 次面板上下文计算、12 次单布局计算和 30 次图层输入解析。新的独立渲染会重新读取函数提供的数据。上述数字描述该输入的调用路径，不能换算为整包提速倍数。
- FASTA 按 8,192 行分块读取。在跨块记录、空记录、gzip、保留字符和仅取长度的用例中核对了长度和来源行号。MAF/chain 仍会同时保留解码结果和原始文本，内存取舍见[导入索引](../../website/zh/formats.md#reader-results)。
- 限制位点目录读取、图层构造、标签布局分别归入 `R/restriction-sites.R`、`R/geom-restriction-site.R`、`R/layout-restriction.R`。图层输入和角色映射归入 `R/layer-input.R`。普通与 Dotplot 布局共用设备缓存写入规则。
