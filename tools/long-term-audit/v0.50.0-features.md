# 特征分道与子集标签的定向核验

2026-11-18，在 v0.50.0 分支用固定标签、避让标签、圆形坐标、直线坐标与固定量尺分面核对图层输出。观察量取自 `export_ggchord_layout()` 中的 `feature` 和 `labels` 表；分面的最终绘制另经 `ggplot_build()` 和 gtable 检查。

## 输入、锚点和显示实例

```r
library(ggplot2)
library(ggchord)
reference <- data.frame(accver = "A", length = 1000)
features <- data.frame(
  accver = "A", start = c(100, 150, 600), end = c(400, 200, 700),
  strand = "+", feature_id = c("a", "b", "c"), type = c("outer", "inner", "other")
)
captions <- features[c(3, 2), ]
captions$text <- c("third", "second")
p <- ggchord(reference) +
  geom_seq() +
  geom_feature(data = features, id = "features", shape = "block",
               position = position_feature_stack()) +
  geom_feature_label(aes(label = text), data = captions, id = "labels",
                     anchor_layer = "features", placement = "repel") +
  coord_circular()
export_ggchord_layout(p)$labels
```

父层先给 a、b、c 分道，再按标签输入顺序选 c、b。固定与避让方式均导出 c 的文字 third 和 b 的文字 second。两个源锚点分别为 650、175。c 在道 0，b 在道 1，两个标签的 `normal_offset` 分别等于所属父特征。更换圆形与直线坐标后，均与该坐标下的实体一致。向两种顺序不同的长表分别添加 S1、S2 的相同特征后，两个面板各有 c、b 两个标签，来源、父层、道号和面板逐项对应。仅有一个匹配层时可省略 `anchor_layer`。

同一源参考 A 在直线布局中以 `layout_sequences(order = c(left = "A", right = "A"))` 展示两次。为 b 的标签指定已有列 `display_instance_id = "right"`，仅右侧实例出现此标签。导出保留 A、right、b 和父层 ID。圆形坐标沿用单一序列实例的契约。

多个兼容特征层会列出候选 ID。显式选择其中一层后，另一层的几何独立绘制。不存在的父层、指定父层中缺少实体、同一实体键的端点有冲突、同时指定 `anchor_layer` 和独立 `position` 都有错误诊断。没有匹配父层的独立标签使用其合法来源区间。无 `feature_id` 的完整同源表仍按原始行序匹配；两张独立输入仅端点巧合时不会自动跟随。

## 多段注释及形状对照

另使用随包 `flagship_circular_example$dense$features` 的 20 条既有区间，将已有唯一 `match_id` 指为 `feature_id`。从完整父层只取第 14 行（2 个来源段）和第 4 行（1 个来源段）标注，并按 14、4 重排。每条母记录各有一个标签，保留两个源端点和实际道位。用 `geom_feature(preset = "plasmid")` 绘制全表，又将同一表显式交给 `geom_feature(shape = "marker")`，分别核对标签与对应实体的法向偏移。marker 是这里选用的显示形状；源表原始类别、分段与 ID 均保留。

## 三项入口迁移

| v0.50.0 删除的入口 | 本版写法 | 保留的行为 |
| --- | --- | --- |
| `geom_gene()` | `geom_feature(preset = "gene")` | 默认表筛选 gene 与 CDS，显式数据逐行绘制，要求明确的正负链，沿用有向箭头及其默认样式。 |
| `geom_feature_plasmid()` | `geom_feature(preset = "plasmid")` | 紧凑的默认位置、宽度、领域形状和填色。显式映射、固定形状和宽度仍可覆盖默认值。 |
| `geom_feature_label_repel()` | `geom_feature_label(placement = "repel")` | 继续使用同一避让算法。原布局参数 `placement` 改用 `label_layout`，原拟合参数 `label_fit` 改用 `overflow`。固定标签继续使用默认的 `placement = "fixed"`。 |

避让布局支持 feature、radial、auto、callout。拟合模式支持 wrap、none、ellipsis、auto、shrink。选择 shrink 时，按已有算法优先尝试特征内部。引导线、括号计数、字号下限和外置标签保留原参数。基因预设在定向探针中从默认输入选择 gene/CDS，显式输入保留两行，显式矩形覆盖箭头，未知链得到诊断。上述核验覆盖所列的锚点、顺序和来源关系。任意第三方 Position 的特定布局仍须按实际数据验证。
