# v0.50.0 公开 API 拟去向

## 0.50.0 开发分支的实际去向

本次从基线的 158 项导出切换为 160 项。下方原始逐名清单用于核对设计覆盖面；当前可运行的函数及参数以 [NAMESPACE](../../NAMESPACE)、[汉语迁移表](../../MIGRATION-Hans.md)和[函数帮助](../../man)为准。

| 变更 | 当前入口 |
| --- | --- |
| 移除五项旧导出 | `geom_gene()`、`geom_feature_plasmid()` 由 `geom_feature(preset = ...)` 承担。`geom_feature_label_repel()` 并入 `geom_feature_label(placement = "repel")`。`position_plasmid()` 改为 `position_offset()`。`position_track()` 改为用加号声明 `track_band()`、图层按 ID 引用。 |
| 新增七项导出 | `track_band()`、`position_offset()`、`layout_sequences()`、`stat_coverage()`、`guide_seq_axis()`、`guide_track_axis()`、`shared_track_limits()`。 |
| 同名函数改变参数归属 | `ggchord(data, mapping = NULL)` 从参考或准备结果起图。全图排序、方向、间距和等长策略移到 `layout_sequences()`。轴的选择移到 guide。起始位置与增道方向分别指定。 |
| 继续保留的领域语义 | 基因、引物的专有标签行为以及用于独立训练的角色标度保留。标准 fill/colour 已用于核对特征、轨道、连接和 Dotplot，固定样式与独立轨道标度有实图对照。 |


清点以分支起点 `aa66b96c` 的 [NAMESPACE](../../NAMESPACE) 为基线。以下清单的第一列逐名登记现有导出，每名只出现一次。用户已确认直接切换。具体去向、替代签名和作用域语法仍待设计评审。获批实现时直接移除获准退役的名称和参数，将替代调用及删除版写入迁移指南和 NEWS。目标工作流和边界见[设计总表](v0.50.0-design.md)。

2026-11-18 复审补入了基础用例和迁移前提。标为“初稿”的写法保留用来辨认方案演变，标为“建议”的写法待确认。现行代码的观察结果见[引擎审计](v0.50.0-engine.md)，最短调用与旗舰图对照见[工作流](v0.50.0-workflows.md)。

领域构造器核对参数全名，包括 R 通常会部分匹配的 `dat` 和 `pos`。基本样本分面支持 `facet_wrap(vars(sample))` 或 `facet_grid(rows = vars(batch), cols = vars(sample))`，使用预先准备的样本列和固定尺度。`layout = 2L` 在全图面板编号中选择面板，统计、绘制和阶段导出使用相同的归属。共享参考可跨面板重复，重复观测需有带样本键的输入记录。[面板选择和来源](v0.50.0-statistics.md)

## 构图、数据与视图

| 现有导出 | 拟去向及契约 |
| --- | --- |

| `prepare_ggchord_data`、`adapt_ggchord` | 保留准备与对象适配。显式映射先于清洗和方向预检，交接保留单位、源表与来源证据。 |
| `as_ggchord_seq`、`as_ggchord_feature`、`as_ggchord_link`、`as_ggchord_alignment` | 保留各表的领域转换与字段契约。分别验证单位、标识、方向及来源。 |

| `focus_ggchord_data`、`segment_ggchord_data`、`focus_ggchord_track` | 保留源数据筛选、分段和轨道裁剪。复用窗口身份、边界和来源规则。轨道裁剪保留原观测及值，重新统计由新统计流程显式指定。 |
| `find_ggchord_loci`、`find_common_features`、`link_ggchord_clusters` | 保留源区间查找、共同注释识别及按显式簇成员关系构造链接。 |

| `diagnose_ggchord`、`view_ggchord` | 保留指定尺寸的诊断和静态预览。正式保存使用上游 `ggplot2::ggsave(plot = p, ...)`。 |
| `ggchord_fusion`、`fusion_panel`、`fusion_ribbon`、`magnify_ggchord`、`export_ggchord_fusion` | 保留组合、子面板登记、真实跨面板区间、显式放大和组合导出。现有图例收集继续仅排版和去重，训练域关联通过显式标度作用域表达。放大继续基于真实源区间、投影及面板尺寸。 |
| `register_ggchord_alignment`、`map_alignment_position` | 保留真实比对的注册与查询，包括反向、缺口、对齐列与源位置。HSP 汇总使用自己的粒度与来源。 |
| `build_ggchord_cds`、`project_ggchord_features`、`project_ggchord_links`、`translate_ggchord_cds` | 保留已有 CDS 模型、坐标转换和字符教学入口。沿用分段、方向、phase、遗传密码与 bp/aa 单位契约。 |
| `bundle_ggchord_ribbons`、`deduplicate_ggchord_ribbons`、`filter_ggchord_ribbons`、`merge_ggchord_ribbons` | 保留直接得到表及报告的合并、去重和筛选。各函数继续沿用缺少源 ID 时的规则。绘图统计复用表处理与来源记录。 |

| `read_bed`、`read_bedgraph`、`read_bedpe`、`read_bigwig`、`read_vcf` | 保留格式入口及来源。转换时明确 0-based 与 1-based；信号单位继续显式填写。 |

| `find_restriction_sites`、`filter_restriction_sites`、`find_primer_bindings`、`primer_catalog` | 保留注释来源接口及表契约。入口整理延后，绘图层继续接收注释表。 |

## Geom、Stat、Position 与物理轨道

| 现有导出 | 拟去向及契约 |
| --- | --- |
| `geom_seq`、`geom_seq_break`、`geom_seq_region` | 保留骨架、显式断点和区间高亮。数据角色统一分派，断点外观与源窗口切分可独立指定。 |
| `geom_seq_label`、`geom_seq_center_label`、`geom_seq_scale` | 保留骨架标签、圆心标签和独立长度比例尺。独立长度参照可与领域轴共存。 |
| `geom_gene`、`geom_feature`、`geom_feature_plasmid` | 拟退役第一及第三个名称，统一使用通用特征层。旧基因层迁为显式选取的 gene/CDS 表与基因预设，旧质粒层迁为通用特征表与质粒预设。筛选、已知链验证、形状及样式分别验收。 |
| `geom_gene_label`、`geom_feature_label`、`geom_gene_label_repel`、`geom_feature_label_repel` | 拟用通用标签层及 `placement = "fixed"` 或 `"repel"` 表达文字布局。复审建议在来源、特征键及显示实例唯一时自动跟随。显式指定目标有初稿 `position_follow(layer = ...)` 与候选 `anchor_layer = ...` 两种方案，待择一。需核对手动对齐、引线、隐藏与溢出。 |
| `geom_primer`、`geom_primer_label_repel`、`geom_restriction_site` | 保留引物和位点几何；引物避让标签拟迁入通用标签入口的引物预设。复用标签布局时单独核对引物身份、链、坐标及原有标注行为。 |
| `geom_link_line`、`geom_link_ribbon` | 保留点连线与区间连带。几何保留固定样式、分支、尖端、曲率与路由；分箱与汇总由统计完成。 |
| `stat_ribbon_bundle`、`stat_ribbon_density` | 保留可加的领域统计入口及计算变量。Geom 的 `stat = "ribbon_bundle"` 或 `"ribbon_density"` 通过同一统计注册表选取，与从 Stat 入口选择 geom 共用一套参数检查和计算。实施时移除 Geom 内逐名硬编码的分支。验证减少行数与保留逐条连接的不同契约。 |
| `geom_alignment_segment` | 保留 HSP 四端点和身份。增设 `stat_alignment_bin2d()` 配合 `geom = "alignment_tile"` 表示源坐标格子，每格可查回所用 HSP。 |
| `geom_residue` | 保留字符/瓦片、折行、缺口、真实位置与溢出策略。 |
| `geom_track` | 保留源空间内置 ggplot2 geom/stat/数据 Position 组合，轨道声明独立交给 `track_band()`。统计先于数据位置与投影。 |
| `geom_track_bar`、`geom_track_col` | 计数柱及已给高度的柱分别默认 count 和 identity。候选 `stat_coverage(data = intervals, binwidth = 250)` 默认把区间并集覆盖率画成柱。其几何入口 `geom_track_col(stat = "coverage", ...)` 应共用同一 Stat。换 `geom = "track_line"` 时核对各窗、分组、分母与贡献记录。现行覆盖入口见下面的轨道对照。 |
| `geom_track_line`、`geom_track_tile` | 保留严格递增位置、NA 分段、圈缝控制的折线路径及铺满闭区间的瓦片路径。只有等价验证后才归并具体实现。 |
| `position_track` | 拟直接移除旧物理带构造器。具名带或自定义毫米宽度用 `+ track_band(id, ...)` 声明，图层用 `track = id` 引用。复审建议单轨可省略声明和引用，省略的层共享默认带；新增具名带时既有默认带保持原位。显式写出的未知名称应提示候选，例如已声明 `depth` 却写作 `deph`。初稿曾考虑遇新名字自动建带，此取舍待确认。数据位置继续使用支持的 dodge、nudge 或 identity。 |
| `position_strand`、`position_plasmid` | 保留 `position_strand(offset)` 的链相关位置。共享的局部法向偏移迁为 `position_offset(offset)`，移除质粒专名和同义简写 `"plasmid"`。继续接受既有逐序列偏移。 |
| `position_feature_stack` | 删除旧 `side`，以 `base_position`、`direction` 明确指定。迁移时保留历史 inside/outside 的实际起点与增道方向。同图跟随优先接入，跨面板复用道号待场景验证。 |

## 六种使用场景的迁移核对

| 场景 | 当前的代表性调用 | 拟议迁移及比较结果 |
| --- | --- | --- |
| 多序列弦图 | `ggchord(seqs, links) + geom_seq() + geom_link_ribbon() + coord_chord()` | 构造器直接接收准备结果。可用 `+ layout_sequences(...)` 显式统一序列次序、方向和锚点；`coord_chord()` 继续投影。比对源序列对、端点、已有用户标度及默认几何。 |
| 单序列圆图 | `geom_feature_plasmid()`、`coord_circular()` 与 `scale_seq_position_continuous(sequences = ...)` | 改用单一特征层入口的质粒预设。位置轴的显示选择由 `guide_seq_axis()` 表达，标度继续决定刻度。比较跨起点特征、正反方向、既有标签和引线，以及隐藏某轴时仍保留骨架。 |
| 共线性与分道跟随 | `geom_feature(position = position_feature_stack(...))`，标签可根据现有规则匹配形状层 | 重叠特征仍用 `position_feature_stack()`。建议唯一可匹配时标签沿用特征位置，多个合法锚点时再选择目标。比较筛选标签前后的道号、锚点、来源及正反 orientation，明确重复或未匹配身份的处理。 |
| 密集双轴 Dotplot | `geom_alignment_segment() + coord_dotplot()` | 可用 `stat_alignment_bin2d(..., geom = "alignment_tile")` 填格并叠加原始线。验收多个序列对、轴反转、轴间隙、边缘归属、绝对格计数及源 HSP。当前连带密度的序列对内归一结果继续供原图层使用。 |
| 多样本定量轨道 | `geom_track_bar(stat = "coverage", binwidth = 4, track = position_track("coverage"))` | 初稿展示逐条具名声明。复审建议单轨默认放置；多组共享一条带时可用长表和 `aes(group = sample)`，多条独立带时再具名。轴按需定制。核对短末窗、空窗、重叠深度、并集、裁剪和来源。显式 `windows` 候选另验收跨样本共用源窗口与局部重新统计的结果。 |
| 总览加局部 Fusion | `magnify_ggchord(overview, region, detail)`，或 `ggchord_fusion(overview, guides = "collect") + fusion_panel(detail, id = "detail")` | 保留两种组合形式。通过待定的作用域选择真正可比较的样本与量纲，再复用原生 scale 与 guide。比较总览与局部源区间、连接前端、原图例位置语义，以及不同单位的标度独立性。 |

轨道的宽度和位置调整可分别迁移。设 `prepared` 为当前准备函数输出，`events` 为含 `accver`、`pos`、`sample` 的点表。上游 dodge 的宽度以源坐标单位计，轨道宽度以 mm 计。旧例沿用 v0.29.0，后例是设计写法。

```r
ggchord(prepared) +
  geom_seq() +
  geom_track_bar(
    ggplot2::aes(group = sample), data = events,
    track = position_track("events", width = grid::unit(4, "mm")),
    position = ggplot2::position_dodge(width = 10)
  ) +
  coord_collinear()

ggchord(data = prepared, mapping = ggplot2::aes()) +
  track_band("events", width = grid::unit(4, "mm")) +
  geom_seq() +
  geom_track_bar(
    ggplot2::aes(group = sample), data = events, track = "events",
    position = ggplot2::position_dodge(width = 10)
  ) +
  coord_collinear()
```

分道直接从旧 `side` 迁为基准与方向。旧 `outside` 改成 `position_feature_stack(base_position = position_offset(-0.1), direction = "inward")`，旧 `inside` 改成偏移 `0.1` 和 `direction = "outward"`，旧 `strand` 改成 `base_position = position_strand(0.1), direction = "auto"`。这些偏移沿用已有物理语义。 [现有分道对照](v0.29.0-layer-grammar.md#起始位置与后续道方向)

旧 `scale_ribbon_fill_gradientn(colours = c("grey90", "steelblue"))` 拟迁至原生 `ggplot2::scale_fill_gradientn()`。若多个图层的 fill 各有不同含义，例如一层表达注释类别、另一层表达连续相似度，再显式限定需要独立训练的作用域。Fusion 联动域需明确参与面板。具体绑定语法待定，训练标度仍保留用户值、缺失值和显式 guide 的优先级。

## 特征、标签与标度的直接替代

统一注释表中，当前基因层按首个存在的 `feature_class`、`type`、`role` 字段选 gene/CDS，匹配前去空白并统一大小写。旧构造器的 `gene_data` 已表示要用的整张表，迁入新签名时直接作为所选基因表。显式输入保留已知正负链要求及来源记录，其他类型和未知链继续可交给通用特征层。现有基因外观包括箭头及默认链着色。质粒预设负责紧凑带、箭头尺寸、分段边界和默认分道；显式固定样式、位置或映射由调用者决定。 [基因数据选择](../../R/annotation-input.R) · [现有基因签名](../../R/geom-gene.R) · [现有质粒预设](../../R/geom-feature.R)

下面保留初稿中显式绑定的写法。`genes` 是按上述规则选择的表，`label_rows` 是其中有名称且需标注的子集，带有相同的源特征身份。图层命名、预设及绑定语法均待确认。

```r
p +
  geom_feature(
    data = genes, preset = "gene", id = "genes",
    position = position_feature_stack(
      base_position = position_strand(0.1),
      direction = "auto"
    ),
    inherit.aes = FALSE
  ) +
  geom_feature_label(
    ggplot2::aes(label = anno), data = label_rows,
    placement = "repel", position = position_follow(layer = "genes"),
    inherit.aes = FALSE
  )
```

- 固定标签与避让标签分别拟用 `placement = "fixed"` 和 `placement = "repel"`。复审建议在来源、实体键及当前面板的显示实例都能唯一匹配时省略目标；筛选、重排标签后仍沿用该实体层的道位。有合法源区间的独立标签可以自行定位。同一实体画了两遍、同一来源跨多个窗口等情况报告歧义，并列出候选层或实例。两条序列上的同名文字不能当作共同身份。
- 对显式指定目标，复审倾向在标签层写 `anchor_layer = "genes"`（候选名），保留 `position` 给标签自己的位置调整。初稿的 `position_follow(layer = "genes")` 则由 Position 负责跟随。两种写法待择一。就算指定了目标层，层内仍需按来源键和显示实例匹配到具体特征。标签层负责文字的避让、隐藏与引线。
- 旧 `geom_feature_plasmid(data = annotations)` 拟改用 `geom_feature(data = annotations, preset = "plasmid")`。`position_offset(-0.1)` 是在需要显式声明原共享带时的替代。保留循环方向和跨起点特征的结果。
- 拟保留 `inherit.aes = FALSE` 隔离全局映射。多表入门例把序列颜色写到 `geom_seq(aes(colour = accver))`，连接层读取自己的 `pident`。显式层表优先，包括保留列名的零行表；准备对象中只存在一张合格表时可自动取用，同时存在 `cds` 和 `repeats` 时应提示 `data = prepared$features$cds` 等明确写法。
- 映射优先级待按两种情况核对。图级 `aes(colour = accver)` 和层内 `geom_seq(colour = "black")` 同时出现时，建议该层以黑色绘制且不贡献颜色映射键，兄弟层可继续按序列着色。同一层内又映射又显式固定同一项，建议报告冲突。候选默认 `show.legend = NA` 由映射决定，用户可显式开启、关闭或按 aesthetic 选取图例。 [原生图层契约](https://ggplot2.tidyverse.org/reference/layer.html)
