# v0.50.0 公开 API 拟去向

清点以分支起点 `aa66b96c` 的 [NAMESPACE](../../NAMESPACE) 为基线。以下清单的第一列逐名登记现有导出，每名只出现一次。用户已确认直接切换。具体去向、替代签名和作用域语法仍待设计评审。获批实现时直接移除获准退役的名称和参数，将替代调用及删除版写入迁移指南和 NEWS。目标工作流和边界见[设计总表](v0.50.0-design.md)。

## 构图、数据与视图

| 现有导出 | 拟去向及契约 |
| --- | --- |

| `geom_track_line`、`geom_track_tile` | 保留严格递增位置、NA 分段、圈缝控制的折线路径及铺满闭区间的瓦片路径。只有等价验证后才归并具体实现。 |
| `position_track` | 迁移至独立的 `+ track_band(id, ...)` 及图层的 `track = id`。直接移除旧位置构造器及旧写法。数据位置继续接受上游已有的 dodge、nudge 或 identity 等支持组合。 |

## 六种使用场景的迁移核对

| 场景 | 当前的代表性调用 | 拟议迁移及比较结果 |
| --- | --- | --- |
| 多序列弦图 | `ggchord(seqs, links) + geom_seq() + geom_link_ribbon() + coord_chord()` | 构造器直接接收准备结果。可用 `+ layout_sequences(...)` 显式统一序列次序、方向和锚点；`coord_chord()` 继续投影。比对源序列对、端点、已有用户标度及默认几何。 |
| 单序列圆图 | `geom_feature_plasmid()`、`coord_circular()` 与 `scale_seq_position_continuous(sequences = ...)` | 改用单一特征层入口的质粒预设。位置轴的显示选择由 `guide_seq_axis()` 表达，标度继续决定刻度。比较跨起点特征、正反方向、既有标签和引线，以及隐藏某轴时仍保留骨架。 |
| 共线性与分道跟随 | `geom_feature(position = position_feature_stack(...))`，标签可根据现有规则匹配形状层 | 重叠特征的形状层仍用 `position_feature_stack()`，标签层显式用 `position_follow(layer)`。比较筛选标签前后的道号、锚点、来源及正反 orientation，明确重复或未匹配身份的处理。 |
| 密集双轴 Dotplot | `geom_alignment_segment() + coord_dotplot()` | 可用 `stat_alignment_bin2d(..., geom = "alignment_tile")` 填格并叠加原始线。验收多个序列对、轴反转、轴间隙、边缘归属、绝对格计数及源 HSP。当前连带密度的序列对内归一结果继续供原图层使用。 |
| 多样本定量轨道 | `geom_track_bar(stat = "coverage", binwidth = 4, track = position_track("coverage"))` | 声明 `+ track_band("coverage", ...)`，再用 `stat_coverage(binwidth = 4, geom = "track_col", track = "coverage")`。用 `guide_track_axis()` 显式指定领域数值轴。保留短末窗、空窗、重复深度、覆盖并集、裁剪及来源。显式 `windows` 候选另验收跨样本共用源窗口，以及保留原统计值与局部重新统计的不同结果。 |
| 总览加局部 Fusion | `magnify_ggchord(overview, region, detail)`，或 `ggchord_fusion(overview, guides = "collect") + fusion_panel(detail, id = "detail")` | 保留两种组合形式。通过待定的作用域选择真正可比较的样本与量纲，再复用原生 scale 与 guide。比较总览与局部源区间、连接前端、原图例位置语义，以及不同单位的标度独立性。 |

轨道的宽度和位置调整可分别迁移。设 `prepared` 为当前准备函数输出，`events` 为含 `accver`、`pos`、`sample` 的点表。上游 dodge 的宽度以源坐标单位计，轨道宽度以 mm 计。旧例沿用 v0.29.0，后例是设计写法。

```r
ggchord(prepared) +
  geom_seq() +
  geom_track_bar(
    ggplot2::aes(group = sample), data = events,
    track = position_track("events", width = grid::unit(4, "mm")),
    position = ggplot2::position_dodge(width = 10)
  ) +
  coord_collinear()

ggchord(data = prepared, mapping = ggplot2::aes()) +
  track_band("events", width = grid::unit(4, "mm")) +
  geom_seq() +
  geom_track_bar(
    ggplot2::aes(group = sample), data = events, track = "events",
    position = ggplot2::position_dodge(width = 10)
  ) +
  coord_collinear()
```

分道直接从旧 `side` 迁为基准与方向。旧 `outside` 改成 `position_feature_stack(base_position = position_offset(-0.1), direction = "inward")`，旧 `inside` 改成偏移 `0.1` 和 `direction = "outward"`，旧 `strand` 改成 `base_position = position_strand(0.1), direction = "auto"`。这些偏移沿用已有物理语义。 [现有分道对照](v0.29.0-layer-grammar.md#起始位置与后续道方向)

旧 `scale_ribbon_fill_gradientn(colours = c("grey90", "steelblue"))` 将由原生 `ggplot2::scale_fill_gradientn()` 加明确的连带作用域表达。轨道 scope 允许分离单图中的相同 aesthetic，Fusion 联动域则需显式列出参与面板。具体绑定语法待定，训练标度仍保留用户值、缺失值和显式 guide 的优先级。

## 特征、标签与标度的直接替代

统一注释表中，当前基因层按首个存在的 `feature_class`、`type`、`role` 字段选 gene/CDS，匹配前去空白并统一大小写。旧构造器的 `gene_data` 已表示要用的整张表，迁入新签名时直接作为所选基因表。显式输入保留已知正负链要求及来源记录，其他类型和未知链继续可交给通用特征层。现有基因外观包括箭头及默认链着色。质粒预设负责紧凑带、箭头尺寸、分段边界和默认分道；显式固定样式、位置或映射由调用者决定。 [基因数据选择](../../R/annotation-input.R) · [现有基因签名](../../R/geom-gene.R) · [现有质粒预设](../../R/geom-feature.R)

下面的 `genes` 是按上述规则选择的表，`label_rows` 是该表中有名称且需标注的记录，携带与形状层相同的源特征身份。图层注册参数名称和 `preset` 值是待确认的示意。

```r
p +
  geom_feature(
    data = genes, preset = "gene", id = "genes",
    position = position_feature_stack(
      base_position = position_strand(0.1),
      direction = "auto"
    ),
    inherit.aes = FALSE
  ) +
  geom_feature_label(
    ggplot2::aes(label = anno), data = label_rows,
    placement = "repel", position = position_follow(layer = "genes"),
    inherit.aes = FALSE
  )
```

- 旧基因或特征固定标签改用 `placement = "fixed"`。旧两类避让标签改用 `placement = "repel"`。两种文字布局都可按明确的目标层寻找锚点。输入过多时的隐藏、缩小及引线策略仍由标签层控制。
- 旧 `geom_feature_plasmid(data = annotations)` 拟改用 `geom_feature(data = annotations, preset = "plasmid")`。`position_offset(-0.1)` 是在需要显式声明原共享带时的替代。保留循环方向和跨起点特征的结果。
- 旧数据 Geom 显式置 `inherit.aes = FALSE` 可恢复映射隔离。旧默认显示或隐藏图例的层分别使用 `show.legend = TRUE` 或 `FALSE`；新默认 `NA` 由映射决定。固定值与显式局部映射优先于全局同名映射的位置须在六种场景中核对。 [原生图层契约](https://ggplot2.tidyverse.org/reference/layer.html)

```r
scope_scale(

    guide = ggplot2::guide_colourbar(
      theme = ggplot2::theme(legend.key.height = grid::unit(4, "mm"))
    )
  ),
  layer = "ribbons"
)
```

骨架、基因/特征、区域、连接线、连接带和轨道各先使用规范 aesthetic（如 `fill`、`colour`、`alpha`、`linewidth`）。同一 aesthetic 的作用域按注册身份绑定，手动颜色、离散 shape、连续 gradientn、分段 stepsn 与 identity 分别调用对应原生标度。旧 `color` 包装器的写法也迁至同一 `colour` 标度。共享 Fusion 标度时，先明确相同量纲、计算粒度和变换，再决定共同域和 guide；同名标题只提供显示信息。 [既有 Fusion 图例语义](../../website/zh/fusion.md#shared-guides) · [现有 guide 包装实现](../../R/guides.R)
