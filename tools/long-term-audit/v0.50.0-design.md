## 对象和数据的所有权

| 对象 | 保存什么 | 生命周期和冲突处理 |
| --- | --- | --- |
| 图与数据 | 一个序列参照表以及可选的具名点、区间、双端连接、对齐等关联表。序列主键为 accver。 | 输入普通序列表或准备好的多表对象。两张同类表都有资格成为默认来源时要求显式选择；不依赖列表先后。 |
| 图层 | 单独的 id、源表、aes、stat、position、geom 与可选的轨道 ID。 | 具名 id 在图内唯一，重复即报错。省略生成图内标识，仅供本次查询。跨层依赖用显式 id。同一图层对象加两次可独立求值及导出。 |
| 来源及显示身份 | 数据源、原始行或持久特征键、分段、窗口、分组、统计行、面板与显示实例分别登记。 | 行号只在一份确定的输入中有效。跨子集引用优先用可验证的稳定键；不能用名字、颜色或行号巧合建立关系。 |
| 序列布局与轨道 | 每条骨架的顺序、方向、相对位置和局部法向；轨道的侧别、顺序与物理尺寸。 | 同一个轨道 ID 只解析到一种带宽和单位。两个图层引用它可各用不同数据。显式轨道或骨架定义冲突时报出声明位置。 |
| 分面、坐标、组合 | 分面按变量复制同一语法，坐标决定投影，Fusion 组织多张独立图及跨面板端点。 | 每个面板有自己的布局、度量和标度训练范围。显式声明跨面板的共享范围。视口裁剪只改变可见部分；数据聚焦、裁剪原统计、重新分窗是独立操作。 |
| 计算与绘制结果 | 每层的原表、角色映射、统计值、位置或道号、可见几何、诊断和来源关系。 | 直接查询可以只计算所需阶段。有些原生层无法提供中间表，应给出阶段状态及原因。失败的构建不得成为下一次导出的缓存。 |

**数据解析。** `data = NULL` 对领域层选择与输入种类匹配的默认表。显式数据优先。函数或公式作用于该层原本会得到的表，每次独立绘制求值一次。普通 ggplot2 层遵守原生图数据与 Layer 行为。每个角色的表达式都对同一份输入求值。图层同名映射覆盖图级映射；继承了不存在的列时报告表、层与列。对于多个无公共列的表，可明确 `inherit.aes = FALSE`。分面变量来自源表，缺少时须在契约中明确是公共骨架重复显示，还是必须提供样本键的观测层，避免把观测无意复制到每组。

**单位与方向。** 公开序列区间采用一基闭区间。位置 1 的单碱基显示边缘为 0 与 1，统计分母为 1。bp 与 aa 由来源声明；跨单位比较须有已登记的投影。正反链、连接的 q/s 端点原序、骨架显示方向、圆图顺逆时针各有含义。角度、源坐标、局部法向偏移和设备 mm 各自使用命名参数。反转视图后仍可查回原始端点。对环状起点及多段输入，交给统计前须能确定真实各段及其母记录；缺少依据时报告需拆段，不能填满包围盒。

## 目标函数目录与候选签名

以下表示可供评审的调用契约，省略号代表经声明的附加参数。参数名为候选。各旧导出的落点以[清单](v0.50.0-api-inventory.md)为准。命名遵循“用户在选择什么”的原则。领域统计采用动词或量名，图形预设只有在能说明独立用途时才保留。

| 拟议入口 | 输入、返回和可组合行为 |
| --- | --- |
| `ggchord(data, mapping = NULL, ..., validate = "warn")` | 返回可加图层的图。序列参照独立于是否画骨架。必需键、长度、单位和引用完整性属于结构约束。用户可选的警告级别只调整质量诊断。 |
| `layout_sequences(order = NULL, orientation = NULL, gap = NULL, length_mode = "proportional", ...)` | 可加的布局声明。承接序列间共同排布；单条骨架的线宽、颜色、双线仍由 geom 决定。按 accver 命名的逐序列设置可重排。Dotplot 的双轴域分别声明。 |
| `track_band(id, side = "outside", order = 1, width = NULL, gap = NULL, ...)` | 可加的物理带；NULL 交给布局解析统一默认尺寸，显式宽度必须为正、间隔非负。geom 以 `track = "depth"` 引用；即使引用先于带声明，也在编译整图时解析。候选简写允许未声明的 ID 使用统一默认带，遇到自定义尺寸须有唯一声明。 |
| `geom_*(mapping = NULL, data = NULL, stat = ..., position = ..., ..., id = NULL, na.rm = FALSE, show.legend = NA, inherit.aes = TRUE)` | 数据图层的公共骨架，geometry-specific 参数按名称。Geom 声明所需角色、接受的统计结果、默认样式和图例键。独立比例尺、轨道声明、主题没有意义相同的 stat 参数。 |
| `geom_feature(..., shape, width, preset)`、`geom_feature_label(..., placement, overflow)` | 统一区间与标签入口。用数据选择确定哪些行是基因，用形状或预设表达如何画。支持同一份数据画箭头、块或文字。标签的固定/避让、候选位置、放不下时的处理与跟随哪一个特征层分别定义。 |
| `position_offset(offset)`、`position_strand(offset)`、`position_feature_stack(base_position, direction, spacing)`、`position_follow(layer, ...)` | 分别表达固定法向偏移、按链起步、重叠区间分道及跟随另一层。`layer` 引用 `id`。历史 inside/outside 名字按旧偏移的实际符号迁移，随后移除。在轨道上的普通数据 dodge 仍用 ggplot2 的位置对象。 |
| `stat_coverage(mapping = NULL, data = NULL, geom = "track_col", position = "identity", ..., binwidth = NULL, windows = NULL, track, id = NULL)` | 返回可加的层，同一 Stat 可由 `geom_track_col(stat = "coverage", ...)` 调用。统一提供图例、继承和缺失值参数。窗宽和显式窗口表二选一。结果可映射为柱高、线高或颜色。 |
| `stat_alignment_bin2d(..., binwidth, geom = "alignment_tile")`、`geom_alignment_tile(..., stat = "identity")` | 每条 HSP 以 q/s 中点各归一格，按有序序列对分组。输出源空间的四条格边、格计数与来源。已有格表可直接画色格；原始 HSP 明细可另加独立的线段层。 |
| `stat_ribbon_bundle(...)`、`stat_ribbon_density(...)`、`geom_link_ribbon(stat = ..., ...)` | 可共用统计构造和输出。束化会改变行数；当前的相对密度保留逐条连接，并依赖序列对内的归一化。连接带中段曲线和引线路由留在几何/布局阶段。 |
| `guide_seq_axis(...)`、`guide_track_axis(...)` | 分别解释沿骨架的源位置和局部轨道数值。由 `scale_seq_position_continuous(guide = ...)` 或 `scale_track_value_continuous(track, guide = ...)` 指定。刻度取值及变换由标度产生，密集刻度的显示、方向和重叠策略由 guide 控制。物理字体由主题或 guide 的局部主题提供。 |
| 普通视觉标度、`scope_scale(scale, layer = ...)`（作用域语法待确认）、`guides()`、`theme_*()` | 简单图直接用 `aes(fill = type)` 加原生标度。需要同时训练独立 fill 时，把标度绑定到明确标识的层、轨道或同一组角色。公共主题与领域主题元素负责外观。 |
| `coord_*()`、`facet_*()`、`ggchord_fusion()` 及布局导出 | 六种现有投影各自声明可消费的角色。一组相同规格的样本图优先验证上游 facet 能力。异构独立子图及双端跨面板连接继续走 Fusion。导出以层和阶段查询，保留适配前后、分组及渲染设备的可追踪关系。 |

**确定参数归属的例子。** 基因是否具有方向和是否属于 CDS 来自输入表，箭头头部大小属于 Geom，分到第几道属于 Position，圆图的零点角度属于 Coord，轨道轴显示百分号由标度标签函数决定。位置相关参数只能进入接受该坐标空间的对象。标准数据层对合适的 Geom 或 Stat 允许从对向入口传参；每个参数在当次组合中只有一个明确接收者。名称不完整、无人接收或同时匹配两个不同含义须报错并指出建议入口。数据缺少必需 ID 或区间次序不合法要报出具体来源；`na.rm` 仅处理该统计声明为可忽略的缺测观测，不把结构错误变成空图。

**精细参数的边界。** 例如 `binwidth` 为有限正整数（bp 或 aa）；显式窗表每行必须有序列键及合法闭端点，重复窗 ID 报错。二维窗宽接受按 query/subject 命名的两个正整数。道间距为正，方向值与骨架取向分别校验。每个数据 Position 都声明可移动的轴；HSP 原始端点保存在来源字段中，禁止拿毫米位移反算新来源。身份列长度必须为 1 或与行数一致；缺少序列、重复键、重复轨道声明的错误列出所属层和输入行。typed 零行表可参与数据流；固定空窗、全 NA 观测、整组缺测和越界裁剪应使导出值与报告彼此一致。

**优先级。** 固定样式用 geom 参数，数据驱动的样式用映射及标度。用户同时显式固定和映射同一项时给出冲突诊断。显式标度优先于推断；图层覆盖图级的同名映射；领域默认排在用户主题和显式样式之后。普通原生层继续采用其上游规则。结构参数允许的具名向量和逐链格式，按身份键解析；美学、guide、主题保持各自的上游参数格式。

## 决定能否组合的具体规则

| 来源 → 统计产物 | 合理的替换 | 必须阻止或区分的情况 |
| --- | --- | --- |
| 点观测 → 事件数、加权计数或分箱 | 同一份计数画柱、点；并排显示各组后仍能反查移动前的成员。 | 点计数和某个位置被多少条区间覆盖的语义不同。 |
| 单序列区间 → 窗口并集及深度 | 柱用完整边缘，线用真实窗中心，铺满带宽的色块用起止边缘。短末窗沿用实际宽度。 | 已给定的窗口均值只有汇总信息。仅裁剪该行时，保留原值和原分母；只有拿到原区间才能对局部窗口重算。 |
| 分组的连续观测 → 五数摘要或密度 | 可用同一组原始记录比较箱线与小提琴。每种新几何单独声明绘制需要的结果列、方向、离群点/归一化与单观测组政策。 | 箱线分位摘要不足以计算密度。沿骨架的采样位置与垂直于骨架的测量轴必须显式区分。列为验证语法的候选，尚无两种图层的实现承诺。 |
| 双端连接 → 原始 HSP、束、相对密度或二维格计数 | 双端点与圆形/直线几何分离；Dotplot 明确双轴，源坐标分箱可与按 HSP 绘制的明细叠加。 | 不以相似度或中点计数推断逐碱基对齐。反转一条显示轴只改图形。 |
| 特征 → 道号 → 标签 | 具名实体层先分道，同源子集按键取已算出的道号和锚点。圆/直线布局分别求物理偏移。 | 同名基因、多个窗口副本、多段或多个合法父层导致歧义时，要求显式实体键/窗口或报错。检查未知引用、自引用和环依赖。 |

固定分箱的手算基准沿用长度 10 的序列，源区间为 3–6、4–5、10–10，窗宽 4。各窗的并集位置数为 2、2、1，平均深度为 0.75、0.75、0.5，贡献行分别为 (1,2)、(1,2)、(3)。显式窗口应要求正整数闭端点、同单位、已知序列、唯一窗键；允许重叠的查询窗口独立统计并标明窗口身份。若用相交窗口画不重叠的分箱柱，会得到覆盖彼此的几何，要选择按窗分面或明确采用叠画。稀疏输入中的显式空窗与未观察到的样本组分别处理，构造完整的实验设计网格必须有输入依据。[基线算例](v0.29.0-layer-grammar.md#区间覆盖与分道实施)

**统计扩展。** 每个领域 Stat 描述输入角色、分组范围、输出列与单位、可追溯关系、缺失及空组政策。以源序列/窗口或 q/s 序列对为外层分区，显式 group 优先，否则采用规定的离散样式分组。来源关系区分一对一、经筛选成员的集合、模型组输入、纯装饰及未知。平滑曲线上的预测点只能报告参与建模的组，不能声称某一行产生了该点。验收时由独立文件中的小型 Stat 新增“每窗相交记录数”并配合两种已有几何画图，核对新列的 `after_stat()`、来源、空组与二次叠层。只允许按接口描述匹配消费能力，无需在总体构图函数内逐一添加 Stat 名字。[ggplot2 扩展指南](https://ggplot2.tidyverse.org/articles/extending-ggplot2.html)

**标度作用域待审方案。** 同一图中显式要求独立的类别 fill 和连续 fill，可用带目标层的原生标度各自训练；叠加的明细和摘要有相同量纲时可引用同一域。解析时先收集作用域，再在各自的源数据、统计值或美学上训练。相同优先级的重叠声明需消除歧义，未知 ID 报错。Fusion 收集图例只决定图例摆在哪里，共享数值域则需要参加面板的量纲、变换、限制、缺失/OOB 政策相容。颜色一样、轴标题一样或最终图例长得一样都不足以证明可比。共享前先用两个范围不相交的深度样本和一个无量纲比例验证训练范围与图例。当原生 ggplot2 无法安全隔离两个同名美学时，比较显式角色美学和绑定适配器两条实现路线；以真正绘制、图例、用户覆盖、after_scale 的一致性决定是否公开暂名 scope_scale。
