# v0.50.0 实图回放与物理标签布局

2026-11-18。以 `cc65de55` 为原版。先在干净源码下启动原版 R 进程，再测试带三处局部优化的当时开发快照。后者另含同期改动，数据、尺寸、设备及四个构图代码块一致。每次运行的输入和 R 源文件 MD5 记录在[取证目录](v0.50.0-render/)。以下是本机开发验证。

## 密集圆图

配方是 `documentation-examples.R` 的 `showcaseplasmiddata` 和 `showcaseplasmid`。它使用随包 pETDuet-1 的 5,420 bp 序列、20 条特征、5 条引物及合并标注的 139 条限制位点来源。两次均使用 ragg 1.5.2 普通 PNG，画布 16.5 × 8 英寸，144 dpi，沿用配方字体和主题。本机通用无衬线字体解析到 Helvetica。[配方](../documentation-examples.R) · [旗舰生成规则](../../data-raw/generate_flagship_data.R)

标准骨架图预热后，密集圆图重绘三次。分别计时构图、`ggplot_build()`、`ggplot_gtable()`、绘制及关设备。各段的中位数以秒计。总计直接取每次整图时间的中位数。

| 阶段 | 原版 | 候选快照 |
| --- | ---: | ---: |
| 构图 | 0.077 | 0.086 |
| build | 2.125 | 2.038 |
| gtable（含物理重算） | 11.231 | 10.548 |
| 绘制及关设备 | 0.122 | 0.120 |
| 完整出图 | 13.523 | 12.693 |

原版三轮为 15.565、13.254、13.523 秒。候选三轮为 14.923、12.658、12.693 秒。整图中位数减少 0.830 秒（6.1%）。四次物理尺寸修正均完成。六张 PNG 的内容一致，同次 gtable 的几何表、标签诊断和图内来源字段一致。两轮分别在独立 R 进程运行；快照含同期改动，整图数据衡量该快照的综合效果。[原版分段时间](v0.50.0-render/baseline.csv) · [候选分段时间](v0.50.0-render/candidate.csv) · [PNG](v0.50.0-render/circular.png) · [布局快照](v0.50.0-render/circular.rds)

原版独立 CPU 采样显示特征标签分道 3.26 秒、字框测量 1.94 秒。候选采样分别为 2.96 秒和 1.70 秒，字框冲突检测由 0.57 降为 0.33 秒。采样包含下层调用且有抖动。局部改动如下。[CPU 采样摘要](v0.50.0-render/cpu.csv)

- 限制位点文字使用与绘制一致的片段度量，跳过随后会被覆盖的通用单字框测量。
- 一条特征标签沿用同一条源角射线。首个通过字形可行性检查的候选才求轮廓锚点，同标签后续候选复用该点。
- 先用整组字形包围盒排除远处字框，剩余组合沿用逐字形的有向矩形检查和原容差。

## 重放

从仓库根目录运行[回放脚本](v0.50.0-render.R)，一次装载一版源码。分别在原版和候选源码下运行前两行，输出目录使用不同位置。可用第三行单独采样，在各阶段运行完成后用最后一行对照。脚本只在指定输出目录创建设备文件和记录。

```sh
Rscript --vanilla /path/to/v0.50.0-render.R OUTPUT timing
Rscript --vanilla /path/to/v0.50.0-render.R OUTPUT views
Rscript --vanilla /path/to/v0.50.0-render.R OUTPUT profile
Rscript --vanilla /path/to/v0.50.0-render.R BASELINE compare CANDIDATE
```

两次运行的生物学来源、设备尺寸和原始脚本按各自输出目录的输入校验表核对。比较范围为这四张普通图和所列布局字段，未覆盖其他字体环境、设备或尺寸。

## 单入口构造器迁移复验

配方改用 `ggchord(prepare_ggchord_data(...))` 后重新绘制三轮圆图及三张旗舰图。各设备 PNG 保持逐字节一致。圆图三次整图时间为 14.399、12.650、13.182 秒，仍完成四次物理修正。准备数据放在构图计时之前。候选快照的耗时会随同期实现调整和本机负载变动。[分段结果](v0.50.0-render/constructor-migrated.csv) · [源码及输入校验](v0.50.0-render/constructor-migrated-inputs.csv)

已核对原版全部几何表中的既有列及 Fusion 原始表中的来源值。适配器增加 `.source_row`、`directionality` 等来源列。若原表已有 `.source_row`，适配器保留其原值于 `metadata_.source_row`，新 `.source_row` 表示传入适配器的行号。该区别在 Fusion 的局部注释表可见。布局、三条跨面板连接及其源 HSP 标识、放大区间均与原版相同。重放比较用 `compare-migrated` 模式同时核对既有来源和新列范围。

## 起始位置与增道方向

从 `cc65de55` 的两个 Position 源文件读取旧函数，在同一 R 进程对照 2 条 100 bp 序列、每条 4 个重叠区间、正负链各两条。每个例子同时检查圆形和直线的道号、原始区间、起始偏移和最终偏移。以下五组均逐项相同。

| 原调用 | 新调用 |
| --- | --- |
| `position_feature_stack(side = "outside")` | `position_feature_stack(base_position = position_offset(-0.1), direction = "inward")` |
| `position_feature_stack(side = "inside")` | `position_feature_stack(base_position = position_offset(0.1), direction = "outward")` |
| `position_feature_stack(side = "strand")` | `position_feature_stack(base_position = position_strand(0.1), direction = "auto")` |
| `position_feature_stack()` | `position_feature_stack()` |
| `position_plasmid(c(A = -0.1, B = 0.15))` | `position_offset(c(A = -0.1, B = 0.15))` |

另外通过公开绘图与导出入口交换两条直线骨架的正反方向。两种同侧分道和逐链分道都保留原始行、端点和链；骨架方向随声明改变。布局里的 `position_name` 采用新名称。旧的 `plasmid`、`feature_stack_plasmid` 和默认 `feature_stack_legacy` 分别对应 `offset`、`feature_stack_offset` 和 `feature_stack_strand`。

## 合并语法后的实图复验

使用本地提交 `88d89fa1` 的源码，以单入口构造器、`layout_sequences()`、`position_offset()`、通用特征预设和通用标签入口重新执行上述四个配方。四张图的 PNG 均与 `cc65de55` 逐字节相同。圆图各次整图时间为 14.149、12.129、12.242 秒，中位数 12.242 秒，gtable 阶段中位数 10.179 秒，仍完成四次物理修正。[分段结果](v0.50.0-render/integrated.csv) · [来源与布局](v0.50.0-render/integrated-layouts.rds) · [源码及输入校验](v0.50.0-render/integrated-inputs.csv)

一致性核对允许上述准备来源字段和位置名称变更。圆图 20 个特征标签现另外记录其锚定的特征层 `layer-0002`，5 个独立引物标签无锚定层。现有的标签几何、内外放置和引线数据一致。Radial、Sankey 的骨架、端点、走向与实例归属一致。Fusion 继续保留六个面板、三条跨面板关系以及原有三处源窗口。

最终核对另外确认，圆图既有特征类别从源记录的 `type` 读取，用 `match_id` 逐行匹配。原版本将显示注释误存为 `type` 和标签的 `repeat_type`，例如 `lac operator`、`MCS-1`。新版本分别保留源类别 `protein_bind`、`misc_feature`，显示文本、全部 25 个标签、重复文本的独立源行和引线保持原样。
