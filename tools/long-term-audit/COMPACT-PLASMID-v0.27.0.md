# 紧凑质粒布局与连续重复标注（2026-11-13）

本轮对应用户四项意见：轴文字靠近骨架、连续重复特征的新标注样式、内层来源优先
内圈，以及按文字需求分配特征与标签轨道间距。此前13图cluster-final是保留的前图；
原始DNA、feature/primer/酶集合和10×8in/110dpi画布不改。新样式另用明确参数比较。

## 原因与处理

1. 质粒主题的自动轴偏移较大，碰撞修正又只在原位置发生碰撞时触发，未主动利用
   骨架旁窄通道。最终默认偏移采用0.8mm，实际字形与骨架保护带保留0.65mm净距，检查特征、
   骨架、文字和引线根部；显式breaks/offset仍优先，无法解决的情况继续报告。
2. 逐条标注没有表达连续重复组的方式。新增显式`label_repeat="bracket"`：相同
   名称、类型、方向、已解析填充且同轨道相邻的非重叠短特征共享弧形范围括注
   与“名称 × 数量”。不跨插入的异类注释；各箭头、源记录与坐标保持独立，
   默认individual仍逐条显示。它是范围标记，不是绕行折线。
3. 成组外移曾对任意feature band启用，而已接受的外部回退不被视为可改善的任务。
   内层停止强制成组外移，并增加一次内层外移任务优先的有界重排，只有保留既有
   可见来源并减少内层外部标签才接受。external仍是回退开关，不承诺任意密度全内圈。
4. 特征轨道固定留白偏大，文字轨道存在固定native步长和约1mm每侧的碰撞padding。
   圆形feature stack按放不进箭头的文字估算走廊需求，空走廊只保留物理净距；
   相邻文字轨道用实际字高和物理间隙，内圈字框padding改为每侧0.25mm。显式
   spacing仍是最小值，不用全局缩字增加容量；文字与引线双向检查仍保留。
5. 新共享标签暴露旧的编号缺陷：隐藏行删除后引线group被压成连续行号，但文字
   group仍是原编号，导致后面的引线丢失或错误关联。现在在删除前把行索引解析为
   稳定group，source_row独立保留。共享成员的visibility与fit原因明确记录为
   represented_by_shared_label，不把共享展示记成隐藏或声称每个来源有独立字框。

## 完整组合发现的严重缺陷与候选退回

c52d00b仅有无引物/无酶局部控制证据。完整候选在记录8图、开始第9图时，
发现feature+primer多实体层时，feature polygon与其label dependency会用不同
字号估算宽度/轨道走廊。pETDuet的实际内层polygon与label anchor出现明显径向
错位；旧cluster-final也有较小差异，紧凑候选将它放大。现有“内部字形在箭头内”
检查未覆盖adjacent/external锚点，不能证明归属正确。该候选已SIGINT停止，
改名compact-candidate，JSON明确complete=false，部分PNG不作为最终通过证据。
候选pET28两处feature引线穿axis字框也保留，根部点障碍不足以代表整个出口路径；
一个只在离线探针扩大根部射线的尝试仍为2处，未采纳，不伪报为修复。

修正方向：在按owner拆分前，为完全匹配输入及Position的feature/label计算共同
几何测量上下文；有多个匹配标签时用最大字号决定共享箭头宽度与间距，各自文字
保留自己的字号、样式、data和layer ID。走廊估算只分配有界的剩余径向预算，避免
把保守的重叠估计全部变成大空白间隙。新增实际可绘制owner轮廓的anchor归属检测，
不再拿标签子布局自己的polygon当匹配证据。修复候选验证结果另行追加。


最新默认样式依据用户澄清：圆内feature起点→圈外external标签的引线灰色虚线，
不改变圈内短线和限制位点原样式。按真实锚点半径与序列圆半径判断，不用lane>0
冒充圆内来源。此前readability-control在停止命令送达前已完成3图，几何/源快照检查通过；
其样式使用此前错误理解，不作为澄清后样式验收，后续按新规则重验。


圈外引线样式首轮实图检查发现：共享perimeter重建的segment没有text锚点字段，
最终逐segment重算分类时NA覆盖了true，实际仍是实线。已拒绝此候选并保留
readability-style-candidate（complete=false），改为从最终所属text按source_row
分发内→外分类，并显式映射通过ggplot2 build；局部脚本加实际built segment
存在断言，不再仅测直接调用draw_panel。该检查通过后才重启13完整比较。
