# 密集内圈注释与简单引线（2026-11-13）

用户反例来自4ab3efc的13张完整位点比较图。本轮保留这些PNG及原results为前图，
不修改源DNA、特征/位点/primer子集、字号下限、10×8in/110dpi尺寸或源方向。
没有运行包级发布检查、冻结网站重建或推送。

## 根因

- 原本按inside/优先任务/feature lane后，按字宽从大到小贪心摆放。它保护大字框，
  却不保护局部源顺序；随后小词可能插到另一个来源前面，形成反向引线。
- 上轮允许feature穿越时，把“文字与已有引线”的约束也撤掉了。允许穿过箭头
  与允许穿过其他注释是不同语义；字框互不重叠不等于引线关系可读。
- 每条内轨单独接受最先可用文字槽，后画的直线再被淡化；这样没有解决跨词
  的关联，只是让部分路径变浅。重复短注释还有内外混杂的梯子。

## 实现

闭合圆先找最大源角空隙作为排序接缝，在原feature lane及inside优先规则内保留
圆周源顺序。稀疏多序列非圆图仍走旧规则。文字候选同时检查新直线对已放字框、
已有直线对新字框、引线相互交叉，冲突时换合法位置，不增加路线折点。
即使相邻一轨的短引线也参与选择时的障碍检查。文字仍沿最终轨道逐字绘制。

允许穿过feature轮廓，默认下层绘制及显式above不变；没有以避障为由添加多折。
external开启时，>=4个同名、同lane且集中在0.8rad内的短注释，从任意feature
band成组进入已有外圈队列。这不是合并生物学来源，也不按质粒名、注释名或
原始坐标特判。external关闭时不使用这项回退，隐藏仍由原有策略明确记录。

## 被拒绝的候选

cluster是仅恢复直线约束的候选，在部分案例后因不能形成满意内圈结果主动SIGINT
停止；源快照未做完成断言，不把其部分PNG当成功。ordered尝试强制按最近内圈
的角向展开，5个稀疏案例实际完成，但pTRE内外混合且有过大角位移，未采纳该
展开策略。保留其结果用于说明“成组展开到同一圆”并不能保证直线不经过其他词。
最终实现只保留源顺序/双向约束，以及有明确开关的成组外圈回退。

## 验证范围

coordinated稀疏两例源/注释/3个原位点选法/设备与此前balanced相同。两例全部
38源标签可见、物理收敛，无inside字形溢出自身、偏移无引线、特征路线超1拐点
或内部单行水平回退。pTRE引线交叉2→0、穿字框8→4；pCAMBIA交叉1→0、穿字框
7→2。全体同名operator外移是明确的布局回退，不包装成“7个都排进内圈”。
引线长度可能增加，这是保留简单线、源归属与不硬塞内圈之间的取舍。

最终完整13图仍使用原参考profile/显式pETDuet替代策略和独立primer，保持原尺寸；
由render-reference-catalogue.R的可选输出前缀隔离保存，旧图不覆盖。新结果记录
association、可见/隐藏、收敛、警告、所有文字/引线冲突，脚本退出后核对逐R SHA。
实际完成情况与逐图数字在下面追加，不以局部对照替代全13范围。


完整位点首个coordinated候选在pET-28a出现外圈交叉9→21，实际未接受，后续
SIGINT中止并保留partial结果。已确认ggchord_simple_feature_leaders把共享外圈
原已排序的一拐点路线再次接成直线，破坏队列布局。最终修复保留external原
路线，仅对inner重建终点/穿字框显示；外圈继续由共享队列给出直线/一拐点，
不重新运行多折graph。后续cluster-final才是完整最终对照，不能升级partial
结果为完成。coordinated稀疏数据只属于此前候选源指纹，不是最终13替代证据。


pET-28a最终实测由原10×8未收敛变为收敛，67源标签全部保留，引线交叉9→0、
穿字框17→0；仍使用相同画布/字号/子集，没有把文字缩到下限以下。更多短词
使用外圈队列，原内圈长梯子减少，仍需按图审读其整体留白和阅读距离。


最终镜像控制额外旋转48°并逆向：pTRE的18源标签全部可见、收敛且无警告，
内部弧字/归属/拐点断言仍0；7条operator成组在左侧外圈，真实源顺序保留。
feature穿越7次作为允许的观察保留；下层绘制不代表几何中心线不相交。
共享外圈队列排序可增加文字到源的距离，本轮没有声称总引线长度同时最小。
