## 根因与实际改动

1. 原生成器先把跨原点区间拆片，再在最后一片生成双向箭头；它在原点新增
   假头和封口。闭合圆现在用展开坐标生成一个完整箭头，再周期映射，使用
   接缝两侧切线。有真实显示开口时保留分片，只在真实端点保留头；compact
   类型的起点单头分支也已修正。没有改原始 start/end/strand。
2. 扩展审计实际复现跨原点多段表被压成整段、显式 gap 被填充的第二个缺陷。
   `v0.27.0-wrapped-gap-before.json` 保留未提交闭合接缝候选的失败观察。
   新实现保留各段端点/颜色/gap，获得完整源长度后只连接真正相邻且同色的 run。
   非环形路径不周期连接，真正断开的 feature 不被连接；长度不由末位观测推断。
3. 旧标签拟合以骨架周长估计内部 feature 带可用长度，双向头也只扣一次。
   现在按实际 feature 带周长和两个头估计，并以绘制字形包络检查自身轮廓。
   跨原点标签仍用完整来源的圆形中点。上一“最长显示片段”候选已撤回，不能
   把错误分片当作标签拟合的正确前提。
4. 明显角向偏移的相邻标签补短引线。内部单行标签始终沿圆轨道排布，移除
   上一候选的水平回退及多折可视图绕行。内轨文字仍须避开其他 feature 和文字，
   引线允许穿过特征，不用已有引线把文字强行推远；最终路线取直接连接。
5. 新公开参数 `label_segment_layer = c("below", "above")` 默认 below：在原生
   scale 训练之后仅拆分绘制数据，引线位于数据层下方，文字保留原标签层顺序。
   above 恢复原标签层位置，后加的其他层仍遵循用户顺序。映射、固定样式、来源
   和图层 ID 不重新推断；透明 feature 保留透明。`label_segment_overlap` 的
   fade/clip/show 继续控制穿过其他字框部分的显示，不能以改变路线代替这些设置。
