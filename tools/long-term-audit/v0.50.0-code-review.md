## 三个可运行的反例

在该版本 checkout 中运行。第一例对照绘制面板与导出的源行，第二例读取投影所用位置、高度和高度域，第三例对照各面板的数值范围。

```r
pkgload::load_all(".")
library(ggplot2)

ref <- data.frame(accver = c("A", "B"), length = c(100, 100))
links <- data.frame(
  qaccver = c("A", "B"), saccver = c("B", "A"),
  qpos = c(10, 20), spos = 50
)
link_plot <- ggchord(ref) +
  geom_seq() +
  geom_link_line(data = links, id = "links", layout = 1L) +
  layout_sequences(order = c(z = "A", a = "B")) +
  coord_collinear() +
  facet_wrap(vars(qaccver))
ggplot_build(link_plot)$layout$layout[c("PANEL", "qaccver")]
link_rows <- export_ggchord_layout(link_plot, include = "link")$link
unique(link_rows[c("source_row", "qaccver", "saccver")])

depth <- data.frame(
  accver = "A", site = c(3, 6), depth = c(2, 9),
  pos = c(15, 16), track_value = c(77, 88)
)
line_plot <- ggchord(ref[1, ], aes(x = site, y = depth)) +
  geom_track_line(data = depth, id = "line") +
  coord_collinear()
line_result <- export_ggchord_layout(line_plot, include = "track", original_data = TRUE)
line_result$original_data$line$track[c("pos", "track_value")]
line_result$track_registry$limits

observations <- data.frame(
  accver = "A", sample = rep(c("x", "y"), each = 2),
  pos = c(10, 20, 10, 20), value = c(2, 5, 8, 12)
)
point_layer <- function(panel) {
  geom_track(
    aes(x = pos, y = value), data = observations,
    geom = "point", measure = "depth", layout = panel
  )
}
band_plot <- ggchord(ref[1, ]) +
  geom_seq() +
  point_layer(1L) +
  point_layer(2L) +
  coord_collinear() +
  facet_wrap(vars(sample))
export_ggchord_layout(band_plot)$track_registry[c("sample", "limits")]
```

## 既有行为与文档差异

- **源列和映射后的同名列。** 特征源表中 `accver` 为 u/v，`ref` 为 A/B。将 `aes(accver = ref, fill = accver)` 放在构造器上，实际填色按 A/B。构造器帮助说明继承映射在各层源表求值，特征帮助又说普通视觉映射在几何生成后求值。两处说明对本例给出不同预期。需要明确填色所见的数据阶段；在决定之前，将填色值存入独立列可消除歧义。[构造器帮助](../../R/ggchord.R#L54) · [特征帮助](../../R/geom-feature.R#L203) · [图层输入](../../R/layer-input.R#L316)
- **轨道形状与具名图例控制。** 当前点轨道的分类 `aes(shape = kind)` 先成为 16、17，再交给外层 `scale_shape_manual()` 会报连续值传给离散标度。具名的 `show.legend = c(fill = FALSE)` 不能隐藏轨道填色图例，整层设为 `FALSE` 可以隐藏。两处相关实现已见于比较基线，旧版归因来自源码对照，动态复现使用本次快照。[内部标度](../../R/track-grammar.R#L463) · [轨道图例参数](../../R/geom-track.R#L289)
- **双语迁移说明。** 历史段落仍有“运行当前替代”的指令。其中的 `ggchord(seqs, gene_data = genes)` 和 `geom_gene()` 在本版均无法运行。对应的可执行写法为 `ggchord(seqs) + geom_seq() + geom_feature(data = genes, preset = "gene", position = position_strand(c("+" = .1, "-" = -.2)))`。应标明原示例的适用版本或更新该段落。[汉语](../../MIGRATION-Hans.md#replacement) · [English](../../MIGRATION.md#replacement)
- **开发工具。** 已迁移的 API 核对脚本仍断言 `geom_seq(candidate_unknown = 1)` 返回图层，实际按本版约定抛错。轨道裁切的旧断言则揭示了 P2-10 的真实行为差异。教学参数清单缺少导出函数 `shared_track_limits()`，以及 `measure`、`facet_domain` 和部分 `stat` 形参。该清单用于文档图谱，待恢复网站工作时同步。[拼写断言](../validate-api-candidate.R#L49) · [教学清单](../teaching-audit/api-signatures.json) · [导出表](../../NAMESPACE)

## 验证范围

- 使用 R 4.6.0、ggplot2 4.0.3。解析了版本差异中仍存在的 125 个 R 实现与脚本文件及 49 个 Rd 文件，均通过语法解析。对现行函数帮助、vignette 和示例调用核对了本版移除的五个函数名。
- 两个随仓示例运行成功。双样本覆盖的实际窗分母均为 4、4、2。外部 Stat 的柱与线都得到逐窗计数 2、1、0 和 0、1、0，成员能回指同一批源行。[迁移示例](../../examples/migrate-v0.50.0.R) · [第三方 Stat](../../examples/stat-window-count.R)
- 另核对了空显式窗表、反向数值标度跨图取共同范围、显式特征填色与标签反差、局部轨道 guide 样式，以及无分面 Fusion 的中心和周边面板物理收敛。环境缺少 patchwork，其组合绘制路径本轮未实测。此前的多图性能及图像比对沿用原提交的记录。[已有验证及版本基线](v0.50.0-status.md)
