开发核验逐一向 22 个入口传入 `linewditth`，均在构造图层时报错。骨架和特征会提示 `linewidth`。分箱的 `binwidth`、平滑的 `method`、外部 Stat 的自定义参数和文本样式仍可传入。对于 21 个布局入口，分别以具名层构图并导出核对身份。同一对象加入两次会得到独立自动 ID，并避开显式保留的 `layer-0001`；显式重名会报错。另用普通 ggplot 核对了具名残基层及其两个字符。数字面板选择继续在统计前生效。

## 阶段导出与外部 Stat

`export_ggchord_layout(..., data_stage = ...)` 按请求顺序为每个注册层列出 `layer_id`、`stage`、`status` 和 `reason`。原生轨道的映射在 ggplot2 内部求值，`mapped` 返回 `NULL` 和对应原因。没有单独统计表的骨架和原始 HSP 线段也有明确的 `statistic` 原因。成功的零行统计记为 `available`。轨道 Stat 失败时，即使 ggplot2 返回零行，统计和派生几何仍记为 `failed`，原因可在阶段表中读取。以 32 条原始 HSP 复核了 Dotplot 的专用导出路径。[导出帮助](../../man/export_ggchord_layout.Rd)

[外部 Stat 示例](../../examples/stat-window-count.R)在一条 12 bp 参考上按 1–4、5–8、9–12 三个闭区间计数。两层导出的窗中心、`after_stat(n_interval)` 高度和成员逐项相同。第一组依次为 2、1、0，成员为 (1,3)、(1)、空集。第二组为 0、1、0，只有中窗含第 2 行。另传入同列的零行源表，源表和统计表均为零行，两个阶段均可用。

## 三项修复复验

`003c94a4` 登记的三项缺口已在 `82f607ae` 修复。以下结果从公开入口取得。[参数归属要求](v0.50.0-design.md#目标函数目录与候选签名) · [失败恢复要求](v0.50.0-engine.md#缓存失效和异常恢复)

1. **非 Geom 入口要求完整参数名。** 六个新增入口分别试用 `track_band(i = "d")`、`layout_sequences(length_mod = "equal")`、`stat_coverage(binwidt = 4)`、`position_offset(offse = .1)`、`guide_seq_axis(sequence = "A")` 和 `guide_track_axis(angl = 30)`，均报错并提示完整名称。另复验 `position_feature_stack(spacin = .2)`、`position_strand(offse = .1)`、两个连续标度的 `guid`、准备入口的 `seq_dat` 和导出的 `data_stag`。通过 `...` 转发的 `offse` 也会报错。全名、按位置传值及两个标度的合法参数仍可使用，序列标度的旧 `sequences` 仍提示迁移到 guide。[位置](../../R/position-feature.R) · [序列标度与轴](../../R/scales.R) · [轨道轴](../../R/track-theme.R)
2. **外部 Stat 和 Geom 的同名参数会在构造图层时报错。** 三个观测位于 5、8、15。向声明了统计半径 `width` 的外部 Stat 与柱形 Geom 显式传入 `width = 4`，错误列出 `width` 和两个接收者。将统计参数改为 `radius = 4`、设柱宽 `width = 2` 后，计数为 2、2、1，三根柱宽均为 2。换用只由 Stat 接收 `width = 2` 的点层时，计数为 1、1、1。另复验了 `color` 别名和文本层参数的冲突，以及[逐窗计数示例](../../examples/stat-window-count.R)中由 Stat 接收 `windows`、由柱层接收 `width` 的合法组合。[参数检查](../../R/layer-input.R) · [轨道统计](../../R/track-grammar.R)
3. **阶段导出区分统计失败、合法零行和不适用，数据回调报错带层 ID。** 让 `signal` 层的 Stat 抛出 `missing sample weights`，阶段表中 `source` 仍可用，`statistic` 和 `geometry` 均为 `failed`，两行 `reason` 都保留原文。合法零行输入和主动返回零行的 Stat 均导出零行统计，状态为 `available`、原因为 `NA`。骨架没有单独统计表时仍为 `unavailable`。另复验了 Stat 初始化失败、普通警告和扩展内部恢复成功。三个样本中两个面板分别报错时，即便静默警告，阶段表仍保留两个原因，成功面板的统计与几何仍可读取。修正同一图的统计错误后重新导出，状态恢复为 `available`。特征层回调错误含显式 ID `exons` 和原文 `missing annotation input`，轨道公式回调错误含自动 ID `layer-0001` 和原文。[阶段导出](../../R/layout-export.R) · [数据回调](../../R/layer-input.R)

当时另复验了 22 个 Geom 对 `linewditth` 的诊断、七种内置轨道统计的普通与阶段导出，以及双样本迁移示例的覆盖窗口（每组分母均为 4、4、2）。上述三项记录对应 `82f607ae`。
