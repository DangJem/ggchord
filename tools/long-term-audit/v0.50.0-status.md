## 22 个公开图层的公共参数

22 个入口均显式接收 `mapping`、`data`、`position`、`show.legend`、`inherit.aes` 和 `...`。表中是函数签名的默认值。特征预设保留各自的默认样式和图例，例如 `preset = "plasmid"` 默认隐藏图例。

| 入口 | 默认图例 | 默认继承映射 | 身份与位置 |
| --- | --- | --- | --- |
| `geom_seq`、`geom_feature`、`geom_link_ribbon` | TRUE | TRUE | `id`。连接带默认使用 identity Stat。 |
| `geom_alignment_segment`、`geom_link_line` | NA | TRUE | `id`。源端点与投影决定位置。 |
| `geom_seq_label`、`geom_seq_center_label`、`geom_seq_break`、`geom_seq_region`、`geom_seq_scale` | FALSE | TRUE | `id`。中心标签现显式接收 `position`，默认 identity。 |
| `geom_feature_label`、`geom_gene_label`、`geom_gene_label_repel` | FALSE | TRUE | `id`。固定标签和避让标签保留各自的控制项。 |
| `geom_primer`、`geom_primer_label_repel` | FALSE | TRUE | `id`。省略位置时按引物侧别放置。 |
| `geom_restriction_site` | FALSE | FALSE | `id`。其独立位点表默认自行提供角色。 |
| `geom_track`、`geom_track_bar`、`geom_track_col`、`geom_track_line`、`geom_track_tile` | NA | TRUE | `id` 标识单层，`track` 引用共享带。bar 默认 count、col 默认 identity。开放线可显式选 Stat，闭合线使用 identity。全带 tile 支持 identity 和 coverage。 |
| `geom_residue` | FALSE | TRUE | 普通 ggplot2 对齐字符图层可用 `name` 命名，使用原生数据位置，走独立的字符与对齐导出流程。 |

开发核验逐一向 22 个入口传入 `linewditth`，均在构造图层时报错。骨架和特征会提示 `linewidth`。分箱的 `binwidth`、平滑的 `method`、外部 Stat 的自定义参数和文本样式仍可传入。对于 21 个布局入口，分别以具名层构图并导出核对身份。同一对象加入两次会得到独立自动 ID，并避开显式保留的 `layer-0001`；显式重名会报错。另用普通 ggplot 核对了具名残基层及其两个字符。数字面板选择继续在统计前生效。

## 阶段导出与外部 Stat

`export_ggchord_layout(..., data_stage = ...)` 按请求顺序为每个注册层列出 `layer_id`、`stage`、`status` 和 `reason`。原生轨道的映射在 ggplot2 内部求值，`mapped` 返回 `NULL` 和对应原因。没有单独统计表的骨架和原始 HSP 线段也有明确的 `statistic` 原因。成功的零行统计记为 `available`。轨道 Stat 失败时，即使 ggplot2 返回零行，统计和派生几何仍记为 `failed`，原因可在阶段表中读取。以 32 条原始 HSP 复核了 Dotplot 的专用导出路径。[导出帮助](../../man/export_ggchord_layout.Rd)

[外部 Stat 示例](../../examples/stat-window-count.R)在一条 12 bp 参考上按 1–4、5–8、9–12 三个闭区间计数。两层导出的窗中心、`after_stat(n_interval)` 高度和成员逐项相同。第一组依次为 2、1、0，成员为 (1,3)、(1)、空集。第二组为 0、1、0，只有中窗含第 2 行。另传入同列的零行源表，源表和统计表均为零行，两个阶段均可用。

## 三项修复复验

`003c94a4` 登记的三项缺口已在 `82f607ae` 修复。以下结果从公开入口取得。[参数归属要求](v0.50.0-design.md#目标函数目录与候选签名) · [失败恢复要求](v0.50.0-engine.md#缓存失效和异常恢复)

## 原延后事项的决定

| 事项 | 本版处理及依据 |
| --- | --- |
| Dotplot 二维分箱 | 沿用用户已选的原始 HSP 线段，增加有向序列对分面。32 条真实记录按中点/起点分别落入 23/20 个非空格，8 条换格；5,000.5 的两种边界归属保留在审计记录。[原始对照](v0.50.0-candidates.md) |
| 跨面板锁定分道 | 各面板按自身实体分道，标签通过稳定身份跟随实体。同带与局部数值标度可显式共享。全局自动锁定每一特征的物理偏移会使别的样本改变当前面板排布，本版选用面板内分道。[分道实例](v0.50.0-features.md) |
| 复杂多段互认 | 接受带稳定实体键、分段及源区间证据的输入。多个合法父层时使用 `anchor_layer`。同名或区间相近不足以确立实体身份。[子集与多段](v0.50.0-features.md) |
| 隐式共享标度 | 采用上表的显式共域函数。两张图使用同一个带名或同一个图例标题无法证明单位和度量一致。 |
| 从 HSP 汇总推断逐碱基覆盖 | 用有证据的源闭区间计算跨度覆盖，需要逐位置对齐时使用已登记的对齐字符及位置映射。只有 HSP 两端无法定位内部缺口。[位置映射](../../man/map_alignment_position.Rd) |
| 交互拾取 | 本版以静态位置查询、图层源行和几何导出供检查。交互设备和事件循环无须成为 R 包静态绘图的运行依赖。[几何导出](../../man/export_ggchord_layout.Rd) |
| 自动序列重排 | 显式调用 `optimize_ggchord_layout()` 查看结果，再用 `layout_sequences()` 应用选择。输入顺序可能表达研究设计，构图时不自行更改。[优化帮助](../../man/optimize_ggchord_layout.Rd) |
| 引物与限制位点入口 | 分别使用引物区间和限制位点表。二者的身份、锚点及单位约束不同；限制位点现对实际显示的 bp 参考校验。[七项复验](#来源分面和区域几何的七项复验) |
| 网站及正式发布 | 网站正文、译文、导航、生成与部署继续暂停。开发复验在本地版本分支进行。合入 main、发布及发布级检测按仓库约定另行授权。 |
