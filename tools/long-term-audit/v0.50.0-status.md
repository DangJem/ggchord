## 22 个公开图层的公共参数

22 个入口均显式接收 `mapping`、`data`、`position`、`show.legend`、`inherit.aes` 和 `...`。表中是函数签名的默认值。特征预设保留各自的默认样式和图例，例如 `preset = "plasmid"` 默认隐藏图例。

| 入口 | 默认图例 | 默认继承映射 | 身份与位置 |
| --- | --- | --- | --- |
| `geom_seq`、`geom_feature`、`geom_link_ribbon` | TRUE | TRUE | `id`。连接带默认使用 identity Stat。 |
| `geom_alignment_segment`、`geom_link_line` | NA | TRUE | `id`。源端点与投影决定位置。 |
| `geom_seq_label`、`geom_seq_center_label`、`geom_seq_break`、`geom_seq_region`、`geom_seq_scale` | FALSE | TRUE | `id`。中心标签现显式接收 `position`，默认 identity。 |
| `geom_feature_label`、`geom_gene_label`、`geom_gene_label_repel` | FALSE | TRUE | `id`。固定标签和避让标签保留各自的控制项。 |
| `geom_primer`、`geom_primer_label_repel` | FALSE | TRUE | `id`。省略位置时按引物侧别放置。 |
| `geom_restriction_site` | FALSE | FALSE | `id`。其独立位点表默认自行提供角色。 |
| `geom_track`、`geom_track_bar`、`geom_track_col`、`geom_track_line`、`geom_track_tile` | NA | TRUE | `id` 标识单层，`track` 引用共享带。bar 默认 count、col 默认 identity。开放线可显式选 Stat；闭合线和全带 tile 使用 identity。 |
| `geom_residue` | FALSE | TRUE | 普通 ggplot2 对齐字符图层可用 `name` 命名，使用原生数据位置，走独立的字符与对齐导出流程。 |

开发核验逐一向 22 个入口传入 `linewditth`，均在构造图层时报错。骨架和特征会提示 `linewidth`。分箱的 `binwidth`、平滑的 `method`、外部 Stat 的自定义参数和文本样式仍可传入。对于 21 个布局入口，分别以具名层构图并导出核对身份。同一对象加入两次会得到独立自动 ID，并避开显式保留的 `layer-0001`；显式重名会报错。另用普通 ggplot 核对了具名残基层及其两个字符。数字面板选择继续在统计前生效。

## 尚未实现或尚待决定的项目

- **接口收敛仍有原案待评审。** `geom_gene_label()`、`geom_gene_label_repel()`、`geom_primer_label_repel()`、角色标度、专用 guide 和 22 个 ggplot2/grid 重导出仍在。基因及引物标签有独立行为，区间形状和图例键需验证等价性。原案提出过删除这些名称，尚无全部删除的决定。
- **扩展及其验收仍有边界。** 将任意第三方 Geom 投影进物理轨道、让 ribbon Stat 选择其他兼容几何均未贯通。计划写的外部“每窗相交记录数”与现有外部“按位置汇总”探针也是两个不同验收例。内置覆盖已处理窗口相交。
- **部分验收场景尚缺本版记录。** 已归档同一设备上四张图的几何与图像对照；改变字号、guide 和画布尺寸后的成组对照，以及嵌套 Fusion 子图失败后恢复外层设备的专项回放，尚未在本版记录中逐项列出。已验证的构建缓存恢复见[引擎记录](v0.50.0-engine.md)。
- **其他待确认候选。** 包括源序列位点标记、局部数值阈值线、接收多个完整层的轨道容器、共享轨道的不同度量兼容检查、以原网格或局部原点重算的专用选择接口，以及把全部场景接入同一准备或跨渲染复用机制。箱线/小提琴已有单值窗反例，需有能代表目标分布的原始观测，再决定是否增加接口。以上均未排期。

## 明确推迟及授权边界

- **网站。** 按 2026-11-18 用户决定，即日起暂停网站相关内容更新，包括正文、译文、导航、生成与部署，待网站重构方案确定后再处理。此前完成的双语迁移保留为历史记录。
- **Dotplot 二维分箱。** 用户已确定本版用原始 HSP 线段，仅登记分箱对照。`stat_alignment_bin2d()`、格子 Geom 及半整数边沿的默认归属留待后续决定。
- **原计划已列为延后的能力。** 跨面板锁定所有分道的物理偏移、复杂多段自动互认、隐式共享标度、交互拾取、自动改变序列顺序，以及引物和限制位点数据入口整理。HSP 摘要推断逐碱基覆盖也在延后清单中，开展那项分析还须有逐段或对齐证据。[原始延后清单](v0.50.0-api-inventory.md#延后与实施前核对)
- **正式验收与发布。** 本版已做开发期核验。整合、正式发布与相应发布验收分别按仓库授权规则执行。
