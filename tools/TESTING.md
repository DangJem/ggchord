# 默认测试维护约定

2026-11-14 用户要求按 gggenomes 的简洁标准收敛，并明确以后不得擅自增加测试项目。

## 参照与取舍

查看 [gggenomes tests](https://github.com/thackl/gggenomes/tree/752e0e19da04b6813f0524d784843901ac64dcb2/tests)：
`test-read_seq_len.R` 为 22 行、3 个读取案例，`test_vars.R` 为 15 行、2 个字段工具案例。
简洁主要来自覆盖范围窄、输入和预期值直接、没有逐参数/逐设备的几何测试，不能据此认定其所有绘图行为都自动验收。
只借鉴组织方式，未复制其代码或数据。

本仓库原 tests 共 13 个 R 文件、1067 行；现为一个标准入口及两个测试文件，共 121 行、9 个案例。
`test-data.R` 保留校验/清理/基本错误、七个轻量文本读取器及三个 ribbon 工具的成功路径。
`test-plot.R` 保留一次核心 build、三种标签布局、feature/region/link 来源，以及自动 ribbon 样式、空引物和 Unicode 测量的最小回归。
图层输出按实际内容或公开导出结果选择，避免坐标轴插入导致固定序号失效。

删除的设备/坐标/内部字段/参数组合和可选外部解码器测试不搬往其他目录，不新增框架、图片快照或大型测试数据。
覆盖范围有意缩小；默认测试通过不代表任意布局、字体、设备或发布平台均通过。

## 后续规则

- 数据与绘图两个短测试文件保持稳定；小输入、直接预期值，每个行为只留必要断言。
- 修复优先修改或替换已有案例。新增测试文件、测试项目或扩大默认范围，须用户明确同意。
- 不按函数/参数/实现分支逐项扩张，不锁定浮点坐标、重建次数、字体尺寸和私有布局结构。
- 普通开发只做当前问题的直接轻量复现。包级检查和正式发布验收继续遵守 AGENTS.md 的授权边界。
