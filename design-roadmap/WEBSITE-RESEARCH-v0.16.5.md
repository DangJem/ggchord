# 网站重构：跨产品调研与实施取舍

2026-11-01；实施中。用户否定上一轮低饱和配色、简陋设计及教程质量。本文取代以
“原生模板 + 页面覆盖”作为成品充分条件的假设；不是版本完成记录。

## 当前问题的原因

1. 配色未区分语义。几乎全部连接、轨道及注释使用相近灰绿，类别不易区分；高透明度
   又降低主体与背景的对比。主题统一被错误地应用到所有数据编码。
2. 选图未先定义问题。全量 266 个 CDS 的线性缩略图适合查看概貌，不适合教读者比较
   一个基因邻域；圆图的多轨道若无值域和解读则像装饰。首页机械堆三个图，未帮助选择。
3. 只有页内目录，没有稳定的学习地图。读者被要求跳到首页复制全局变量，再跳回专题；
   常用准备和可选配色混在一起，教程无法独立起步。
4. 页面标题与承诺不一致。“开始使用”只有安装和跳转，缺少第一张图、结果、解释、
   保存和失败排查；专题常是函数摘要而不是完成任务的过程。
5. 原生模板解决了生成问题，没有自动解决信息设计。行宽、空白、图形比例、内容节奏
   和代码位置缺乏统一规则。页面数量、翻译数量及链接检查均不能证明阅读体验。

## 信息架构与读者路径

- **开始使用**：安装/加载 → 真实随包输入 → 第一张共线性图 → 看懂骨架、箭头与连接 →
  切换弦图/圆图的条件 → 调整一项映射 → 按尺寸保存 → 排查与下一步。
- **学习教程**：第一张图、读入自己的数据、绘制质粒图、比较基因邻域、添加轨道。
  每章须独立交代准备、步骤和结果，不依赖读者猜测之前创建了哪些变量。
- **任务指南**：标签拥挤、筛选连接、翻转/对齐、局部窗口、配色和图例、格式转换、
  蛋白 CDS 投影、输出尺寸。直接解决一个问题，再链接原理与参数。
- **函数参考**：保留完整英语/汉语参数契约、搜索与上下文链接，不作为入门课程。
- **示例图集**：按“想比较什么”组织。每例包含适用/不适用情形、数据来源、完整脚本、
  图和关键解读；不只是 PNG 清单。

全站统一：桌面章节侧栏/正文/页内目录，窄屏章节抽屉；语言始终可切换。首页用于
说明用途、选择学习路径和展示有解释的科研案例，不堆砌文档内部验收数字。

## 图形编码方向

| 任务 | 主要几何 | 色彩与信息层次 |
| --- | --- | --- |
| 多序列总体比对关系 | 弦图 | 序列用明确类别色；连接按真实相似度连续色或按 query 类别色，两种含义不可混用 |
| 单条质粒注释 | 圆图 | CDS、复制起点、启动子等用可区分类别色；引物/酶切用独立线与标签层 |
| 基因邻域位置/方向比较 | 局部共线性图 | 区间保留比例和源方向；有证据的同源组使用一致颜色，其他基因不凭名称伪造分组 |
| 全基因组概貌 | 全长线性图 | 全量注释可作为概览，不能用它代替可读的局部案例 |
| GC 等数值轨道 | bar/line 与独立注释带 | 连续值用顺序色；只有真实中心基线才使用发散色。明确值域、单位、窗口及线的含义 |
| 标签布局对照 | 同一输入的并列案例 | 相同输入、字号和尺寸；说明适用密度，保留几何，避免用密集长文字当宣传图 |

数据色板与网站强调色分离。提高类别可辨性和主体对比，保留适量高彩度，不为统一
页面色调牺牲科学阅读。暂不更改 R 包默认色板，全部文档选择显式写入代码。

## 实施与验收门槛

先完成信息架构和开始使用的真实教学路径，再重构全站模板与逐图编码；沿读者路径
检查所有正文。保留双语一致、真实最小输入、来源、完整参考和无损用户原画。
未获部署/正式发布授权，冻结 docs/ 不变。验收以新手能否独立完成首图和保存、已有
数据用户能否选格式与选图、熟练用户能否找到参数为主；静态检查只是其中一部分。

## 已实施的具体取舍

- 统一正文网格、白色阅读面、深色文字、蓝色交互强调及等宽辅助文字；章节导航与图形
  数据色板分开。宽屏显示页内侧栏，中等/窄屏保留展开目录，不因隐藏侧栏丢失导航。
- 首页按问题选择真实弦图、pUC19 圆图和 AmpR 局部图。全长 266 CDS 概览留在原始文件
  教程；不再用它承担首页局部比较的任务。图集按任务索引，并逐图链接准备与解释。
- 首图教程独立选择两条序列及 2/4/6 列，依次加载、检查、组合图层、读图和保存。
  其他任务页就地提供自己的准备代码；完整工作流按中间对象和显示决策拆步。
- 显式类别色使用蓝、橙、青绿、紫；注释类型各有稳定色。基础弦图/共线性图的连接按
  query 类别配色，真实比对案例按实际 pident 连续配色；首图的中性连接用于突出输入
  角色。GC 使用蓝色顺序色。没有修改包的默认 palette 或原始数据。
- AmpR 从实际定向编码 DNA 建立成员关系，聚焦各 CDS 两侧 200 bp，轴保留源坐标。
  外置标签原本因连接冲突隐藏，改用通用注释内部文字后两条 AmpR 均 placed；这是
  文档几何选择，不通过关闭碰撞策略强制堆叠文字。
- 堆叠注释增加几何宽度、显式设置有下限的 shrink，使 lacZα、ori、AmpR 可内部阅读。
  GC 轨道由 6 mm 改为 10 mm，定量和类别图例分组排列；刻度及主要文字放大。
- 新章节抽屉位于 main 内，若直接索引其文字会让每页都命中所有章节关键词；搜索
  提取器排除导航和目录，保留正文及准备代码。此问题在实际交互验收中另行核对。
