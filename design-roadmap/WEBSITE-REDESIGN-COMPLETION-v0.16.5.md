# v0.16.5 整站重构与内容重写：本地完成记录

2026-11-01。开发范围已实现并通过下述局部验证；尚未正式发布或部署。
本记录取代此前将模板、索引覆盖或低对比图形当作完成依据的结论。旧记录保留历史，
不代表用户已接受本轮主观视觉风格。本地完成也不等同完整发布验收。

## 问题与解决方向

用户指出旧站配色寡淡、图形选择缺少依据、页面内容与标题不符、入门流程不能独立完成。
[跨产品调研与实施取舍](WEBSITE-RESEARCH-v0.16.5.md)记录了实际查阅的 Diátaxis、Astro、
Rust Book、Observable Plot、Matplotlib、Seaborn、gggenomes、Scanpy/scverse、Geist 等
不同方面的参考；未抓取成功的正文明确排除，不复制上游模板、图形或绘图代码。

本轮交付：

- 克制的正文网格、字体层级、蓝色交互强调、稳定章节导航与响应式目录。顶栏常驻；
  修正右侧目录外边距、窄屏 12 px 溢出及参考页重复图标。入口页优先任务导航。
- 首页按问题展示真实弦图、完整 pUC19 圆图和 AmpR 局部邻域；全量注释概览留在专题。
  数据类别、连续相似度、GC 数值和固定强调各有明确编码，不统一套低饱和灰绿色。
- 首图教程完成安装/版本判断、2/4/6 列输入选择、图层组合、读图、保存、失败排查及
  下一步。原始文件、质粒、CDS 邻域和轨道流程有分步准备、结果解释及本页保存代码。
- 任务页就地准备对象；色板和排版按实际依赖拆分。生成的 vignette 源同样按章起步，
  不再要求先复制首页全局变量。图集按任务查找，每图链接准备、代码和解释。
- 共用 21 张显式尺寸 PNG，主要文字增大、轨道加宽、图例分组；AmpR 使用两侧 200 bp
  的源坐标窗口和内部标签。原始数据、包默认色板和公开签名保持不变。
- 图片预留固有宽高，懒加载前即有比例；原始尺寸画布允许在手机上阅读完整像素。
  搜索排除新章节抽屉和目录，避免所有页面都命中导航词。

## 本版本其他已完成范围

完整英语/汉语参考从 93 个当前 Rd 主题生成，856 段译文绑定源摘要；130 个导出入口
均可查阅。标准 BLAST 12 列与最小六列连接表、真实 PAF、真实 BLASTp 读取/CDS 投影、
格式适配、灵活参数支持范围及迁移同步保留。原生 aa 绘图仍为用户选定的单独待确认
方案，不计入本版实现承诺。

用户原画保持逐像素无损的 PNG/WebP 优化结果与来源记录。精简输入调查确认的 F52
空引物结果、F53 缺少可选 anno 时丢失链填色，已分别修复并记录。没有扩大运行依赖、
新建绘图 API 或修改许可证。
