## 发布依据

包实现、README、迁移说明、双语长教程、函数帮助和网站已完成。本地标准 R CMD check、完整测试及远端四平台验收通过；新站由 Pages Actions 部署。当前版详细事实见[正式验收](RELEASE-ACCEPTANCE-v0.16.6.md)和[版本文档](versions/v0.16.6.md)；配套Pages部署结果单独记录。各开发阶段的完成记录及[唯一候选基线](API-CANDIDATE-v0.16.4.md)保留历史证据。v0.13.0 从未正式发布；原 v0.16.0 定量轨道范围并入 v0.15.0 的历史不变。

## 未来版本

- **v1.0.0**：稳定 API 正式发布，不首次启动架构或网站重构。

保留 chord、circular、collinear 三种主要模式，不增加第四类；交互绘图不在 v1.0.0 及之前范围。下一版须在用户批准本版整合后，才从整合后的 main 创建专用分支；本次开发授权不自动扩展为整合或发布授权。

## 跨版本事项

- 用户提出中心圆图与四周共线性视图之间的跨视图ribbon组合，已记录为
  [待确认构想](COMPOSITE-VIEWS-PROPOSAL.md)，不安排版本或改变当前三类坐标边界。
- 按实际风险补充几何、拥挤标签与性能验证，区分合法相交、数值错误和视觉退化；有限场景不构成穷举保证，不以固定秒数作跨机器门槛。
- v0.16.6审计保留按序列/链参数及有效低频列表形式，推荐命名向量，没有新增弃用；特殊键、位置匹配与各helper边界已记录。
- 原生蛋白坐标仍为[待确认方案](PROTEIN-COORDINATES-PROPOSAL.md)，不承诺实现版本；本版已按用户选择完善读取与 CDS 投影。
- Pages 已切换 Actions。旧 docs 仅为历史归档，不再部署或重建；自动审批未允许删除该目录，未来删除需明确处理。历史跳转清单已独立版本化。
