## 未来版本摘要

- **v0.16.1–v0.16.3**：依次整理绘图语法、数据契约、内部引擎与输出；严重正确性
  问题发现后优先处理，不因归属后续版本而延后必要修复。
- **v0.16.4（已启用）**：整合迁移与候选API冻结，为v0.16.5提供唯一引用清单。
- **v0.16.5**：在候选 API 稳定后完成英语/汉语文档、教程、README 与网站重构。
- **v0.16.6**：发布候选冻结，集中处理平台兼容、视觉、性能和发布阻断问题。
- **v1.0.0**：仅正式稳定发布；不在此时首次启动架构或文档网站重构。

保留 chord、circular、collinear 三种主要模式，不增加第四类；新增 API 仅在通过
真实需求、契约、替代方案和验证审查后纳入。交互式绘图不在 v1.0.0 及之前的范围内。
后续版本开始前须以前版本地开发完成并整合 main 为前提，再从 main 创建专用分支；
本轮已从main（`24930b0`）创建`codex/v0.16.5`，首轮实现已整合main；用户要求复核网站风格与内容完整性，现回到本版分支修订；后续阶段等待，不自动推送、正式发布或运行完整发布验收。
