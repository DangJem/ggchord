原计划转移记录保留在 [v0.16.0 历史小节](versions/v0.16.0.md#原计划转移记录历史)。

## 未来版本摘要

- **v0.17.0–v0.19.0**：依次整理绘图语法、数据契约、内部引擎与输出；严重正确性
  问题发现后优先处理，不因归属后续版本而延后必要修复。
- **v0.20.0（可选）**：迁移较多时独立稳定化，否则相应工作归入 v0.19.0。
- **v0.98.0**：在候选 API 稳定后完成英语/汉语文档、教程、README 与网站重构。
- **v0.99.0**：发布候选冻结，集中处理平台兼容、视觉、性能和发布阻断问题。
- **v1.0.0**：仅正式稳定发布；不在此时首次启动架构或文档网站重构。

保留 chord、circular、collinear 三种主要模式，不增加第四类；新增 API 仅在通过
真实需求、契约、替代方案和验证审查后纳入。交互式绘图不在 v1.0.0 及之前的范围内。
后续版本开始前须以前版正式发布并整合 main 为前提，再从 main 创建专用分支；
本轮只建立 v0.16.0 规划，不授权源码实施、自动推送、正式发布或完整发布验收。

## 跨版本待办

- v0.15.0 已完成正负曲率、极短弧和拥挤标签的有限边界验证；候选发布阶段按实际
  风险补充几何压力范围，区分合法相交、数值错误和视觉退化，不把固定耗时作为
  机器无关门槛，也不把有限场景写成穷举保证。
- v0.98.0 文档重构时确定网站信息架构，建立英语/汉语共用的图片生成源和资产清单，
  清理无引用图片并设计六边形 logo；字体、图标、配色和其他视觉资产可直接采用
  合法的第三方方案。
- 网站迁移完成后从主分支删除冻结的 `docs/`，改由独立发布分支或 Actions 发布。
