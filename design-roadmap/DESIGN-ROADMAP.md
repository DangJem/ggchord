## 未来版本摘要

- **v0.16.1–v0.16.3**：依次整理绘图语法、数据契约、内部引擎与输出；严重正确性
  问题发现后优先处理，不因归属后续版本而延后必要修复。
- **v0.16.4（可选）**：迁移较多时独立稳定化，否则相应工作归入 v0.16.3。
- **v0.16.5**：在候选 API 稳定后完成英语/汉语文档、教程、README 与网站重构。
- **v0.16.6**：发布候选冻结，集中处理平台兼容、视觉、性能和发布阻断问题。
- **v1.0.0**：仅正式稳定发布；不在此时首次启动架构或文档网站重构。

保留 chord、circular、collinear 三种主要模式，不增加第四类；新增 API 仅在通过
真实需求、契约、替代方案和验证审查后纳入。交互式绘图不在 v1.0.0 及之前的范围内。
后续版本开始前须以前版本地开发完成并整合 main 为前提，再从 main 创建专用分支；
本轮已启动 v0.16.0；后续阶段按各自完成条件推进，不自动推送、正式发布或运行完整发布验收。

## 跨版本待办

- v0.15.0 已完成正负曲率、极短弧和拥挤标签的有限边界验证；候选发布阶段按实际
  风险补充几何压力范围，区分合法相交、数值错误和视觉退化，不把固定耗时作为
  机器无关门槛，也不把有限场景写成穷举保证。
- v0.16.5 文档重构时确定网站信息架构，建立英语/汉语共用的图片生成源和资产清单，
  清理无引用图片并设计六边形 logo；字体、图标、配色和其他视觉资产可直接采用
  合法的第三方方案。
- 网站迁移完成后从主分支删除冻结的 `docs/`，改由独立发布分支或 Actions 发布。
