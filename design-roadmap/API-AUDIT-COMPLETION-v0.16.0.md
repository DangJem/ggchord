## 实际变化与验证

- 11项行为修复：F01/F02/F11关联问题、F31/F32/F33/F35/F36/F37/F38/F41；
  F34另按用户选择保留历史默认并澄清帮助。详见[迁移表](API-MIGRATION.md)和
  [版本执行记录](versions/v0.16.0.md)。没有新增、删除、重命名公开函数或改变形参默认值。
- 各修复已用直接最小输入取得对应运行证据。F41最后确认冲突ID明确报错、合法同DNA
  多name保留、原输入不变，以及不同ID迁移示例可搜索两条DNA；复用既有案例留一个回归。
- 最终静态生成与独立目录重建的全部17文件（16 CSV与README）逐字节一致，输入
  快照前后未漂移。3302行语义必填字段、897个函数、872个绑定及159条动态归属均已核对。
- `tools/validate-api-signatures.R`在F41源码上加载一次本地namespace，108个自有
  入口的形参名、顺序、默认表达式全部一致。它不调用这些API；不认证参数语义。
- context嵌套/错误恢复、ref/scale副本隔离、retired guard及13个原型aes只读清点的
  有限证据另见 `audit-validation/`；不把这些证据升级为所有设备/字体/图层组合通过。
- 最终差异空白检查通过。未运行testthat、devtools::test、R CMD build/check、
  vignette重建或PNG/PDF/SVG发布矩阵；新增回归源码仍待正式发布授权后全套执行。
