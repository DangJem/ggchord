# v0.16.6 — 发布候选审计与收敛

**状态：计划中；尚未开始。**

2026-10-30 用户确认从 v0.16.0 开始分阶段重构；本版不再直接接续 v0.15.0，
也不是第一次开展全量 API 审计。前序依赖见 [分阶段重构计划](../API-REFACTOR-PLAN.md)。

## 前置条件

- 前序 API 候选、迁移及稳定字段收敛，v0.16.5 的文档与网站重构完成。
- 前版本地开发完成并整合 main 后，从 main 创建 `codex/v0.16.6`；本轮未创建此分支。
- 明确支持的 R、ggplot2 与平台范围，并整理待正式发布授权后执行的完整验收项。

## 范围

- 冻结候选，检查全部导出、参数、美学、S3/ggproto 与返回契约的审计覆盖和决定状态；
  追踪 v0.16.0 以来的迁移，不临时发起批量改名或删除。
- 核对 getter/export 推荐路径、gene/feature 便利入口、link/ribbon 角色、颜色别名、
  重导出和低频参数语法是否已有明确取舍；保留也须有理由。
- 复核 geom/stat/position/scale/coord 职责与图层独立性，不让 stat/position 承接
  设备碰撞状态，不让 scale 承接物理轨道布局；内部 registry 与候选状态不公开。
- 集中修复发布阻断问题，整理三坐标、同类多层、方向、不同半径/曲率/gap、拥挤
  标签、定量轨道及尺寸变化的代表性视觉与几何记录。
- 建立少量视觉与性能基准，区分合法相交、数值错误和视觉退化；不把固定耗时当作
  跨机器门槛，不将有限场景写成穷举保证。
- 检查英语/汉语 README、教程、reference、网站与迁移示例的一致性及安装路径。

## 非目标与待确认事项

不主动扩张功能或增加布局模式，不在 RC 首次重写引擎、迁移接口或网站。
任何阻断修复若需要破坏性变化，先说明影响并确认；必要时退回相应阶段，不能只为
保持版本日期而带债进入 v1.0.0。具体平台组合和性能样例随前序风险盘点确定。

## 交付、验证与完成条件

- 候选 API 清单、迁移核对、支持版本声明、风险与阻断问题状态表、完整验收记录。
- 普通收敛仅做改动相关的轻量验证；计划本身不授权包级测试、打包/check、完整
  vignette 重建、PNG/PDF/SVG 设备矩阵或正式发布。
- 明确授权 GitHub 正式发布后，执行完整 testthat、R CMD check、英语/汉语
  vignette、设备与跨平台验收；源码、图像、文档和报告必须对应同一候选。
- 无未解决的严重正确性问题；文档网站已完成、迁移可执行、默认变化均有说明。
  本地通过与正式发布分别记录；本版本地开发完成并整合 main 后才创建 v1.0.0 分支。
