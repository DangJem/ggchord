1. 保存附件来源和校验信息，复核静态脚本；补审别名、ggproto 方法、匿名回调、
   S3/动态注册、NSE、`quote/eval` 和运行时包装，不能只统计直接具名函数。
2. 清点全部公开与内部对象、逐个形参、美学、返回结构和调用/参数流；覆盖构造器、
   geom/stat/position/scale/guide/coord/theme、导入、处理、预览和诊断。
3. 生成带基线 SHA 的机读清单；逐参数记录类型、默认、单位、NULL/NA、缺参、自动/
   禁用、验证、透传、坐标支持及来源证据，横向比较 offset/gap/width 等同类语义。

**交付**：`audit-generated/` 下的完整候选清单和覆盖/遗漏说明。静态盘点完成不等于
逐项审计完成，词法零引用不能作为删除依据。

- 复核附件全部 F01–F30，分别记录报告 C/H/D、本地静态证据、运行证据和决定状态。

- 提交 `API-ARCHITECTURE-PRINCIPLES.md`、`API-AUDIT-DECISIONS.md` 和

**交付**：目标架构、逐 API/参数建议、第一批方案及待用户选择的问题清单。
getter/export、gene/feature、颜色别名、重导出与新旧形状入口不预先决定去留。

- 优先复现 F01：非 NULL 且不合类型的 ribbon/gene 输入是否被静默丢为 NULL；
  分清 data.frame/tibble、NULL 及不支持对象的公开预期。

- 按确认后的范围小批实施；每批同步直接相关帮助、迁移、NEWS 和版本记录。

**交付**：最小反例、必要修复、相关轻量验证，以及所有实际改变的迁移记录。
若候选问题未复现，记录条件和结论，不强行安排修复。

## 非目标

不重写整个布局引擎，不重建网站，不增加第四种模式，不批量裁剪 API。
后续阶段的主要实施归属不影响本版全量审计；新 API 仅可作为经审查的缺口方案，
不预先承诺更多轨道、多 contig 或其他研究池能力。

## 完成条件与验证

- 所有导出、重导出、S3、内部对象和逐参数均有台账；覆盖差异与未知有明确记录。
- 公开入口均有有据可查的建议与确认状态，不能仍全为 UNREVIEWED 或语义空栏。
- 第一批实际改动有最小公开行为验证；迁移包含旧/新调用、原因、影响、错误提示和
  删除版本。影响安全实施的未知先解决，其他事项有后续阶段归属。
- 普通开发只做必要最小脚本、代表性 build 或断言；本版计划不授权运行完整
  testthat、打包/check、vignette 或设备矩阵。
- 用户明确授权 GitHub 正式发布后另行执行完整验收；正式发布并整合 main 后才
  创建 v0.16.1 分支。审计完成、本地验证完成和正式发布分别记录。
