# v0.16.5 — 文档、教程与网站重构

**状态：计划中；尚未开始。须在 v1.0.0 正式发布前完成。**

2026-10-30 用户确认采用报告路线，将原 v1.0.0 的文档网站重构前移至本版。
完整阶段安排见 [分阶段重构计划](../API-REFACTOR-PLAN.md)。

## 前置条件

- v0.16.3 或独立设置的 v0.16.4 已形成稳定 API 候选、默认值与返回字段，迁移有
  可运行的成对调用；不以尚未选择的接口批量编写教程。
- 前版正式发布并整合 main 后，再从 main 创建 `codex/v0.16.5`。
- 网站生成、部署方式和资源清理必须先完成设计，不把冻结 `docs/` 当作当前 API
  的权威来源；本轮没有解除网站冻结或授权上线。

## 范围

1. **定位与入门**：处理 F23，使 DESCRIPTION Title、README 与网站准确涵盖三种
   模式，包名可保留。首页提供定位、三类代表图、最小例子与安装/入门入口。
2. **文档结构**：围绕“安装 → 数据格式 → 最小出图 → 常用调整 → 进阶功能 → FAQ”
   组织内容。专题包括数据模型与坐标、三类场景、绘图职责、track、标签、引物/
   酶切、CDS 投影、focus/segment、输出诊断、reference、迁移和可复现 gallery。
3. **重写与同步**：基于候选 API 重写英语和现代汉语教程、README、vignette、
   roxygen/Rd、网页手册、FAQ 与迁移指南。README 保持简洁，详细内容放 reference
   和专题。删除过时例子前核对引用，不改写原始示例输入来改善视觉。
4. **双语契约**：用户可见的语种名统一为“英语”和“汉语”或“现代汉语”；对应页面
   一对一、有显眼切换，层级、代码、参数和锚点尽量对齐。建立术语表，并由 CI
   检查缺失翻译或孤立页；不能把某一语种缩为关键内容不全的摘要。
5. **视觉与可访问性**：优化字体层级、行宽、对比度、代码折叠、页内目录、搜索、
   移动端、键盘操作及明暗主题；以阅读效率与可发现性为验收依据。
6. **共享图片**：建立英语/汉语共用的图片生成源、参数与资产清单，重建文档图片，
   清理无引用的 `man/figures` 与网页图片，设计六边形 logo。记录第三方字体、
   图标、图片及配色的来源和许可，函数和参数名称仍保持通用；文档可按需列出
   主要布局、函数簇和默认风格的设计参考对象及链接。
7. **真实导出尺寸**：说明直接打印到 RStudio Plots 会按面板尺寸重新排列标签与
   图例；尺寸敏感图推荐 `view_ggchord()` 预览，并以相同显式尺寸 `ggsave()`。
   网页、README、vignette 图片共用导出尺寸测量路径，不使用临时面板布局。
8. **网站发布方式**：设计独立发布分支或 Actions 流程，完成迁移后再从主分支移除
   冻结 `docs/`。迁移和上线另按用户确认范围执行，不能先删旧站再补新站。

## 非目标与待确认事项

本版不首次定义核心 API、不增加第四类或交互绘图，不因文档困难另增同义入口。
官网信息架构细节、站点技术方案、logo/视觉方案及部署切换时机待本版设计确认。
候选 API 若有重大变化，应先解决接口与迁移，再重建受影响文档，不带矛盾进入 RC。

## 交付与完成条件

- 英语/汉语完整文档、网站源、导航/reference 分类、术语表、迁移与可复现 gallery。
- 函数与参数帮助从源码生成，文档无失效旧入口；每个新公开参数至少一个运行示例。
- 最小教程能完成三类图及保存；图片、输入与生成代码可追踪，语种间共用资产。
- 网站切换、搜索、锚点、移动端和键盘检查有记录，部署源与版本可追溯。
- 普通编写仅验证相关例子和链接，可生成 Rd，不自动触发完整 vignette 重建、
  testthat、包检查或发布设备矩阵；这些在明确 GitHub 正式发布授权后完整执行。
- 文档网站完成后才进入 v0.16.6 收敛；没有通过相关验收不能把本版标为完成。
