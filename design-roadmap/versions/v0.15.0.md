## 第一阶段：已实现

### 报告式准备与集合

新增 `prepare_ggchord_data()`，输出 constructor 三表及命名 `features`、`links` 集合。
`mapping` 复用既有列转换，保留来源 metadata；输入文件先用对应 reader 导入，
不根据扩展名自动导入。`genome` 列如存在须完整；不推断分组或重命名 accession。

默认只转换、验证，不清洗、去重、截断、聚合、改序或翻转。显式 `steps` 按
clean → filter → deduplicate → merge → bundle → optimize 的固定顺序执行；
每步继续可独立调用。clean 只影响 constructor 三表，其余操作只影响主 ribbon 表，
命名集合始终独立。布局优化只返回建议，不应用到图形。

报告包含转换来源、导入格式/文件/每文件行数、前后验证、命名 feature 的边界与 ID
问题、命名 link 的验证、各步骤报告、每个输出 ribbon 对应的原始输入行、pair 计数
和可选布局建议。去重等删除关系可在对应步骤报告中查到；步骤行号针对该步骤输入。
默认关闭二次方级的近重复验证；显式请求去重才执行所选去重策略。

准备流程的 clean 默认保留方向端点 `reversed_interval = "keep"`，区别于独立
`clean_ggchord_data()` 的历史默认 `"sort"`。显式 sort 与后续 deduplicate、merge、
bundle、optimize 冲突时给出错误与 keep 替代写法，防止正反向连接被合并。
该检查先归一化参数缩写；已排序输入的 direction 与端点不一致时同样拒绝，
不能通过再次 clean 覆盖方向来绕过。

`gene_data` 保持方向性基因契约；未知链和双向通用 feature 放入 `features`，
不通过把未知链填成 `+` 来绕过验证。结构性转换错误立即报错；已转换表中的未知
序列、越界等保留在报告，不默认修复。稳定 parent-child/domain 操作由第二阶段的显式 CDS 投影器处理。

### 导入与身份

- 新增 `read_bed()`：BED3–12，0-based half-open → 1-based inclusive；BED12
  保留并验证 blocks，生成 `segments`。保留原始坐标/显示字段，不自动套用颜色，
  BED name 不自动成为唯一 feature ID。零宽 insertion 和 BED12+ 扩展明确拒绝。
- 新增 `read_paf()`：保留 query/target 角色和相对方向，负链 subject 端点递减；
  保留原始坐标、tags 和 mapq 来源。`pident` 是已报告 matches/block length 的比例，
  不声称重新比对或精确重算；mapq 255 输出缺失值并保留原值。
- `read_gff3()` 暴露解码的 `feature_id` 与 `parent_ids` 列表，先分 Parent 再解码，
  保留重复分段 ID；新增 `unstranded = "keep"`，用于 nondirectional feature。
  旧默认 plus 不改变，`source_strand` 保留原始输入；再次转换时原始字段如冲突会
  按既有 metadata 前缀规则保留，转换报告可追踪其名称。
- 所有 reader 记录导入文件及每文件输出行数；转换器保留上游导入和转换记录。
  新格式依据 UCSC BED 和 PAF 规范实现，来源在 roxygen 中列出；没有复制解析代码。

### 目标 locus 与区间正确性

新增 `find_ggchord_loci()`：按明确 `feature_id` 找到目标，按链方向分别扩展
upstream/downstream，裁剪到全序列范围，报告目标边界、裁剪和来源行。
未知链只允许对称扩展；歧义 ID、蛋白坐标或跨原点区间不能被猜测为普通 locus。

现有 `focus_ggchord_data()` 已支持同一序列多个独立窗口和唯一 `locus_id`，
新 locus 结果直接复用它。每个窗口作为独立序列输出；第三阶段在此基础上增加同排多窗口、显示缺口和
局部翻转，不把独立窗口改写成一条虚假的连续基因组。

修复 `clean_ggchord_data()` 把 `start == end` 的合法 inclusive 区间误当零长度
删除的问题。完全越界区间在 clip 前报告并删除，不在边界制造虚假 1 bp；部分相交
裁剪后仅余 1 bp 仍保留。不改其历史排序默认，也不扩大为完整清洗重写。

## 第二阶段：已实现

2026-10-29 用户要求继续直到完成本版全部内容；本阶段现已完成实现与局部检查。

### 同源簇与基因组关系

- `link_ggchord_clusters()` 要求明确 feature ID、cluster membership 和比较 pairs。
  多拷贝/一对多默认跳过并报告，显式 `paralogs = "all"` 才展开，分配前检查
  `max_links`。保留比较方向、成员、来源行和原始分段，不生成 pident 或 alignment length。
  重复 ID 默认拒绝；显式 `segment_policy = "span"` 才按同序列/同链的非重叠片段
  建立 feature 包络锚点，且明确它不是 exon-to-exon alignment。
- `validate_ggchord_hierarchy()` 检查 genome 主键、contig 全局唯一 ID、外键、缺失、
  空表和孤立 genome。返回原表、结构化问题及 genome→contig 索引，不推断分组、
  拼接序列或自动改变绘图排列。
- `examples/data-workflow.R` 复用仓库原始 FASTA/GFF3/BLAST 输入；同源 membership
  必须来自用户，示例不根据名称伪造生物关系。

### 蛋白/基因组投影与父子 domain

- `build_ggchord_cds()` 建立显式分段 CDS 模型，接受长表或 segments 列表。按链确定
  转录顺序；显式 `segment_order` 保留跨原点 join。普通 `segment_index` 只作为来源
  metadata，不能把 BED 基因组顺序误认成负链转录顺序。
- 验证 GFF3 phase 连续性，只有首 phase 排除首个完整密码子前的碱基；后续 phase
  不逐片段删除。nested CDS 从明确首 phase/codon_start 推导后续连续 phase，
  不从外包络猜测。GFF3 phase 的数值/文字格式显式解析，未知点号保持未知。
  遗传密码只保留输入 metadata，不隐式翻译或推断。
- `partial = "trim"` 显式选择完整的观测密码子，保留首尾残缺信息；默认拒绝 partial。
  `codon_count` 包括源 CDS 中的终止密码子，不声称等于成熟蛋白长度。frameshift、
  translation exception、跨序列 trans-splicing 与非 join 的不确定次序明确拒绝。
- `project_ggchord_features()` 支持 aa↔基因组，保留 feature ID、单一 parent ID、
  分段、遗传密码及来源坐标。不连续 domain 往返不填补缺失区域；逆投影拆分密码子
  时默认错误，显式 `codon_boundary = "expand"` 才扩展并报告。
- `project_ggchord_links()` 只对明确 `ungapped = TRUE`、等长有序残基区间，按双方
  CDS 片段边界拆分配对。一般带 gap 的比对仅凭端点不足以恢复对应关系，明确拒绝，
  不能统一乘三或伪造核苷酸 identity/length。原蛋白统计保留为 source metadata。
- 投影结果可用于现有 feature/ribbon 图层，转换器和准备报告保留投影来源链。

### GenBank/GBFF 与可选序列对象

- 新增 `read_genbank()`，显式调用已选 Python 环境中的成熟 Biopython public
  `SeqIO.parse()`，R 侧以可选 jsonlite 交换临时 JSON。无安装、下载或 build 副作用。
  只面向中小型本地记录，不宣称 chromosome-scale streaming；此方案避免 R 候选
  parser 自动重命名 accession 的行为。没有复制第三方 parser 代码。
- 保留多 record、原始 accession.version、join/complement 顺序、qualifiers、原始文本、
  metadata、原始模糊位置及边界描述；没有 ORIGIN bases 不等于没有已声明全长。
  远程、不支持的 fuzzy 位置、混链、零宽位置默认错误，显式 report 保留未绘制项。
- CDS `codon_start` 缺失时按 INSDC 默认 1，标记 format-default 来源；原 qualifier
  不改。首密码子偏移/末端余数与模糊边界分别保留证据，不把完整位置边界误当完整
  CDS 末端。非法数值 qualifier 不静默截断或填值。
- `as_ggchord_seq()` 支持可选 Biostrings XStringSet/XString；未命名对象必须给
  `ids`，已有名称不得静默覆盖；保留 widths、metadata 和 bp/aa/character 单位。
  aa 宽度不是核苷酸坐标，必须走明确的 CDS 投影。named 对象可直接交给 ggchord。
- jsonlite/Biostrings 放在 Suggests；依赖缺失时明确说明安装或普通表格替代方向。

## 第三阶段：已实现

`segment_ggchord_data()` 复用 focus，返回独立窗口序列、片段声明和可逆来源表。
每个窗口保留独立 accession、来源序列/起止/全长、局部坐标和截断标志，
不生成一条坐标连续的假基因组。窗口表顺序控制同排片段顺序，row_id 显式指定显示排。

`coord_collinear(segments = ..., segment_gap = ...)` 把独立窗口映射到同一排，
支持每片段 orientation 与整排 align。各排共享真实 bp 标度；gap 是显示保留距离，
不等于被省略的基因组长度。片段之间自动画断裂标记；其笔画不继承骨架箭头。
显式窗口方向与自动 orientation、geom_seq 的方向以及 anchor 冲突时错误，避免互相覆盖。

跨缺口 ribbon 按线性端点对应拆成只覆盖保留窗口的片段，标记 display projection；
显式 cross_gap='drop' 则只保留完全包含于窗口对的输入。源 identity 不重算，估计
长度已有标志。实际会分配的窗口对在分配前受 max_links 限制，包括 drop 后要过滤的
部分重叠候选。点连接只有两端都在窗口内才保留；重复裁剪不覆盖最初的点来源。

Ribbon 邻接以显示排计算；同排比较默认省略并报告，显式同排 pair 或同排点连接
给出错误及拆排方向，不把不支持的几何压成一条线。feature、region、标签和轴继续
通过每个窗口自己的坐标工作；相同原 feature 可出现在多个不同窗口，标签匹配以
window accession + feature ID 确定，缺失 ID 时可复用完全对应的坐标表。

导出每窗口的 row_id、顺序、source 起止/全长、方向、x 偏移、公共 bp 标度和断裂
标志；`map_ggchord_position()` 用窗口 ID 反算，缺口及窗口外位置明确错误。
`examples/segmented.R` 提供独立合成坐标教学例；不改写任何原始业务输入。

## 已批准的合并开发范围

### A. 轨道声明、映射和数值语义

1. 用户声明稳定 track ID、顺序、侧别、带宽和间距。放置由 Position 风格接口表达，
   coord 负责物理映射；geom 保持独立 data/mapping/layer_id，scale 管数值和 guide。
   同 ID 可以多层叠加，声明冲突必须报错。环形 ring 是同一语义的环形实现，不另建
   第二套编号系统；不暴露内部半径、beam、slot 或迭代参数。
2. 提供区间 tile、采样点折线、区间柱形。coverage、GC content、GC skew 用已有
   数值表及教程展示，不新增比对、深度统计、自动 GC 计算或隐式预处理。
3. 同 ID 跨序列、图层、窗口共享数值域；不同 ID 可有不同单位和数值域。设计显式
   track-scoped role scale，用户 scale 优先，不能把 limits 塞进 geom，不能偷偷逐序列
   归一化。颜色域和数值高度域是不同 aesthetic，不混为一套映射。
4. 数值域包含明确 baseline，支持负值；变换、limits、breaks、labels 与 guide 同步。
   不可用的 baseline/变换组合给出明确错误或按显式 oob 策略处理并报告。
5. 新的物理宽度/间距支持明确单位；现有数值参数继续保留原布局单位，不能静默改成
   毫米，也不把所有旧参数一次迁移作为前置。最终函数名与签名在确认方案后按该契约
   实施，当前接口名 `geom_track_tile/line/bar()`、`position_track()`、`scale_track_*()`。

### B. 坐标、分段与障碍

- `coord_circular()`、`coord_collinear()` 支持三类基础几何；直线型含分段窗口和翻转。
- `coord_chord()` 按骨架局部法线实现几何可定义的带宽。先验证映射与带宽边界；
  不能容纳的曲率、内侧宽度或自交情况明确失败，不能通过压平、裁切数值或套半径
  伪造支持。不会承诺所有曲率/带宽组合均合法。
- 新轨道先使用小型带宽分配器，再接入既有实体障碍 provider 和布局导出。
  旧 feature/label 仅在确有共享冲突时接入资源申请，不全面重写标签求解器。
  数值轨道有不可越界实体带宽；外部文字仍以完整 bbox 参与碰撞，不能混作数值带。
- 保留 `accver`、1-based-inclusive 坐标和 source/window 关系。分段区间裁切/拆分，
  折线不跨显示缺口或 NA，翻转只改变显示方向，不改变数值域或正负含义。
- Inf 拒绝；NA 不补零、不插值；重复点和重叠区间不自动平均，明确排序/分组与歧义
  处理。圆图默认不连接首尾，若允许闭合必须显式声明。坐标越界按显式策略报错或
  裁切，并导出原始来源和裁切原因。不默认降采样、平滑或聚合。

### C. 物理尺寸、文字和轴

- 建立渲染测量上下文，区分 measured / estimated / unavailable；准确记录目标尺寸、
  实际 panel、设备/字体条件。设备未知的 build 可以估计，但报告不能写“实测通过”。
  尺寸变化需使有关布局缓存失效；尺寸/布局反馈采用有界流程，不能无限重建。
- 在现有文字框和局部形状工具上增加显式内部字号适配、最小字号及实际字号导出。
  不默认缩小全部文字，不删除原标签文本，到下限后走已有外移或隐藏策略并记录原因。
- 选择性序列轴复用 seq_position 入口，按 accver/window ID 选择；保持 relative/source
  坐标与反向语义。公共直线 bp 比例尺只用于共享标度的直线型，显示 gap 不算基因组
  距离；圆图/弦图保留局部序列轴。轨道数值轴与基因组 bp 轴分别表达。

### D. 按需输出诊断

- 提供一个目标尺寸报告入口，复用现有预览、导出和诊断信息，不改变 ggsave 工作流。
- 报告测量条件、最小字号/线宽、真实画布裁切、guide 超出画布、已支持的文字/引线/
  实体冲突，以及图层/轨道/来源行。panel 外对象在 clip='off' 下可能合法，不能一律
  报裁切；合法 ribbon 相交也不算错误。
- 字体嵌入、字体回退、跨软件透明度等只有取得对应文件/设备证据才评价，否则明确
  未检查或未知。PNG/PDF/SVG 不做“通用合格证”；颜色模拟、灰度相近和 guide 占比
  仅为提示，保留算法假设与阈值，不自动改风格。

### 实现结果

- 轨道入口为 `position_track()` 和 `geom_track_tile/line/bar()`。同 ID 共享声明与数值域，
  独立图层保留输入、映射和来源行；同 ID 的冲突带宽/侧别/顺序报错。
  `scale_track_value_continuous()` 管高度、变换、baseline、单位与数值轴；
  `scale_track_fill/colour_gradientn/manual()` 管独立视觉域。用户 scale 与显式固定样式
  保持优先，支持 staged visual mapping，未显式固定的普通样式可正常映射。
- 三种 coord 均已实现局部法线轨道。区间按完整 inclusive 宽度绘制，单碱基不会退化；
  点按既有 bp 位置绘制。非法带宽、自交、跨序列骨架/带宽相撞明确拒绝，不改变数据
  或曲率来掩盖。允许区间按绘制顺序重叠，折线按显式 group 分系列并要求位置递增；
  NA 断线，孤立点省略并报告，Inf 拒绝，只有显式 closed 且圆图 gap=0 才闭合。
- `focus_ggchord_track()` 为点/区间复用显式窗口 ID，保留最初 source 坐标和来源链，
  不创造边界样点。分段翻转改变显示方向而不改变正负值；缺口与 NA 不连线。
  坐标裁切与数值 limits 的省略分别报告。全带宽接入旧障碍 provider；线性共享标签
  避开实体带宽，曲线旧注释先完成布局再分配新带宽，不重写全部旧标签求解器。
- 标准 print/ggsave 的 gtable 钩子取得真实 panel，最多三轮局部重建，尺寸改变使相关
  缓存失效，设备/上下文在退出时恢复。测量状态区分 panel 实测与几何是否收敛，
  未收敛及设备未知保持 estimated；原默认绘图不自动触发新尺寸重排。
- `geom_feature_label_repel(label_fit = "shrink", label_min_size = ...)` 和
  `geom_gene_label_repel(gene_label_fit = "shrink", gene_label_min_size = ...)`
  显式启用内部优先适配。保留原文本和请求/下限/实际字号，到下限仍不容纳时恢复
  请求字号并走原外移/隐藏策略，导出具体原因。默认 wrap 和默认字号不变。
- `scale_seq_position_continuous(sequences = ...)` 选择 accver/window 轴，空向量隐藏全部，
  未知 ID 给出错误。`geom_seq_scale()` 在直线型共享 bp 标度下绘独立比例尺，可与
  分段/反向和 source 轴组合；显示 gap 不计为源基因组距离。
- `diagnose_ggchord()` 只检查一个指定目标设备/尺寸，隔离原图与缓存，返回 panel 条件、
  画布边界、字体/线宽提示、guide 尺寸、旧布局诊断、轨道来源及可选色觉模拟。
  字体嵌入/回退、跨软件透明度、未注册 grob 和箭头端部明确标为未检查；灰度、
  色觉和 guide 占比只作提示。正式保存继续使用标准 `ggsave()`。
- `export_ggchord_layout()` 增加轨道几何、`track_registry`、`track_diagnostics`、
  `label_fit_diagnostics`、`axis_selection`、`render_context`；数值轴和公共比例尺归入 axis。
  导出组合修复了空表与非空表补列合并问题。
