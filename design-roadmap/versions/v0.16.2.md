# v0.16.2 — 数据 API 与生物学契约统一

**状态：2026-10-31 本地开发完成；在 codex/v0.16.2 完成并按授权整合本地 main；未正式验收或发布。**

本版是 API 分阶段重构的数据阶段；总安排见
[API 重构计划](../API-REFACTOR-PLAN.md)。以下列明本版核查范围；候选先复现再定性，没有新增数据分析入口。

## 前置依赖

- v0.16.0 提供完整盘点、证据分级与基础修复记录，v0.16.1 明确绘图层职责边界。
- 开始本版开发前，v0.16.1 必须已本地开发完成并整合 main；再从 main
  创建 `codex/v0.16.2`。前置条件已满足，本轮已启动本版数据契约开发。
- 严重正确性缺陷按发现时所在版本优先处理，不因归属本阶段而延迟修复。

## 范围

- 统一 read、as、validate、clean、prepare 的职责、输入类型、错误模型和返回契约。
- 比较各读取器的单文件/多文件、来源字段、编码、异常行与可选依赖行为。
- 明确 1-based inclusive 与 0-based half-open 转换；核查单碱基、零宽、越界、
  反向端点、环形跨原点与分段窗口，保留原 ID、源行、坐标与变更报告。
- 区分生物学 strand、显示 orientation 和连接的相对 direction；自动布局不构成
  生物学方向推断，不擅自交换 query/subject 或补造缺失长度、注释与统计值。
- 梳理 focus、segment、map、project 及 filter、deduplicate、merge、bundle、stat
  的选择、投影与聚合含义，说明信息损失、来源集合和适用字段。
- 核查 Bioconductor 适配的元数据、未知链和序列信息保真，以及 GenBank 的
  Python/Biopython 环境、离线使用、位置解析和失败信息。
- 明确 cluster、primer、restriction、common-feature 等辅助算法的输入、来源、
  结果置信含义与静态绘图边界，不把搜索命中表述为实验验证。

## 报告问题对应

- C/H/D 均保留原证据来源；只有新的源码或运行证据才能改变核查结论。

## 非目标

- 不默认执行不可逆清洗或制造业务数据，不以统一名称抹平 link 与 alignment 的差别。
- 不增加第四类绘图、不全面重写布局、不将可选生物信息依赖自动改为强依赖。
- 多 contig、分组或其他新工作流留在待研究池，未通过准入评估前不形成承诺。
