# v1.0.0 — 稳定 API 正式发布

**状态：计划中；尚未开始。**

2026-10-30 用户确认采用分阶段路线。原在本版安排的文档、教程与网站重构已前移至
[v0.98.0](v0.98.0.md)，具体要求在该版完整保留；本版是稳定发布，不是第一次启动
架构、API 或文档重构。跨版本安排见 [分阶段重构计划](../API-REFACTOR-PLAN.md)。

## 前置条件

- v0.99.0 候选收敛完成，无未解决的严重正确性或发布阻断问题；文档网站在本版前
  已完成且与候选一致，迁移、支持范围、默认值与返回字段已经明确。
- v0.99.0 正式发布并整合 main 后，从 main 创建 `codex/v1.0.0`。
- 用户另行明确授权 GitHub 正式发布后，才执行完整发布验收与发布操作。

## 范围与交付

- 冻结核心 aes、scale、theme、guide、coord、数据与 layout export 的正式契约。
  旧参数迁移与删除应已在前序完成；遗漏若影响稳定性，先返回相应阶段处理。
- 仅修复 RC 新发现的发布阻断问题；修复必须同步相关帮助、迁移、图片及双语页面，
  不借阻断修复增加未审查的新功能或大规模更换默认外观。
- 明确稳定版后的兼容、弃用与删除政策，以及支持的 R、ggplot2 和平台范围。
- 发布权威参考文档与对应版本网站，保证源码、包元数据、tag、安装方式、说明及
  附件校验信息一致；正式发布后按仓库规则整理版本记录和历史索引，再整合 main。

## 发布完成条件

- 在明确发布授权后通过完整 testthat、R CMD check、英语/汉语 vignette、
  PNG/PDF/SVG 及规定的平台验收；候选改动导致证据失效时重做受影响检查。
- README 简洁，英语/汉语页面对应，代码、API reference、图片与迁移均匹配发布版。
- GitHub Release 按“现代汉语”在前、`English` 在后，覆盖同一组版本事实；逐项
  核对 tag、版本号、比较链接、附件、校验和及草稿/预发布状态。
- API、文档或发布资产仍有重大冲突则延后发布；本地验收通过不等于已正式发布。

## 非目标

不首次重写网站、批量新增或重命名公开 API，不新增第四类绘图。
`view_ggchord()` 是静态导出尺寸预览；真正的交互式绘图不属于 v1.0.0 及之前的
承诺范围，发布后再基于稳定契约单独评估，不预先承诺接口。
