## 非目标

- 不增加第四类绘图模式，不全面重写布局引擎或重建网站。

- 不为缩短函数签名把参数统一藏入 `...`；不无理由改变默认配色、布局和图例。
- 新 API 仅作为有真实场景和现有能力缺口证据的候选，按总计划准入后确定。

  显式调用改变图形；radial 默认保持。冗余 trunk 兼容值随后按自主清理授权删除，
  旧调用明确迁移至 radial。straight 使用位点 tick 端点
  到标签边缘的直线，不自动绕行；elbow 保留一个折点；既有标签槽位和来源不变。
- 用户已选择显式固定样式优先：提供固定值时覆盖同名视觉映射，省略固定值时保留
  映射；默认外观不变，需同步迁移说明并核查 wrapper/inherit.aes/staged mapping。
- 用户未接受最初整组保留建议，随后明确授权自主判断，形成下列实际取舍。
- 用户随后授权自主判断具体统一/优化/删除项：feature 作为通用内核，gene 等为
  特定语义参数的快捷方式；避免同义不同名参数，英美拼写别名除外。theme 的 IDE
  显式参数优先保留 ggchord 专属设置，通用 ggplot2 外观通过 dots 继续传递。
  采用以下实施范围：保留 gene 入口及其定向链约束和独立 gene 美学，但共享 feature
  构造内核；固定形状统一为 shape（美学仍为 feature_shape），宽度统一为 width；
  gene 标签公开参数统一为 label_*，连接 gap/control 统一为 link_gap/link_ctrl_point。
  移除的旧固定参数在 v0.16.1 给出明确迁移错误。用户在中断后进一步明确：旧版承诺
  的 v1.0.0 删除期限已过期，应及时删除需要移除的 API；本版据此删除 gene_offset/
  feature_offset，统一迁移至 Position，不再保留旧弃用入口。colour/color 和重导出
  保留，均无独立语义重复。
