- v0.16.3 收尾时盘点尚未收敛的公开语义、默认值、废弃入口、返回字段与迁移风险。
- 若剩余工作较多，向用户提出独立版本范围；若较少，可在 v0.16.3 收尾完成。
  是否单独发布及其范围待该次盘点后决定，不能预先写成已批准承诺。
- 若启用，开始开发前 v0.16.3 必须已本地开发完成并整合 main；再从 main
  创建 `codex/v0.16.4`。本轮不创建该分支，也不提前删除任何旧入口。
- 若不启用，记录取舍和剩余事项归属，由 v0.16.3 接续 v0.16.5，避免重复安排工作。
  保留 v0.16.4 空号，后续 v0.16.5/v0.16.6 不因此重新编号。

## 候选范围

- 整合前序已决定的命名、错误信息、未知参数处理及废弃策略，核查实际实现一致性。
- 核对每项已实施改名、合并、拆分或删除是否具备可执行的新旧调用与明确删除版本。
- 逐项收束别名、重导出、旧参数和布局 getter/export 的公开边界。
- 冻结稳定候选的默认值、单位、NULL/NA 语义、aesthetic 与返回对象稳定字段。
- 修复三种坐标与核心图层的已确认组合缺口，解决迁移链中的不兼容与文档误导。
- 为 v0.16.5 的教程及网站重构提供唯一、可引用的 API 候选及未定事项清单。
