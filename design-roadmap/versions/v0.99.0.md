# v0.99.0 — 稳定 API 候选审计

**状态：计划中。**

v0.99.0 只做发布候选审计，不再扩张功能：

- 清点全部导出函数、参数、aesthetic、S3 类和返回对象；
- 删除无调用或职责重复的接口，冻结保留接口；
- 对不同 R、ggplot2 版本和主流平台执行兼容检查；
- 建立少量稳定视觉基准和性能基准；
- 修复 release blocker，不再加入新布局模式。

审计清单至少包括：

- 确认 `get_chord_layout()` 与 `export_ggchord_layout()` 的单一推荐入口及迁移路径；
- 审核 gene/feature 便利入口是否继续并存，并确保其共享实现而非复制行为；
- 统一 link/ribbon 的 geom、stat、scale 角色命名，清点所有颜色／colour 别名，
  为保留别名和弃用别名分别记录理由与删除版本；
- 逐项审核 ggplot2 re-export，避免把纯便利符号误当成 ggchord 长期 API；
- 核对每个 geom/stat/position/scale/coord 参数的职责，禁止 stat/position 接收
  设备碰撞参数，也禁止 scale 携带物理轨道状态；
- 将内部 annotation registry、候选状态和导出诊断字段分级，只有明确承诺的字段
  进入稳定返回契约，其余保持内部且不以测试锁定。
