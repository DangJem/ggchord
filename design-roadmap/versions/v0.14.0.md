# v0.14.0 — 直线型多序列共线性

**状态：正式发布验收中，尚未发布。** 开发分支为 `codex/v0.14.0`，从已发布
v0.13.1 的主分支创建。以下计划于 2026-10-28 确定；实现、轻量验证和正式发布
验收分别记录，不把开发完成视为已发布。

新增专用 `coord_collinear()`，不能“静默忽略”弦图参数：

```r
ggchord(seq_data, ribbon_data, gene_data) +
  geom_seq() +
  geom_link_ribbon() +
  geom_gene() +
  coord_collinear()
```

- 同一套 sequence/gene/feature/ribbon 数据和 role aesthetics 可在弦图与直线图间切换；
- sequence 变为水平轨道，ribbon 变为相邻或跨轨道连接，gene/feature 使用法线偏移；
- `seq_order`、`seq_orientation`、position scale 和 `focus_ggchord_data()` 保留
  对应语义；
- `seq_radius`、`seq_curvature`、`seq_ring` 等弦图专属参数若被显式设置，立即
  给出可执行的冲突信息，不能静默忽略；
- 可无损转换的参数才转换，例如 `seq_gap` 对应轨道间距；
- 支持全局坐标、相邻比较、显式锚点对齐及有证据的自动定向；保留 feature stack，
  分段局部翻转另行设计；
- 直线模式共享 scale/theme/guide，不另建一套重复 geom API。

## 与圆形轨道的职责边界

- `coord_collinear()` 不继承 `coord_circular()` 的同心物理 track 注册表、
  `track 0 = backbone` 编号、径向半径、圆心保留区、弧形标签或内环刻度几何；
- Position 的局部意图仍可复用：`position_strand()` 表示法线两侧，
  `position_feature_stack()` 仍输出局部 lane、重叠顺序和优先级；是否映射为
  直线上下带及其物理间距，由 `coord_collinear()` 自己的 layout strategy 决定；
- breaks、labels、transform、字体 bbox、基础碰撞和障碍注册协议可共享，
  但直线坐标轴、水平/垂直标签和连接线分流必须是独立策略；
- 公开导出中必须区分 Position 的 `lane` 和各 coord 生成的物理布局资源，
  不让直线坐标伪造“半径”或圆形 `track` 语义以换取表面接口一致。

该版本重点是坐标契约和语义一致性，不承诺在第一版实现自由 track 容器或任意
facet 组合。

## 开发计划与坐标契约

### 第一阶段：坐标入口和参数边界

- 新增继承现有 ggchord 坐标基类的 `coord_collinear()`，保留 `ratio`、
  `xlim`、`ylim`、`expand`、`clip`、`fit`；没有全局旋转参数，水平轨道从上到下
  按 `seq_order` 排列，默认遵循输入顺序。
- 所有序列共享一个线性 bp 比例；最长骨架的布局宽度为 2，默认左对齐；
  `coord_collinear(align = ...)` 可选居中、右对齐，`anchor` 可显式指定逐序列锚点。
  `seq_orientation = -1` 只翻转该序列的基因组方向；连接端点、feature 箭头和轴
  同步翻转，不改写原始坐标、链或输入表。
- `seq_gap` 转为相邻骨架间距占最长骨架宽度的比例，默认 0.3；显式值必须有限且
  大于零，不再套用弦图的总 gap 小于 1 限制。向量按序列匹配，最后一条序列的值
  不产生额外轨道。该默认值只适用于直线模式。
- 两种添加顺序都尽早拒绝显式 `seq_radius`、`seq_curvature`、`seq_ring` 映射或
  ring scale，以及显式 `seq_label_radius`，并指出删除参数或改用 `seq_gap`。
  默认参数不会被误认成用户显式输入。
- 单圆图专用的中心标题、restriction-site 和 primer 层暂不纳入直线模式，给出
  明确错误与使用 `coord_circular()` 或通用 feature 的替代方向。
- feature 标签的 `external = FALSE` 限制圆形骨架外置，在线性坐标中无法无损转换，
  显式报错并提示删除该限制或使用 `coord_circular()`；自动标签各模式共享线性行策略。

### 第二阶段：独立线性布局

- 在已标准化数据和参数后选择线性策略，复用图层 registry、role aesthetics、
  source row、统计、scale、theme 和 guide，不新增重复的 geom API。
- 生成水平骨架、gene/feature 形状、region、相邻与跨轨道 ribbon 和 point link。
  线性 ribbon 默认仅相邻序列；`adjacent_only = FALSE` 保留跨轨道连接，`pairs`
  选择显式比较对。所有坐标下 ribbon 默认外框虚线，固定/映射线型及用户 scale 优先。
  连接保留真实 query/subject 区间与反向比对；跨轨道连接允许经过中间轨道，
  不承诺自动绕开整条中间骨架。
- 自动连接控制点由两端决定，不吸向弦图原点；显式控制点解释为线性布局 x/y。
  端点间隙朝向目标轨道，并按该方向读取 feature 障碍。显式 gap 优先。
- Position 的正法线固定向上、负法线向下，不随整图中心或序列翻转改变。
  复用现有 lane 分配和优先级，把 lane 映射成独立上下带。

### 第三阶段：轴、标签与导出

- 各序列独立生成水平轴，复用 position scale 的 breaks、labels 与 transform 的
  既有刻度语义；不把横坐标伪装成角度或半径。
- sequence label 放在轨道左侧；gene/feature label 使用线性水平或垂直文字及
  独立局部避让策略，保留固定标签和自动标签入口。弧形/radial 模式的局部意图
  适配为切线/法线，不调用圆形轨道注册表或外部圆周分配器。
- 多个同类图层保留独立输入、映射和几何；用户 scale 优先。
- `export_ggchord_layout()` 标注 `coordinate = "collinear"`，附真实序列 y、
  横向范围和 bp 比例的 `sequence_layout`，保留 Position `lane`、
  `normal_offset` 和 source row，不生成 circular track/radius 字段。
- 跨图层标签共同避让所有序列标签、轴文字及真实 feature；导出 `label_diagnostics`
  记录放置、隐藏、来源行和原因，候选位置耗尽时不输出未说明的碰撞。
- gene/feature 多边形和标签分别拥有自己的 Position。在线性模式中，未显式指定
  Position 的标签可复用相同生物区间几何层的 lane，类型和文字不参与区间匹配；
  显式指定标签 Position 只调整标签锚点，不改变几何层。标签文字独立读取标签层输入。
- position scale 显式 `breaks = NULL`、`minor_breaks = NULL`、`labels = NULL`
  分别关闭相应刻度或文字，不回退到默认值；自动 feature 标签保留请求侧别，移位后
  的引线仍保留显式线型。

### 第四阶段：文档、示例与轻量验证

- 更新开发版本号、已实现的 NEWS、对应 roxygen/Rd 和一个可运行示例；不重建冻结
  网站或全面重写教程。
- 使用显式的 `tools/validate-collinear.R` 验证代表性 build、正反方向、序列顺序、
  相邻/跨轨道连接、Position 上下带、独立图层、focus 后输入和参数冲突。
  检查公开几何方向、有限坐标与 source row，不锁定精确浮点数或内部迭代细节。
- 只加入最小公开行为测试；当前阶段不运行 testthat、包 build/check、vignette
  重建或 PNG/PDF/SVG 发布矩阵。正式发布仍须用户明确授权，再执行仓库规定的

### 2026-10-28 扩展范围实现记录

本次扩展已实现，继续处于开发分支，**尚未正式发布**。以下为代码事实；正式发布
验收与本地轻量验证分别记录。

- C1–C4 已修复。自动连接基础间隙按通道缩小；显式 gap 和实际 feature 障碍
  无法容纳时明确报错。focus 同步裁切/平移 segments、派生 runs 和 cleavage
  arrows，记录 source origin、源区间、截断端及 alignment 显示投影/估算标记。
  线性短箭头压缩头部到真实区间；重复 seq_order 拒绝，subset 语义保持。
- `coord_collinear(align, anchor, orientation, min_support)` 统一拥有显示平移和方向。
  `anchor` 接受逐 accver 命名位置或唯一的 position/start-end 表；缺失、多义及
  越界锚点报错。`orientation = "auto"` 以较早显示序列为参考累积区间方向支持，
  首条固定参考方向；未知链证据不参与。阈值衡量正反支持不平衡，平票/低支持/
  无证据保留初始方向，导出 `orientation_diagnostics`，不承诺全局最优或生物学
  链推断。显式 seq_orientation 与自动模式冲突；不改序列顺序和输入坐标。
- ribbon 新增 `adjacent_only` 与 `pairs`；NULL 使用坐标默认，显式 pairs 可替代
  默认邻接筛选，TRUE 与非邻接 pairs 冲突。`connection_report` 记录原图层行号、
  两端、保留状态和省略原因；筛选后几何仍正确关联原始行。圆形路径保留默认全连接，
  跨轨道连接不会被删除，线性使用者可显式恢复。
- `sequence_layout` 增加 x 平移、方向、units_per_bp、source origin 与截断状态。
  `map_ggchord_position()` 支持相对/源 bp 与布局 x 正反转换，返回对应骨架 y，
  可供标准 ggplot2 附加层使用。`coordinates = "source"` 只改变线性 position
  scale 的刻度域与文字；`geom_seq_break()` 按真实截断端绘制断裂装饰，翻转后仍
  跟随对应基因组端。断裂装饰和手动 symbol 扩展不改写生物坐标。
- unique `feature_id` 优先匹配标签与实体，标签筛选/重排继承完整源实体表的 lane，
  不先筛选再重新堆叠；同 ID 的区间矛盾报错。未显式 Position 的兼容整表区间
  匹配仍保留；同时匹配多个实体图层时报错，提示使用显式标签 Position 或无歧义
  ID。显式标签 Position 独立计算，不影响实体。能够完整放入 feature 的文字先
